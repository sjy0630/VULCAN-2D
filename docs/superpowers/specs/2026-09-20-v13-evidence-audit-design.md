# v0.13 状态交接与验证审查设计

用户目标：为朱凯晨 Nature h-BN 1T1M 器件提供仿真模型和有依据的物理解释。用户已授权推进 SET/RESET 衔接、物理依据与完整验证。本轮落实第一阶段；不改变已有拟合律、不新增时间动力学或微观物种假设。

## 设计选择

SET 的 x 在正向 pre/connected 包络之间定义；RESET 的 p 在反向 HRS/LRS 包络之间定义。直接令 p0=x 或乘 x 修正 RESET 没有标定依据。用最终 SET 参考电流缩放虽量纲正确，却假定同一个 η 对未连接分量也成立，还会在 x→0 时破坏 RESET 包络排序。

因此采用最小可核实方案：保留 `model_v12.py` 及已提交报告，新增 `model_v13.py` 作为适用域审查层。SET 最终参考电流与完整 connected 包络须满足相对误差不大于 1e-3，并同时检查状态接近 1（误差不大于 1e-3）、参考电压和包络正值、包络排序与有限性。两条容差均为充分 SET 近似的实现约束，不是实测材料阈值。全部检查只读模型输出，不读目标电流。域外抛出明确异常，独立 SET 接口仍可诊断。

新增 API 保留 SET/RESET 各自状态与电流，输出 `handoff` 审查信息；不输出误导性的统一 `connected_fraction`。旧 M12 显式 API 保持原样，包顶层完整循环接口切换到 M13。数值律、默认参数及两个 RESET 模式不变。

## 验证与证据

新增 `validate_v13.py` 复用原拟合和评分函数：原 51 对只限定训练资格，全 53 对均做目标排除预测。每折剔除目标 S_i 和可用 R_i，记录编号；R2/R3 也不得用含其 SET 的全量拟合。输出旧 51 对、全 53 对、原拒绝 2 对三个分组，以及固定前35→后18顺序检查，保留两个 RESET 模式。

评分完整披露实际电流门槛、无效预测数、失败原因和逐循环误差。固定前35训练输运律对实测 RESET 重建 E50/width，仅作回顾性诊断，不反馈给预测。图形显示这些范围与失败样本，不能写“目标电流仅用于评分”而忽略训练资格筛选。

物理证据表逐项对应当前执行路径的方程、参数单位、数据来源与推断层级。旧版 patch/损伤/热模型叙述不作为 v0.12 当前实现证据。
