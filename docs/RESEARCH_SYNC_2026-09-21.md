## 安装与测试

本机使用 Python 3.13。建立独立环境后：

```bash
python -m pip install -r requirements-research.txt
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m unittest discover -s tests
```

部分连续传播模块按源码哈希编译本地 C++ 加速库，需要可用的 C++11 编译器。
本次在 macOS arm64 上验证，未宣称完成 Windows/Linux 全平台验证。
2026-09-21 本地工作区与仅由 Git 暂存内容导出的干净副本均通过 239 项测试；
干净副本验证不依赖此次未上传的本地研究轨迹。
