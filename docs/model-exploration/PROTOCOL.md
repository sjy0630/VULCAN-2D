# 模型迭代协议

自 2026-11-25 起执行。适用于改方程、状态、参数、晶体管负载线、初始化、数据筛选或验证方式，以及用于决定模型去留的对照实验。模型暂留、退回或失败的理由与改善一起归档。

## 开始前

1. **写清问题。** 用一句话写本轮要解释哪段曲线。列出基准、打算改变的公式或假设、应保留的行为，以及什么结果会让这次尝试值得继续。例如，改善 0.9 V SET 开通位置，同时检查裸 hBN 的漏电和达到 1 mA 的电压。
2. **定好比较条件。** 记录数据来源和版本、圈号或扫描 ID、标定和留出范围、限流和筛点规则、模型使用的实测输入。写明初态如何得到，SET 末态是否传给 RESET，以及各圈之间是否传递状态。扫描时间、缺失圈和 SET/RESET 配对关系按可确认程度记录。
3. **留好基准。** 保存基准参数、代码版本或实际使用的快照，以及能找到基准评分和曲线的路径。验证新旧模型时尽量共用样本、输入和评分点。必须改口径时，用新口径重算基准，或在表中把结果标为不同任务。

## 每轮要留什么

| 内容 | 最少记录 |
|---|---|
| 改动 | 旧版和新版的关键方程或代码入口、变动参数及单位、参数来源与约束。用普通话解释该改动影响的是即时电流、状态演化、初态还是外电路 |
| 物理依据 | 写明实测看到了什么，模型据此提出什么假设，这一轮结果支持该假设到什么程度。记录拟合值触及边界、仅能定位现象、依赖特定观测输入等情况 |
| 评分 | 对同一批点给出基准和候选值，附样本数、单位、分段条件。I–V 默认报告对数电流 RMSE（decade），并注明所用电流下限或筛点、聚合方式与使用的实测输入 |
| 图 | 有 I–V 结果时保存实测、基准和候选的同图对照，标出栅压、接法、SET/RESET、去程/回程、横轴用端口电压还是 hBN 局部电压。用一两句话写清偏差落在哪段 |
| 去留 | 写出改善、退化、仍未覆盖的工况，以及本轮决定。可写保留为候选、保留作对照、采用或停止这一方向 |
| 复现 | 记录版本或快照、关键代码与参数文件、运行命令、数据入口。随机试验写种子或重复策略，数值精度会影响结论时保留加密或电路校验结果 |

实验输出尽量保留原始 JSON、CSV 或 NPZ 和原图。纯推导、定位诊断或中止的实验可用推导、统计量、日志、异常位置或已生成的图表作为证据，并注明进展到哪一步。一次迭代可记录多个对照，给每个会影响结论的候选留一行。

## 裸 1M 与跨栅压 1T1M 的验证

- **候选若声称统一**，写清 hBN 电流方程、状态规律和共用参数。栅压通过晶体管负载线进入计算，裸器件按其仪器限流条件处理。另行校准的幅度、逐扫描低压实测输入或其他初始化量要单独列出，并说明来源。
- **按接法、栅压和分支报误差。** 在本轮涵盖的范围内，至少展示关键工况的分段评分和图。SET 一般看开通前、开通区和开通后，限流点以及达到限流的电压单列。RESET 一般看去程、回程和低压终点。全局 RMSE 可一并列出。
- **明确预测条件。** 写明模型只用了波形、用了低压实测初态，还是代入了实测入口、终点或写后分组。标明同组留出、跨栅压留出、跨接法迁移，以及数据此前是否用于选择模型。只做某一支路的实验可按该支路收尾，结论覆盖实际测试的范围。

## 归档与汇报

1. 从[模板](ITERATION_TEMPLATE.md)复制一份到 `iterations/YYYY-MM-DD-NN-简短主题/README.md`，同一天用 `01`、`02` 顺排。评分、图和小型配置放在该目录中，相同证据可用相对链接复用。大数据或已有数据记录路径、版本或校验值即可。
2. 在[模型探索目录](README.md#迭代记录)追加一条，写明日期、问题、结果和记录入口。保留旧轮次的评分与原图。复跑或更正时追加结果，注明采用了哪份证据及原因。
3. 汇报前打开图和评分文件，核对报告数字、单位、基准和数据范围。记录应写明本轮做到了哪一步、据此怎么决定，便于下一次沿着证据接手。
