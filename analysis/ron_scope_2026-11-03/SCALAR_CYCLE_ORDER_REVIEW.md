# 重复协议下确定性单状态模型的周期保序约束

日期：2026-11-03。性质：理论推导与检验范围审核；不拟合、不运行新 ODE、不读取 holdout 或新的原始数组。

**结论：命题成立，但需要“同一个完整驱动协议”“标量状态的确定性唯一演化”和“固定节点端口读出对状态同向单调”这三个条件同时成立。** 在这些条件下，每个连续记录段的同一相位、同一原生命令节点上的电流幅值，只能沿一个方向单调变化或进入平台；不能先明显上升再明显下降。一个段内不同节点、不同相位还必须共享同一个电流排序方向。仅靠重新选择固定 Ron、阈值或速率，不能改变这个结构性质。

这个结论不是对所有单状态物理模型、所有含噪器件或所有实验历史的否定；以下逐项限定其适用范围。

## 1. 假设必须写全

设 x 是唯一动力学状态，单个完整循环的协议坐标为 τ∈[0,T]。它可以是物理时间，也可以是当前模型的累计绝对命令电压路径，但一次检验只能采用一个明确约定。

1. 每个循环执行相同的完整协议：电压顺序、相位顺序、已建模的扫速/驻留、固定外部负载及参数都相同。相同的已存电压数组只证明电压节点相同，**不自动证明真实时间协议相同**。
2. 状态满足确定性标量方程 `dx/dτ=f(τ,x;θ)`，在所比较的状态域内存在前向唯一解，能完成所需协议；θ 不随圈号改变。允许非自治、分段相位或显式时变驱动，只要每圈重复同一函数/协议。
3. 相位切换时状态连续，或切换映射本身保序。不能加入未声明的每圈重新初始化、非保序跳变规则或有自身记忆的控制器。
4. 对每个固定采样节点 c，端口电流幅值 `Y_c(x)` 是状态的单调函数，且本次使用的各节点具有相同的单调方向。当前冻结谱读出对 Γ 单调增加、对 `u=ln(1+Γc/Γ)` 单调减少；正、负支路分别使用正确的带符号材料函数，均可按幅值排序，**不需要材料读出是奇函数**。
5. 比较的是同一器件、同一状态描述及同一测量映射。附加随机激励、状态依赖测量偏置或未建模的物理变量不能悄悄塞入固定标量模型。

## 2. 保序证明与周期序列

### 2.1 单段流映射保序

令 `Φτ(a)` 表示从初态 a 出发的状态。若 `a≤b`，两条连续轨迹不能先分离后交叉：若首次相遇，则从相遇状态开始前向唯一解相同，之后不能重新交换顺序。因此

\[
a\le b\quad\Rightarrow\quad \Phi_\tau(a)\le\Phi_\tau(b).
\]

这里只需要弱保序。吸收边界可使不同轨迹在有限时刻合并，所以不能总声称严格保序或流映射可逆。多个相位、固定的保序边界操作、重复的非自治驱动，其映射复合仍保序。

### 2.2 一周期映射使入口状态单调

令 `P=ΦT`，第 n 圈入口状态为 xn，则 `x_(n+1)=P(xn)`。

- 如果 `x1≥x0`，则 `x2=P(x1)≥P(x0)=x1`；归纳得整段 xn 非减。
- 如果 `x1≤x0`，同理整段 xn 非增。
- 如果 `x1=x0`，此初态已是周期入口固定点，随后入口状态不再改变。

不需要 P 是收缩映射，也不需要先证明存在稳定周期。这个结论本身只给单调性；轨迹可以趋向边界、停在平台、在所允许状态域内持续漂移，不能由此直接断言已收敛。

### 2.3 每个固定相位节点同序

第 n 圈节点 c 的状态是 `x_(n,c)=Φ_c(xn)`。由于每个 `Φ_c` 保序，所有节点状态与入口序列具有相同排序方向。若材料/端口电流幅值对 x 非增，则电流方向与状态方向相反；如果对 x 非减，则方向相同。

对于当前 u 坐标，**整个连续段的所有固定节点电流幅值共享一个方向**。限流或饱和可以产生相等值，但不能造成真正的方向反转。因此同一 LRS 低压节点反复上下变化，或两条循环曲线在不同节点表现出相反电流排序，均可能构成这个模型类的判别证据；必须先评估误差容许范围及协议假设。

比较应固定原始索引和扫描分支。不能把同电压的外扫点与回扫点混用，也不能把正负读点的幅值直接相减后解释成同一状态；应在每个固定节点分别比较跨圈次序。

## 3. 外部晶体管、仪器反馈与边界是否破坏结论

### 固定且无记忆的负反馈负载

以某一极性的正幅值变量为例，设材料电流 `i=f(v,u)` 满足 `f_u≤0`、`f_v≥0`，串联负载压降 `r(i)` 单调非减，总幅值 a 固定：

\[
i=f(a-r(i),u),\qquad
\frac{\partial i}{\partial u}
=\frac{f_u}{1+f_v r'(i)}\le0.
\]

只要负载解唯一且稳定采用同一静态支路，这种反馈会削弱电流对状态的敏感度，但不会反转排序。理想固定限流给出 `i=min(f(a,u),Icc)`，也保留弱单调性。正负极性可以具有不同的固定晶体管支路；各自的单调映射须核实，不必要求两支路相同。

“有负反馈”四个字本身不是充分条件。若负载多稳态、出现非单调的端口映射、支路选择有历史、栅压随圈次变化，或仪器的积分器/限流锁存/RC 动态带来额外状态，上述标量闭合假设可能失效。固定外部电路参数也不等于外部电路没有动力学状态。

### 吸收边界与协议切换

当前 SET 的 u=0 吸收边界会使映射非严格保序，RESET 相位随后可按同一规则离开边界；两相复合仍保序。数值域保护（例如 `state_limit`）不能被当作真实器件吸收边界。人工非保序重置映射不受本定理保护，必须明确作为额外模型假设，而不能以“边界处理”名义隐藏。

固定、即时、单值的状态反馈若仍使方程闭合成唯一解的标量 ODE，也不破坏保序。相反，状态触发的事件若改变所比较的采样时刻、协议分支或结束规则，需重新证明相应事件映射保序，不能直接套用固定节点结论。

## 4. 等待、噪声与其他例外

| 情况 | 对结论的影响 |
|---|---|
| 非自治驱动，但每圈完整协议完全相同 | 不构成例外；同一个 P 仍然保序 |
| 每圈有相同的确定性等待，状态仍是唯一标量 | 等待流并入 P，仍保序；不要求等待动力学与扫描动力学相同 |
| 真实等待时长/扫速在不同圈变化 | 周期映射可能变为 Pn；一系列不同的保序映射不保证单条迭代序列单调 |
| 当前路径时钟模型下仅在精确零偏压等待 | 当前 I=0 时导数为零且路径不增长；仅增加等待时长不能在这个固定模型内制造反转 |
| 未知的真实零偏压松弛与变化的等待 | 属于新增时间协议/动力学条件；没有测量不能据反转反推出松弛率 |
| 测量噪声、零点偏置或重复性波动 | 观测序列可反转，即使潜在预测单调；需用误差带敏感性量化，不能把每个微小逆序当物理否决 |
| 标量随机动力学或随机驱动 | 单条实验样本可上下变化；不能据此必然推出至少两个内部状态 |
| 非单调读出 | 状态仍可单调，但电流可反转；本报告排除范围要求读出单调，不能外推到全部标量模型 |
| 非唯一解、非保序混合重置、额外隐藏状态 | 超出本定理假设；若采用，须单独给物理依据，不能仅为通过检验而添加 |
| 数值解出现反复反转 | 先排查步长、事件及代数根切换；精确保序定理不保证粗数值算法自动保序 |

固定的正比例电流校准不会改变跨圈排序。调整固定 Ron 或其他保持读出单调性的共同参数，也不能改变上述序性质；它们仍可能修复电流绝对尺度等其他问题，因此不能把本判据称作全部误差的原因。

### 6.0 实际脚本采用的约定与另一合法约定

**实际 `scalar_cycle_order_audit.py` 采用线性对称相对带**

\[
L_n=y_n(1-\delta),\qquad U_n=y_n(1+\delta),
\quad \delta\in\{0.05,0.10,0.20\}.
\]

因此两个中心值的严格区间分离阈值为 `(1+δ)/(1−δ)`，三个设置分别为 **1.105263…、1.222222…、1.5**。设某一方向最不利的逆序比为 R≥1，则最小所需相对带为

\[
\delta_{\min}=\frac{R-1}{R+1}.
\]

脚本 `band_requirement()` 正是逐点对计算这个量，`interval_check()` 用实际 `(1±δ)` 区间做可行性检查。以下保留初始理论稿的**对称乘性带**推导，以便区别两种常用定义；其中 f=1.05/1.10/1.20 **不是**实际脚本 δ=5%/10%/20% 的区间，不能把两套阈值或最小百分数混用。

记同一节点的正电流幅值为 yn。另一合法但不同的对称乘性带是

\[
L_n=y_n/f,\quad U_n=f y_n,\qquad
f\in\{1.05,1.10,1.20\}.
\]

两种带都是**敏感性设定，不是测量误差置信区间**。实际报告中的数值若来自当前脚本，应按本节开头的线性相对带解释。

### 6.1 存在性判据

存在非减序列 `zn∈[Ln,Un]` 的充要条件是

\[
\max_{i\le j}L_i\le U_j\quad\text{对每个 }j.
\]

可从 `z1=L1` 开始，依次设 `zj=max(Lj,z_(j-1))`；若超过 Uj，则返回造成冲突的 i、j。非增方向对偶：

\[
\min_{i\le j}U_i\ge L_j\quad\text{对每个 }j.
\]

每段必须同时检查两种方向；只排除上升而允许下降，不是对模型类的排除。两种方向都失败，才表示该节点在给定容差内不能来自单调循环输出。

若检查多个节点，各节点允许的方向集合还须有公共元素。例如一个节点只允许上升，另一个只允许下降，即使每个节点单独单调，也不能通过当前同向单调读出的共同段检验。

### 6.2 见证与最小容差

对于对称乘性带，在同一节点、同一段内，`yi>f² yj`（i<j）是非减方向的反例；`yj>f² yi` 是非增方向的反例。三个 f 设置的分离比阈值分别为 **1.1025、1.21、1.44**。实际脚本的线性相对带改用第 6.0 节的比值阈值。不能用仅相差 5% 的两个中心值就声称两个各有 5% 允许变化的读点已经严格排序。

可报告明显峰/谷的三个原标签，也可分别报告否决上升和下降的两个点对；两组见证不必相邻或构成同一个三点极值。保留原始索引、中心值、带端点、段号和扫描分支，不能用标签重新排序消除反转。

对单个节点可直接给出使某方向可行的最小公共乘性因子：

\[
f_\uparrow=\sqrt{\max(1,\max_{i<j}y_i/y_j)},\qquad
f_\downarrow=\sqrt{\max(1,\max_{i<j}y_j/y_i)}.
\]

多个节点共享方向时，先对节点取各方向因子的最大值，再在两种方向中取较小值。`fmin−1` 只是让区间单调性不再冲突所需的最小敏感性幅度，不是仪器噪声估计或真实模型最小拟合误差。

## 7. 保持原评分权重的 isotonic 乐观代价下界

在原始有效 mask 上，记 `yn,c=log10|I_(n,c)|`，每个观测的原残差权重为

\[
w_{n,c}=\frac1{N_g m_g},
\]

其中 Ng 是该观测所属**原完整训练评分组**的有效点数，mg 是该相位评分组数（裸 SET 为 3，单组相位为 1）。裸 SET 的 limited/nonlimited 归属保持由原观测决定；同一个节点跨圈可能有不同组别，因此其权重也可能不同。不能按节点、连续段或新模型预测重新计算 Ng 或分组。

对每个连续段 S 和一个共同电流方向 d，对各个原生节点分别做加权 isotonic 最小二乘：

\[
C_{S,d}=\frac12\sum_c\min_{z_{n,c}\,\text{按 }d\text{ 排序}}
\sum_{n\in S\cap M_c}w_{n,c}(z_{n,c}-y_{n,c})^2.
\]

两相位/全部节点在这个段内必须使用相同 d。最终必要下界为

\[
C_{\rm lower}=\sum_S\min\{C_{S,\uparrow},C_{S,\downarrow}\}.
\]

这个下界允许每个节点独立选取预测序列，放松了共同标量状态、节点之间动力学、读出绝对值与电路等条件；因此它是乐观下界，通常达不到真实可实现模型的精度。原 mask 外的观测不计入时也只是进一步放松，仍可形成合法下界。

实现注意：

- PAV 使用逐点原权重；不能对每个节点等权或把每个段重新归一化。
- 保留原目标的 `1/2` 因子；报告 phase/group RMSE 时按原定义转换，不能把加权总 cost 当作单一普通 RMSE。
- 非增方向可对 log 电流取负后求非减 isotonic，再取回负号；应在记录顺序中操作，不能对观测值排序。
- 段方向应对两个相位和全部节点的代价求和后共同选取；逐节点挑最优方向会变成更弱的下界，不能再称为使用了共同循环方向约束。
- 不能减去旧“所有圈共用一条预测”时的跨圈 scatter 常数；isotonic 已允许逐圈不同预测。
- 当前电流上界、共同状态读出及实际动力学还可能造成额外误差；该 floor 不是完整的不可约误差分解。

若这个乐观下界已经超过预先声明的允许预算，则所有满足本报告假设的模型都不能达到该预算；如果低于预算，不能据此认为真实模型可以做到。任意非零 floor 也不自动否决一个有用的近似模型。

## 8. 这个审核能决定什么

若训练数据的反转在合理范围的敏感性设置下持续存在，或保序类的乐观代价下界已明显高于目标，那么继续搜索固定 Ron、阈值和速率无法消除那部分结构矛盾。下一步应先辨别同协议假设、噪声/随机性、状态与读出闭合条件，而不是仅扩大参数范围。

本报告没有选定新机制，也没有证明必须引入第二个状态：时序变化、随机标量过程或非单调读出都是逻辑上的不同逃逸条件，各自需要独立证据。反转很小、与测量重复性相当时，保留确定性单状态模型作为平均行为近似也可能合理。最终判断应同时报告违反假设所需的偏差大小与全曲线误差，不能仅用“通过/失败”掩盖量级。
