# 同方程分组存在性：本轮试验边界

本轮不把分别拟合称为最终统一模型，也不默认不同器件一定需要不同参数。
先用原训练数据、固定谱、beta=1、A_RESET=0 检查组内是否存在可用轨迹。

1. 分组适配器沿用原目标的掩码和权重。1R取原5,583维残差，1T1R取21,440维；
   未选组不模拟、不输出误差。适配器的10项合成验证已完成，真实轨迹尚待下项。
2. 裸组入口先检查聚合区间、外扫到达限流、低阻读态、RESET尾态以及峰值/峰位。
   推荐的6参数起点来自 `BARE_ENTRY_REVIEW.md`，只是必要条件相容。
3. 先只对该点执行一次完整裸SET/RESET，不优化、不替换旧基线。沿用原积分
   精度与加密检查，报告全部7项裸主特征及原始记录误差；必要条件过关不能
   代替真实峰位、尾态和跃迁位置的检查。
4. series单组入口的19个既有gamma_c点未找到SET速率相容区间。先对每个点
   做有界的一维阈值连续复核和独立不等式审核，不启动已无入口的昂贵拟合。
   若冲突保持，参数分组就不能单独修复当前固定方程。

仅限既定算法参数域；算法边界不是物理先验。只用训练4–35与原14条裸记录，
不读留出数值。series保持cycle4一次初态和连续历史；裸无已知跨记录时序。
扫描设置和forming/cycling身份仍未知。本轮没有规划外发、推送或默认模型更改。
