# 1T1R 入口必要界：独立审核

2026-11-03。只读审核 `series_entry_review.py`、`SERIES_ENTRY_REVIEW.json/.md`、
旧端点预算与晶体管实现；没有新扫描、谱计算或 ODE。审核时脚本与 JSON 哈希一致
（`8d2982705dd3b8590c5f8cf3544bc7843b4f53a21cbdebb303a5e0b9cf6e9008`）。

**主要 SET 速率比较在其声明的端点条件下方向正确，不必假定 0→0.2 V 冻结
才能解释为必要界。但应把观测锚与真正 0 V 初态分开。另发现重启充分条件的
连续状态下界未被当前节点取最小值认证；RESET 相容计数也需区分无穷上界。**

## 1. 0.2 V 观测锚不是自动已知的 0 V 初态

原精确反演值 `g_anchor=2.617950369e−6 eV` 来自第 4 圈 SET **外扫0.2 V**，
而不是原始 0 V 状态测量。令 `u_anchor=ln(1+gamma_c/g_anchor)`。单向 SET
只保证更早的真实初态 `u(0)≥u_anchor`，不能无条件令二者相等。

不过，现有必要界可以合法地从已知 0.2 V 状态出发解释：

- 已知到 2 V 必须有更多闭合，即 `u(2 V)≤u_2,max<u_anchor`。
- 若 `JS≥I_terminal(2 V,g_anchor) exp(u_anchor)`，那么在整个 0.2→2 V
  区间，固定该状态的电流随命令电压不减，但归一化驱动始终不超过 JS。
  正部状态律在该状态的导数为零；局部唯一流使它不能自行离开冻结态。
  因此要到达目标状态，JS 必须低于代码的 `activation_max`。
- 代码将从 `u_anchor` 到 `u_2,max` 的路程分配 **2 V**，而实际只有
  **1.8 V**。这是对可行性更宽松的路径预算，因此由它得到的下界仍合法。

这个解释不依赖更早 0→0.2 V 的状态是否演化，也不需要对更早未知 Γ 的
归一化驱动取最大值。建议将该变量称为 `u_anchor_at_0p2V`，不要把必要界
解释成已经观测了 0 V 初态。

若以后实际 seed 要把 `u_anchor` 直接设置为 0 V 初态，则必须另外满足

\[
 J_S>I_{\rm terminal}(0.2\ \mathrm V,g_{\rm anchor})e^{u_{\rm anchor}}.
\]

该条件足以保证 0→0.2 V 冻结；代码 `tail_sok` 已加入它，但主 SET 统计
没有先用它筛阈值。当前 seed 数为零，所以没有发出违反这一初态条件的 seed。
把主比较理解为“从观测锚出发的放宽必要界”即可避免误用。

## 2. 2 V 电流上界与外扫状态落差

当前 T lookup 由累计最大值构造成单调曲线，固定 gate 的插值保留单调性。
正向被动串联电路满足 `0≤VT≤Vcommand≤2 V`，所以

\[
 I\le I_T(2\ \mathrm V,1.1\ \mathrm V)
 =58.77722142\ \mu\mathrm A=:I_{\max,2}.
\]

这不是把全部 2 V 施加给 h-BN，而是在去掉材料压降时得到有利于快速 SET
的电流上界；当前映射和准静态串联条件仍是显式前提。

外扫 2 V 的目标取扩张后的聚合电流下界，对应
`Γ_target≥0.002466837971 eV`，故 `u(2 V)≤u_2,max`。令
`c=ln(Imax,2/JS)`，它允许为负。只要 `u_2,max+c>0`，正部比较给

\[
 k_S\ge\frac12\ln\frac{u_{\rm anchor}+c}{u_{2,\max}+c}.
\]

若 `u_2,max+c≤0`，则目标位于不可从上方越过的停止界之下，记无穷下界正确。
`JS≤Imax,2 exp(u_2,max)` 的上限正是这个必要条件；其余实际初态激活上限
与原算法盒上限的取小值也没有改变方向。

## 3. 5→2 V 返扫上界的端点来源

实际使用的是**旧的非对称放宽条件**：5 V 端用 Q10/1.05，而 2 V 端仍用
原 Q90，没有再乘 1.05。不能把本次新保存的 `set_return_2.gamma_band_ev`
误认为进入了主速率计算，也不能称该界同时给予两个端点完整 5% 放宽。

条件为 `Γ5≥g5,min`、`Γ2≤g2,max`。在一条满足这两个端点的单向 SET 返扫
上，`Γ` 始终不小于 g5,min，且 `u` 始终不小于 `u2,min`。缓存电流下界和
该状态下界共同给驱动下界；最大允许状态落差
`u5,max−u2,min` 除以正部左积分，给 kS 上界。该方向正确。

端点界来自训练聚合分位数，不能一般性声称分位数本身组成同一实测轨迹。
但这里第 4 圈实际数据同时落在相关条件内：外扫2 V为27.418 µA，返扫5 V为
50.970 µA，返扫2 V为29.778 µA；后者小于所用原Q90的30.2394 µA。
所以“第4圈0.2 V锚＋同圈能满足的放宽端点预算”的条件比较并非跨 cell 拼接。
它仍不是要求32圈每条实际轨迹都位于公共Q10–Q90，不能替代完整训练评分。

连续 JS 域的保守比值公式方向正确，但在 gamma_c=0.03、0.05 等行，该下界
低于1；这些行的失败证据仍只来自声明的有限阈值网格。没有对连续 gamma_c、
自由初态带或整个可拟合误差范围的全域排除。

## 4. 需修正的重启下界与计数口径

**重启采样最小值不是连续状态带的下界。** 当前

```text
restart_J_min = min[I_terminal(5 V,gamma_node)*(1+gamma_c/gamma_node)]
```

只取65个节点。电流随 Γ 增加、第二因子随 Γ 减少，乘积的内部最小值不能
由节点最小值保证。将 `JS<restart_J_min` 称为对整个 HRS 带均可重启的充分
条件，缺少证明。应使用每片的

\[
 I_{\rm terminal}(5\ \mathrm V,g_{\rm lo})
 (1+\gamma_c/g_{\rm hi})
\]

再取最小值，或独立证明该区间的乘积单调。该值只用于后续seed筛选；目前
没有seed，主要SET无交集结果不受影响。

两个0.2→0尾段的 `J_upper` 已正确采用反向单调因子的分片上端组合。
若阈值严格高于这个上界，整段保持冻结的充分条件成立；否则不能把读出状态
直接搬到真实相位边界。RESET的跨读带预算只能保留这一条件解释。

**RESET计数须区分物理上界无穷。** 当前 `rok` 将 `rup` 与算法上限31.6228
取小值后计数，可能包含原必要上界无穷的情景。因此表中180/181等数值应叫
“工作盒内必要区间相容数”，并单列有限预算上界与欠约束上界；不能称为已获得
有限物理上界或已验证RESET。有限下界配无穷上界既不是失败，也不是拟合成功。

## 5. 当前可保留的结论

在固定谱、当前 T 映射、所用第4圈0.2 V锚及上述聚合端点预算下，所列离散
gamma_c/有限JS网格没有SET入口种子。它是单组条件诊断，不能直接替代具有
自由初态和真实连续32圈轨迹的拟合结论。初态表述、非对称端点放宽、重启
下界认证及无穷上界分类应修正后再据此选择任何后续seed。

缓存双线性插值、端口二分和已有历史精度检查没有变成新的区间算术认证；
本次不重新认证谱值误差，也没有重跑筛选。
