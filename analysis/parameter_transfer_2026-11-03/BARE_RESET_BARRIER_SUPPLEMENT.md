# Bare RESET 路径屏障：旧五个候选的补充检查

2026-11-03。保留原 `BARE_ENTRY_REVIEW.md` 和 `bare_entry_budget_audit.json`，
本篇补上原速率预算未能识别的**路径不可达性**。只读取已有谱缓存与旧候选，
不计算新谱、不积分状态、不扫描参数、不优化，也不读取保留集。

**在冻结数值缓存模型内，旧五个候选中两个存在 RESET 状态屏障，另外三个未被该必要界否决。
原推荐候选属于被否决者，因此其 RESET 尾电流偏高不能靠增大 kR 修复。**
这不等于 A0 家族整体失败，也不等于其余三个已经通过真实轨迹检查。

## 1. 为什么仅看速率预算还不够

固定 beta=1、A_RESET=0 时，RESET 律为

\[
\frac{du}{d\ell}=k_R\,[\ln(|F(-|V|,u)|/J_R)+u]_+,
\qquad \Gamma(u)=\frac{\gamma_c}{e^u-1}.
\]

低阻读出约束要求初态 `Gamma >= 1.782940844 eV`；末端0.2 V的电流上界
`0.477002757 nA` 则给出宽松目标 `Gamma <= 3.981071706e-6 eV`。
因此任何连续且单向增大的 RESET 状态都必须穿过二者之间的状态。

若某个必经内点 `u_b` 满足

\[
J_R\ge |F(-V_{\max},u_b)|e^{u_b},
\]

电流对负电压幅值的单调性保证：整个扫描中，在该状态的驱动都不大于零。
正部状态律和局部唯一性使它成为不可穿过的屏障。调高有限 `kR`、延长同一
电压范围内的路径都不能跨过去。必要条件是

\[
J_R<\inf_{u_{\mathrm{read}}<u<u_H}|F(-V_{\max},u)|e^u.
\]

原分片速率预算用一个单元内较大的电流乘以较大的 `exp(u)`，其组合可以
高估实际同一状态的驱动；这样的宽松时间下界仍合法，却可能漏掉冻结屏障。
因此“必要速率区间有交集”从来不等于“该状态轨迹可达”。

## 2. 计算方向与结果

实际最大负电压幅值为 `2.5 V`。这里取更高的已有缓存节点
`2.5061199855 V`，并在必须经过的 Gamma 开区间内取56个已有节点。
每个节点的 `I(Vupper,Gamma)*(1+gamma_c/Gamma)` 都是该状态最大驱动阈值
的上界；再取这56个上界的最小值，仍是整个连续状态路径阈值最小值的
**宽松上界**。因此用它否决候选方向正确，未被否决不能反推可达。

| gamma_c (eV) | 旧 JR (mA) | 必要 JR 上界 (mA) | JR/上界 | 判断 |
|---:|---:|---:|---:|---|
| 0.1258925412 | 1.359356391 | 1.277927314 | 1.063720 | 存在屏障，否决 |
| 0.1412537545 | 1.467799268 | 1.433851822 | 1.023676 | 存在屏障，否决 |
| 0.1584893192 | 1.467799268 | 1.608801998 | 0.912355 | 未否决，未验证 |
| 0.1778279410 | 1.467799268 | 1.805099323 | 0.813140 | 未否决，未验证 |
| 0.1995262315 | 1.359356391 | 2.025348545 | 0.671172 | 未否决，未验证 |

前两个候选最先遇到的缓存模型内屏障分别位于
`Gamma = 0.00794328235 eV` 和 `0.00316227766 eV`。再用低于0.2 V的
缓存电压节点求读出电流下界，分别得到 `1.505625 µA` 和 `0.525303 µA`，
已是目标上界的3156倍和1101倍。它们不只是“尾部不够快”，而是这组固定
`gamma_c, JR` 根本无法抵达所需高阻态。

原推荐候选的真实前向报告 `bare_entry_forward.json` 得到尾电流
`5.551878 µA`，与上述更宽松的 `1.505625 µA` 下界相容；该前向值不是本篇
重新模拟的结果。

保留后面三个已有候选，先逐一完成同一套7项真实 bare SET/RESET 检查；
本篇不新建起点、不扩大搜索域，也不推荐对已否决的前两个启动优化。
候选完整六维坐标保存在旧 JSON 的 `cases[*].candidate.bare_six_coordinates`。
本次逐候选判断保存在 `bare_reset_barrier_audit.json`。

该结论有明确前提：固定谱、beta1 A0 状态律、单向连续 RESET、现有共同
读出/尾部聚合预算与既定电压幅值。共同分位数预算不代表每条记录都满足，
也不建立不同实测记录间的物理配对。缓存谱有既有数值误差，本次没有重新
认证积分误差或将浮点缓存变成区间算术。

只否决上述两个固定参数候选；没有排除其他 JR，也没有全域排除 A0。
对相同 `gamma_c,JR`，A>0项会进一步减少驱动，因此不能解救这两个原样候选；
但允许 JR 等参数同时变化的 A>0 家族不在本次排除范围内。
