# 固定 m=2 的跨极性连续历史试验

上一轮为实际进展：完成固定 m=2 的条件 SET 拟合、数值复核和固定匹配 m=1 的必要误差界限。当前完整 1R/1T1R 目标仍未实现。本轮离开孤立 SET 校准，检验最短连续历史 **保存的 SET4 末态 → RESET4 → SET5**。旧阶段已冻结，新产物仅写入本目录。

## 固定方程和唯一新参数

冻结上一轮 λ、J+、κ+、Ron、Γc、谱形状、晶体管映射和 m=2，不调回已知正向参数；a=0。输入为实际局部 Vh、i=|I|，v=|Vh|，σ=sign(Vh)，s为累计命令电压路径。统一表达式为

`q'=κq v[(i/J0)exp(σb)(1−q)−exp(−σb+λv)q²]`，

`κq=κ+exp(b)`、`J0=J+exp(2b)`、`q=exp(−u)`。

它在正电压下严格保持已校准方程，在负电压下给出

`u'=κ+v[exp(2b+λv−u)−(i/J+)exp(−2b)expm1(u)]`。

唯一新增连续校准量为 b，有限探索域 **[0, ln(10)]**。该范围及正负向共用方程都是可拒绝假设，不是实验置信界或已知微观反应。b不得按周期、扫向或拓扑改变。场符号取自实际 Vh，正场返扫不翻转极性；材料必须使用既有真正的负场谱，反向晶体管保持测得的0–2 V电压域。

## 数据与状态

只读取已验证的 SET4 参考轨迹、原训练内 RESET4 和 SET5 数据。RESET4固定从保存 SET4 的返零末态 `u=3.655082141628295` 开始，不通过 RESET 首点反演入口。SET5入口必须直接采用对应 RESET4 的模拟末态；不得使用 SET5 的0.2 V条件锚或校准新的初态。

所有原生点、重复顶点和零端点保留。评分沿用原阈值：SET为1e−11 A、RESET为1e−12 A，且|V|>1e−12，使用有限原电流的幅值；不裁低流或扣除散布。只有RESET4误差用于选择b。SET5是本次拟合未使用的跨圈检查，但它属于原训练集，不称为原保留集或独立实验。

没有扫描或等待时间信息，不补造秒钟。重复零端点不创造额外路径时间；本试验没有建模未记录的间隔演化。裸器件缺失4/23圈和其原训练段、原27023维联合残差以及20项聚合合同保持不变；本轮尚不运行裸器件或聚合合同。

## 数值前置检查

1. 核对本轮实际使用的冻结源、最终参数、两条训练数据和新代码哈希。禁止重新读取全部无关历史轨迹来替代本轮检查。
2. 固定12个静态电路点：`u∈{保存SET4末态, 原0.2V锚,25}`，`command∈{+0.2,+5,−0.02,−2} V`。对比新fast、新严格42次二分与既有独立负/正谱参考。门槛：电流差≤5e−7 decade、局部电压差≤1e−9 V、KCL≤1e−13 A。只选择通过的电路实现；都不通过则停止ODE部分并保留失败。
3. 在这些已求解点做 b=0、ln(10) 的RHS代数检查：正向不变，负向±2b映射正确。没有额外求根或ODE。
4. 一次固定参数的正向回归：从保存SET4的 `derived_initial_u` 出发，使用新通用相位核，以加密精度跑完整原SET4。与冻结加密原生电流和状态比较，最大差须≤1e−4 decade、≤1e−3 u。不能以新0.2 V锚修复结果；这是新适配器的验证，不是重做旧拟合。失败则停止b校准。

近零只允许继承并正确变换的局部遗漏界。负场单个0↔δ微段上界为

`(κ+ δ²/2)[exp(2b+λδ)+πΓc exp(−2b)/(Ron J+)]`。

该界必须≤1e−12且状态合法。若命令已在表域内而实际局部电压低于表分辨率，仍报告分辨率失败；不得夹电压、状态或外推电流。零场冻结不代表解释了实验保持时间。

## 有限校准与停止规则

- **总计最多20次RESET4搜索目标调用**：先b=0和b=ln(10)各一次，再唯一一次bounded一维优化，最多18次调用，`xatol=1e−4`。从所有完成的搜索调用中选择原RESET4评分MSE最低者；不重新启动、不扩b域、不借SET5选择参数。
- 搜索积分精度：rtol=2e−6、atol=2e−7、max_step=0.04 V。每条RESET搜索轨迹最多12 s，搜索部分最多120 s。任何轨迹超时立即结束整个搜索，不继续收集候选；已有完整最优者可进入预留验证。
- 本轮数值计算总预算240 s，计时从输入加载/哈希/计划保存之后开始，包含电路前置、正向回归、搜索和最终验证。文件I/O等待另行记录，不称为模型计算失败。
- 最终同一b做两套RESET4→SET5完整连续验证：nominal=(1e−7,1e−8,0.02 V)，refined=(1e−8,1e−9,0.01 V)。每个相位最多30 s。每套RESET都从同一保存SET4末态开始，其实际末态接同套SET5。两精度不重新选b。
- 最多25个相位ODE尝试：1个固定SET4回归、20个RESET搜索、4个最终相位。若失败可少于此数，不能自动补跑。每条完整相位按原真实波形包含外扫/返扫段，失败时保留已完成段和最后RHS。
- 数值域、分辨率或求解失败返回无有限评分并保留数组；搜索目标可记为正无穷，但序列化不可伪造成有效有限残差。若没有完成候选，停止并报告未定，不改模型救火。

## 最终核验与报告

两精度分别比较RESET4和SET5全部原评分点：最大log电流差≤1e−4 decade，最大u差≤1e−3；相位衔接误差≤1e−12，原生/RHS KCL≤1e−13 A。最终原生点再做独立legacy求根对比，门槛沿用5e−7 decade/1e−9 V。检查电流符号、被动性、状态域和全部点数。

分别给出RESET4校准误差、SET5跨圈误差、外/返扫与低压误差、RESET峰位置/幅度与原返扫0.2 V尾读点、SET启动及返回形状。原20主特征是训练群体中位数合同，单圈参考不得被称为聚合通过。优化停止标志、边界最优、数值失败和全部参数请求均保留。

如跨圈失败，区分有限b域/固定读出与协议假设下的失配、数值未定和普遍物理结论；不自动排除所有统一模型。若成功，下一步才扩展到已知完整历史及裸器件所需通道，并继续沿用同一状态定义和材料方程。完整目标始终为统一解释两种接法及降低原口径误差，而非让本轮单一检查好看。
