# 保留电荷—构型：数值与拟合执行约定

补充已归档的 `RETAINED_CHARGE_CONFIGURATION_DESIGN_2026-09-21.md`，不修改旧阶段
证据身份。实现只消去导电电子 n，每个能谱通道保留 P(q,m) 四态；沿用前一
候选的九个坐标（前八个是旧构型参数，第九个是 ln(Gamma_t/扫描速率)，范围
[-40,20]，单位参照 V^-1）。旁侧电荷主初态是 q=0 下的零偏热平衡边缘分布。

为快速处理刚性转移，四态生成矩阵用正项均匀化及随机矩阵平方计算指数。
电压表上预计算实际子步长度的半步/整步传播矩阵，电压间作凸组合。子步长度
按12位有效数字归类并报告相对舍入，不能把不同扫描长度强行当成相同。
插值的是传播矩阵，不是其对数速率；因此必须同时加密电压表、子步与能谱。
复用旧的冻结负载求解器而不改写它，缓存身份同时包含新源和旧求解器源。

默认主网格为64能量节点、0.005 V电压表及0.01 V路径子步。先对声明起点作
加密，再拟合；所有选中解至少检查128/192节点及电压/路径步长连续减半。
容许最大预测变化0.005 decade、加权变化0.001；不通过就保留失败并改进计算，
不能仅放松数值门槛。另有独立四态矩阵指数、完整八态极限和自适应ODE/电路
参照。准静态读出仍忽略慢电荷重分布的高阶端口瞬态，绝对时标分离未实测。

先比较 lambda=0 与 lambda>=0 两种鞍点，各作全53共同描述与前35→后18预测。
保持已归档的八窗评分与全部低信号标记。每个划分只使用匹配训练集的输运
基线和旧构型解。固定五个起点：匹配旧解分别配 ln旁侧率=-3、0、6；另两个
固定物理起点改变构型能级排序，不依据目标RESET求初态。优化上限180次主
评估，线性对数电流残差；所有实际调用数、边界和未收敛起点保留。必要时只
在相同训练集内对嵌套鞍点作交叉初始化，不以优化器局部解宣称物理优势。

成败重点是 R3→R4、S3/S4、进入重复轨迹的速度以及前35→后18预测，不能仅
看平均拟合误差。新的快速旁侧极限对应旧 Gamma_t/Gamma_R→0 候选，必须按
正确时标顺序比较。若拟合选择极快旁侧率，意味着本轮没有从数据支持旁侧
电荷保留；若选择慢率，也仍需辨识性与完整曲线支持，不能等同微观物种鉴定。
