## 两个候选分别缺什么

下表均为 refined 保存曲线重新算得的原评分点 RMSE：

| 数据块 | 禁用 a | 开启 a |
|---|---:|---:|
| 1r_set | 2.00996112 | 2.65737207 |
| 1r_reset | 2.07759533 | 3.98227911 |
| 1t1r_set | 0.40181646 | 1.27651051 |
| 1t1r_reset | 0.58409580 | 2.47495740 |

禁用 a 的四个通过项均是串联轨迹形状：SET 返扫 1–2 V 和 2–4 V 指数、RESET 外扫 1–1.4 V 指数和平台跨度。它未复现裸器件低阻态：裸 RESET 峰中位仅 1.0434 µA，峰压在 2.5 V 端点；裸 SET 返扫低压电阻约 0.889 MΩ，裸 RESET 低压电阻约 1.017 MΩ。全部 14 条裸 SET 都没有达到 0.995 mA，阈值特征明确 undefined，未编造跨越电压或删掉记录。

开启 a 新通过了裸 RESET 峰电流、峰压和两个裸低阻读数；共同通过的是串联 SET 2–4 V 指数。与此同时，它丢失了另外三个串联形状门，并在裸 SET 早启动、RESET 关断及串联电流水平上出现更大误差。因此从 4/20 到 5/20 不代表整体拟合改善；这个固定种子的 cost 和全点误差均更大。

这次完整对照给出的事实是：旧标量参数在裸低阻幅值上不足，而这一额外通道种子在补出大电流后未能恰当恢复高阻态。没有执行拟合，不能据此否决双状态模型的整个参数空间，也不能宣布统一物理解释完成。
