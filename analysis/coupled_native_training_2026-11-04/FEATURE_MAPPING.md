# 原 20 项特征约束的全训练集映射

`feature_audit.py` 只做已生成预测的算术后处理，不读取原始数据压缩包、不调用材料或求解器。原定义与区间来自 `analysis/constrained_shared_2026-11-03/feature_constraints.py/.json`；不改动这两个旧文件。

## 固定统计口径

- 输入必须恰好是裸 1R 的 1–3、5–15 共 14 个编号，以及 1T1R 的 4–35 共 32 个编号，每编号 SET/RESET，共 46 对、92 条原生曲线。
- 每条预测与同编号实测一一对应。先分别提取记录特征，再取**普通中位数**，绝不先平均曲线或用一条周期稳态曲线代替。
- 全部 20 项共 514 个原先有效的逐记录特征。原始观测的有效集合固定；模型不能通过低于 floor、没有跨越阈值等原因排除困难记录。
- 通常要求模型中位数进入固定经验 Q10–Q90；RESET 平台 log-current 跨度只要求在 [0,Q90]。逐项保留失败、实测全范围、模型中位数、每记录预测值。全局 RMSE 不能抵消失败特征。
- 模型没有达到 0.995 mA 阈值等情形标为 undefined 并使该项失败，不编造电压、不插值、不返回优化惩罚值。输入波形错误和非有限算术是执行问题，不能伪装成物理否决。

## 特征与原生索引

| 类型 | 数目 | 映射 |
|---|---:|---|
| 端口电流读数 | 7 | 复用原定义的记录内 native_index，并核对电压与分支 |
| 轨迹端点指数 | 4 | 复用原两个 native indices，计算 log(Ib/Ia)/log(abs(Vb/Va)) |
| RESET 1–1.4 V 平台均值与跨度 | 2 | 每条外扫原生窗口的电流几何均值和 log10 电流 Q90–Q10 |
| 两接法 RESET 峰电流及峰压 | 4 | 每条模型外扫独立 argmax，保留端点峰，不能沿用观测峰位置 |
| 裸 SET 0.995 mA 转变中点 | 1 | 每条模型外扫首次达到固定阈值的前后原生电压中点，保留完整括区 |
| 裸 SET 返扫 0.05 V 电阻 | 1 | 原生 0.05 V / 对应电流 |
| 裸 RESET 0.05–0.2 V 电阻 | 1 | 原生外扫过原点 I=G abs(V) 拟合，R=sum(V²)/sum(abs(V)I) |

第一次达到最大 abs(V) 的索引属于外扫，其后所有索引属于返扫，重复峰值亦不更换规则。电流使用原存储值/模型值的幅度；这些是轨迹特征，不是固定隐藏状态下的本构导数。

## 关键实测约束

1T1R SET 返扫 I(0.2 V)、I(2 V)、I(4 V) 分别要求 0.542976–1.105368、28.515–30.2394、43.5902–44.4812 µA。返扫 2–4 V 指数区间为 0.5423946–0.6183441，须与低压读数同时满足。

1T1R RESET 外扫 1–1.4 V 平台几何均值为 1.9035004–4.0266783 µA，log10 电流跨度不超过 0.169220175 decade。裸 RESET 峰电流为 3.106175–9.909414 mA，峰压 0.475–0.795 V；裸 SET 转变中点约为 2.59–2.775 V。

## 与评分和历史传播的关系

20 项特征是完整评分后的独立验收项，不改变原 27023 维逐记录评分。原评分按两接法 × 两相位的四块等权；裸 SET 又按非限流外扫、非限流返扫、限流三组等权。每组原始 log10 误差除以 sqrt(n_group × n_groups)，最终 cost=0.5 sum(residual²)，另报原始逐点 RMSE。

用户现已确认同一裸器件连续循环、编号按顺序、同号先 SET 后 RESET；缺失 4、23 圈实际测过但没有数据。原文中关于裸器件身份/顺序未知的 A6 不再作为当前历史假设，数字特征与区间保持原样。本阶段仅在裸 1–3、裸 5–15、串联 4–35 三段内传播 q/a，各段一个入口状态；不虚构缺失圈、不跨裸第 4 圈衔接、不访问保留集。

`audit_observed_contract(problem)` 可在冻结后由根代理的验证运行器调用，纯算术重构 514 项观测特征并核对原值；此处代码编写阶段只做语法与静态审查，未执行该检查。通过这些经验特征不等于独立验证微观机制；经验区间不是置信区间或不可约噪声。
