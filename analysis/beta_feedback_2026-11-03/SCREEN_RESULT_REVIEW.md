# 有限 beta 筛查的结果与边界

预先声明的24情景全部完成，主谱预算计算57.71秒，**无有限联合种子**。
未运行 ODE，未扩大 alpha 或 gamma_c 域，未改旧产物。四个 beta 的谱电流
矩阵只算一次并保存于 `fixed_spectrum_budget_arrays.npz`。

## 主预算结论

每个情景都同时使用同一 beta 的 SET 和 RESET，时钟比例对两极性一致。
JS 上界是实际初态2.8V激活与公共低阻读预算可达性的较小者；beta=1 的
上界已允许超过 Icc，未沿用不适用的 JS<Icc 截断。所有窄括区的 stop barrier
单独检查，没有把对数分母非正当作有限速率。

24情景的 SET 主预算均无交集。最宽容主预算比仍为7.9491，出现在
gamma_c=0.2 eV、beta=1、alpha=50。这个比是所需裸跃迁速率下限除以允许
速率上限，远高于1。RESET 在部分情景有有限必要区间，但不能修复 SET。

RESET 的某些阈值使其宽松裸低读积分为0，即不给速率上限；原始代数比会
显示0，不能误读为“拟合完美”。最终报告已把无限上界阈值另计，只在有限
区间内统计候选。该统计修正完全使用缓存数组，没有第二次谱积分。

## 同记录诊断（独立于主筛的逐条条件）

缓变和骤变的同记录5%条件没有被自动加入全曲线评分。12条方向可行记录的
有限阈值区间均不相容；另6/15号记录原本已有端点方向诊断。放开 beta 确实
降低了一些同记录比值，但没有在本域得到条件可行点。

取声明共同阈值上界 Jmax_beta，令c0=ln(Icc/Jmax_beta)，通式

    ratio ≥ (B−A)/(Δu δ)
            × min[L, (L*c0+D_beta)/(c0+beta*B)]

在L*c0+D_beta>0、c0+beta*B>0时覆盖所有0<JS≤Jmax_beta。分片/左和只会
使该界更宽松。12条记录中最宽容的比值下界为：

| beta | gamma_c=0.2 eV | gamma_c=0.4 eV | gamma_c=1.0 eV |
| ---: | ---: | ---: | ---: |
| 0.25 | 4.5704 | 4.6545 | 4.7108 |
| 0.50 | 3.2663 | 3.3264 | 3.3667 |
| 0.75 | 1.5561 | 1.5848 | 1.6039 |
| 1.00 | 3.5642 | 5.7014 | 7.8050 |

因此，在声明共同 Jmax 条件下，以上同记录诊断不是181个阈值格点漏解。
但公共187.68Ω读预算是Q90条件，**不是每条记录的实测电阻**；例如裸1/11号
实测读值可以高于它。不能把表格包装成没有预算条件的逐条实验排除。

## 下一步限制

同记录路径界需要两段共用常数k_per_commandV。未知整体扫速可被该常数
吸收，未知自适应停留或非匀速不能。真实时间协议和瞬态限流的适用性仍需
独立核查，不能从电压点间距推定。

更改 beta 不破坏同态电压越高 SET 闭合率不减的结构，也不允许正向返扫
Γ 回退，所以此前跨拓扑时间比较与冻结谱Fermi窗口限制仍需保留。
本轮没有证明所有共享模型无解，更没有识别微观机制。按预先计划停止，
不凭无种子结果自动增加 alpha、新谱或其他材料参数。
