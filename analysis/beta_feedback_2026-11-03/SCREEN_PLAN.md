# 有限 beta 反馈必要预算筛：先验计划

本计划先于运行保存。只做必要预算，不运行 ODE、不拟合、不更改 core 或旧产物。

- 固定原谱形、Ron、温度与晶体管映射。
- gamma_c={0.2,0.4,1.0} eV；共同材料 beta={0.25,0.5,0.75,1.0}。
- alpha=r_series/r_bare={20,50}，SET/RESET 共用同一 beta、同一 alpha。
- A_RESET=0。原裸0.2V、series第4圈0.2V初态锚各只用一次；不逐圈重置。
- 复用既有5%高压端点敏感性、1mA理想限流及原有限读点预算，不改主验收门槛。
- JS取181个有限对数点，范围1e-7 A到下列上界的98%：
  min{F(2.8V,gamma_R0)exp(beta*u_R0), Icc*exp(beta*u_L)}。
  若上端≤下端则记有限域为空；JS不硬性截在Icc。
- JR沿用有限网格策略：1e-6 A至soft最大驱动上界的99%，181个对数点，
  加入原bare保守电流最大值的80%至99.9%共121点；只保留正的有限速率区间。

## 检查内容

1. 实际初态2.8V正向激活与低阻目标可达性均查验，不能把正驱动等同达到限流。
2. 裸SET跃迁下界使用
   ln[(c+beta*B)/(c+beta*A)]/(beta*delta)，c=ln(Icc/JS)。若分母≤0且
   B>A，有限路径到达存在stop barrier，不能计算成可行速率。
3. 与series5→2V保守超驱动积分上界相交。主筛只要求14条裸窄括区中最宽容
   的下界，同时保留更强的逐条诊断；2→2.8V到达条件另列。
4. 同记录缓变段使用分片下界F(V,g_lo)*(1+gamma_c/g_hi)^beta。旧文件只保存
   beta1分片最小值，没有完整F矩阵，所以允许一次计算固定谱矩阵并缓存，
   随后所有beta复用。逐条5%条件失败是诊断，不自动升格为完整曲线硬门槛。
5. RESET按同beta计算soft最大I*exp(beta*u)及所需开态落差，bare允许使用
   整个低读状态预算；共同bare参考速率需满足alpha*L_series≤kR≤U_bare。
6. 每个24情景都记录结果和原因。若没有有限主预算种子则停止；不增大alpha、
   gamma_c域或新谱，不用J→0极限作伪种子。

## 解释边界

alpha是假设情景而非测量值。同一记录两段共用常数k_per_commandV，若真实
自适应停留/非匀速协议不同，需要时间戳重算。beta变化不会自动解除同态电压
单调比较，也不会解除固定谱且正向态只增导时的两点Fermi窗口限制。

本轮上限120秒，旧conditional_clock和same_record产物保持不变。预算相容
只说明未被这些必要检查否决，不表示物理机制或完整联合模型已成立。
