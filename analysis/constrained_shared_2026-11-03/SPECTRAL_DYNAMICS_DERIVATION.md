# 谱读出与一状态共享动力学：先检验必要条件

2026-11-03。只作数学推导和训练条件诊断，没有修改生产模型，没有 ODE
拟合。谱读出定义见 [SPECTRAL_READOUT_SCREEN.md](SPECTRAL_READOUT_SCREEN.md)。
下文的“共享”指 1R 和 1T1R 使用同一个带符号材料本构、同一个状态方程及
同一套材料参数；SET/RESET 可有经声明的极性非对称，但不得按接法切换材料。

## 1. 应先检验哪一种“一状态”主张

采用固定共同 `ε,η,w,T,Ron`，状态只改变

\[
 \gamma(u)=\gamma_c/(e^u-1),\qquad i=f_\sigma(v,u),\quad
 v=|V_h|,\ i=|I|,\quad \sigma=\operatorname{sgn}V_h.
\]

κ=0 时 `f_v>0,f_u<0`（有限非零状态/电压），`u=0` 是精确 Ohmic 极限。
因此用同一实际电压比较，较小电流对应较大 u；完整闭合的裸 SET 路径应能
穿越软 SET 的中间态。不能仅凭“裸/串联”标签断言该排序，须用同一读出
反演和已声明初态检验。

给定可信的去嵌入 `(v,i)`、共同谱形和 `0<i<v/Ron`，可先反解唯一 γ。
这一步不需要 γc。选定 γc 后才有 `u=ln(1+γc/γ)`，所以 γ 很小不自动
证明 u≫1，γc 与状态坐标仍有可辨识性问题。u 不是测得的 nm，也不是
独立确认的缺陷数目。不能变换状态坐标却不相应变换 G，然后称物理未变。

最低成本的下一项实测诊断是：在允许的谱形/电路情景下，反演训练曲线的
γ 路径，检查正向只增宽、反向只变窄、SET 终态与 RESET 初态连续，以及
两接法在相同 `(u,v)` 附近是否要求互不相容的演化方向或速率。单点噪声、
原始电流 floor 和晶体管去嵌入误差必须保留；反演不是自主动力学预测。

## 2. 当前能标定的是路径率，不是反应速率

现有原始记录没有时间、扫速和停留时间。继续用

\[
 s=\int|dV_{\rm command}|,\qquad du/ds=G_\sigma(i,u)
\]

只能称有效路径率，单位为每伏扫描路径。它隐含两组协议可以用共同路径率
比较的假设。物理时间模型应为 `du/dt=H(Vh,u)`，且 `G=H/|dVcmd/dt|`；
未知扫速不能被当作已经相等，也不能由电压采样间距推断。
因此共享物理 H **不自动意味着** 共享路径 G。不同已测扫速造成的不同
路径率不属于材料方程不同；当前强制两接法同一路径率是额外建模条件。
正扫速只改变速度大小，不改变硬启动阈值和同态驱动排序，故第 4 节的
精确冻结/启动不等式通常不依赖扫速；有限速率的状态漂移和累计路径诊断
则非常依赖。不能因这个协议缺口宣称物理无解，也不能无数据任意设置
两组扫速来挽救拟合。
电压反向返扫时 s 仍递增，不能根据扫向自动冻结状态。零压等待也不能由
这一仅含路径长度的模型预测。下列冻结、锁定和准静态结论均需分别说明。

## 3. 任意电路下的阈值反馈条件

外电路写为 `a=v+Tσ(i)`，其中 `T′≥0`。在固定供电 a 附近，

\[
 {\partial\ln i\over\partial u}\bigg|_a
 ={f_u\over i(1+f_vT')}=-\chi_{\rm ext},\qquad
 \chi_{\rm ext}={\chi\over1+f_vT'},\quad
 \chi=-\partial_u\ln f.
\]

考虑待检验的共同阈值坐标

\[
 J_\beta=i e^{\beta u},\qquad
 \partial_u\ln J_\beta|_a=\beta-\chi_{\rm ext}.\tag{1}
\]

SET 在 `Jβ>JS` 时闭合（G<0）。为了由闭合降低超驱动而实现稳定自限，
必须有 `β>χext`。RESET 在 `Jβ>JR` 时打开（G>0），要由打开降低驱动
则需 `β<χext`。这是阈值边界的一侧反馈条件；有限速度的动态平台还要有
足够速率追随变化的外电压，不是只验符号就成功。

对于谱读出，令 `c(u)=1/(1−e^(−u))`，

\[
 \chi=c(u)E_\gamma,\qquad
 E_\gamma=\partial\ln i/\partial\ln\gamma,\qquad0\le E_\gamma\le2.\tag{2}
\]

最后的界来自每个 Lorentz 传输点的弹性
`2Δ²/(Δ²+γ²)∈[0,2]`，再对同号费米窗口和正权能量分布求平均。
它不依赖零温近似。宽 Ohmic 极限 Eγ→0；离共振窄窗可接近 2；
窄谱且完整能窗已覆盖时 Eγ≈1。

旧 `β=1` 并非整个谱族必败：晶体管的 `f_vT′` 可降低 χext，宽谱态也可
有 χext<1。但在**窄谱完整窗口、有限 u** 极限下，`f_v≈0,χ≈c(u)>1`，
旧 SET 阈值反而产生正反馈。显式地

\[
 i\simeq{\pi\gamma_c\over Ron(e^u-1)},\quad
 J_1\simeq{\pi\gamma_c/Ron\over1-e^{-u}}.
\]

u 下降会提高 J，而不是使它退回阈值。大 u 时只是趋于中性和病态，
不会自动变成稳定自限。严格固定 J 的满窗近似还固定 u，不能描述持续闭合
但 J 精确不变的一整段轨迹。上述结果已由独立审阅代理复核。

一个共同常数 β 若要同时提供 SET 和 RESET 的恢复性反馈，必须存在
`max χext,SET < β < min χext,RESET` 的非空区间。在两个均处于窄谱满窗、
RESET 状态比软 SET 更开（uR>uS）的极限，`c(uR)<c(uS)`，这个区间为空。
不同 βS/βR 可以绕过这项局部冲突，但增加了极性激活耦合假设，尚无独立
证据；不能由“同一个数学函数支持两个参数”宣称微观机制已确定。

## 4. β 的 SET 状态落差预算，以及它无法绕过的电压约束

对于 `JS=i exp(βu)` 的硬启动阈值，取 β≥0、软返扫最大电流 iT、
其冻结状态 uT、裸初态 uR、低阻所需状态 uL，有

\[
 i_Te^{\beta u_T}\le J_S\le I_{cc}e^{\beta u_L},\qquad
 \boxed{\beta(u_T-u_L)\le\ln(I_{cc}/i_T).}\tag{3}
\]

若裸形成前确实冻结到最后低压点电流 iR,pre，而首次开始闭合前电流为
iR,on，同一阈值存在至少需要

\[
 \max(i_Te^{\beta u_T},i_{R,pre}e^{\beta u_R})
 <\min(i_{R,on}e^{\beta u_R},I_{cc}e^{\beta u_L}),\tag{4}
\]

等号只代表零速度边界；真正有限路径闭合需要余量。由此得到

\[
 \beta(u_R-u_T)>\ln(i_T/i_{R,on}),\qquad
 \beta(u_R-u_L)\le\ln(I_{cc}/i_{R,pre}).\tag{5}
\]

不能把仪器限流后的 1 mA 当作形成前 iR,on；后者要从所选读出及初态
在首次触发实际电压上求出。若特意取最有利 `JS=iT exp(βuT)`，还需要
`β(uR−uT)≤ln(iT/iR,pre)`，因为裸预形成驱动必须低于阈值。
这一特例不应偷偷用于未知阈值的一般情形。

当前窗口的 iT≈51.322 µA 给式 (3) 右边 2.96963；4 V 特征的约
44–45 µA 不能替代包含 5 V 的冻结返扫窗口最大电流。
裸 2 V 训练中位约 54.5 nA 可作为低压数量级参照，但不是所有记录的
硬阈值或真正形成前电流。式 (3)–(5) 应用原始训练分布和明确窗口计算。

更关键的是，β 不解决下列与读出细节无关的矛盾。若裸在第一次实际限流
Vf 前后连续闭合并经过 uT，而软在该态、局部电压 vT>Vf 时确实冻结，
则对任何单调输运

\[
 f_+(V_f,u_T)<f_+(v_T,u_T)=i_T,
\]

所以裸在该状态的 `Jβ` 比已冻结的软态还小，不能越过同一 SET 阈值。
这也适用于任意随局部电压或电流单调增强的单向闭合率；乘上共同
`exp(−E(u)/kT)` 势垒、改用 `Vh/(u+u0)` 场代理均不改变同态排序。

名义映射下软高压约 3.3 V、裸首次限流约 2.7 V 是一个条件冲突。
需要核验的逃逸条件只有：软态并非真正冻结、状态路径并不重叠、实际
电压/晶体管映射改变，或引入有独立依据的非单调/额外状态过程。不能仅靠
把 β 从 1 改成可调数就宣称它被消除。有限速率仍可逃逸，但必须量化
状态变化、累计路径和完整轨迹，不再把静态拟合当作同态包络。

## 5. RESET 的低电流尾部排除什么，又允许什么

裸训练 RESET 在 −2.5 V 的电流中位 0.214 µA、Q90 0.873 µA；全部
14 条低于串联 1.0–1.4 V 平台 Q10≈1.904 µA。因此一个在任意状态都规定
`Greset=0 for i≤Ip`、Ip≈2–4 µA 的普适硬电流地板不可能解释两者。
在向外加压、有限正差分电阻下，首次向下触及 i=Ip 时
`di/ds=(da/ds)/(F_i+T′)>0`，不能越过地板。谱读出没有取消这个定理。

允许的一状态方向是让开启驱动随 u/局部场变化，使裸在亚微安时仍能继续
打开，同时串联平台在有限区间达到反馈平衡；不能为 bare 和 series 选择
不同地板。平台也可能来自冻结谱窗或晶体管负载，但都要检查实际谱形和
独立晶体管斜率，不能凭外观归因。

在 `γ≪热/谱窗尺度` 且 **u≫1** 的特定极限，定义

\[
 S_\sigma(v)=\left|\langle f_T(\epsilon-(1-\eta)V_h)
                 -f_T(\epsilon+\eta V_h)\rangle\right|,\quad0<S\le1,
\]

\[
 i\simeq A e^{-u}S_\sigma(v),\qquad A=\pi\gamma_c/Ron.
\]

若 RESET 近乎跟随同一 `JR=i exp(βu)` 阈值，且 `0<β<1`，则

\[
 u\simeq{\ln(AS/J_R)\over1-\beta},\qquad
 \boxed{i\simeq J_R^{1/(1-\beta)}(AS)^{-\beta/(1-\beta)}}.\tag{6}
\]

增大的谱窗口 S 可以让电流下降，因而 β>0 能解除 β=0 的普适电流地板。
但这同时规定了平台斜率，不能独立拟合尾部和平台：令 q=β/(1−β)，

\[
 \ln(i_T/i_B)=q\ln(S_B/S_T),\qquad
 |\Delta\ln i_T|=q|\Delta\ln S_T|.\tag{7}
\]

**有限 u 修正不能省略：**保留 γ=γc/(e^u−1) 时，沿同一阈值有
`d ln i/d ln S=−β/(c(u)−β)`，稳定要求 β<c(u)。小 γ 不等于 u≫1；
γc 尚未由共享动态标定时，式 (6) 只是一个特定渐近筛选。

## 6. 对当前选中静态谱形的一次便宜数值筛选

[脚本](check_spectral_dynamics_constraints.py) 与
[结果](spectral_dynamics_constraints.json) 使用已有训练静态 Gaussian
形状 `ε=0.55626 eV,w=0.19769 eV,η=0.45555,T=300 K`，不重拟合。
在平台中位电流 2.67851 µA 上，名义独立晶体管映射给约 0.04692 V 压降。
条件窄谱窗口为

| 位置 | S− |
|---|---:|
| 串联端口 1.0 V | 0.27388 |
| 串联端口 1.2 V | 0.43939 |
| 串联端口 1.4 V | 0.61642 |
| 裸端口 2.5 V | 0.99792 |

512→1024 节点加密的最大窗口差为 `5.2e-9`。这验证本次积分，未证明
近锁定和 u≫1 假设。为了通过式 (7) 取得中位电流比 12.526，需要
q=3.08166、β=0.75500；却会令光滑平台在 1.04–1.36 V 上漂移
**0.86625 decade**，明显超出既定平台 log Q90−Q10 span 上限
**0.16922 decade**。后者若被满足，仅允许中点到裸尾部比约 **1.63854**。

1.04/1.36 V 是连续均匀窗口下光滑单调模型的 10%/90% 位置，不是把
原始噪声电流的分位点误当作电压分位点。中位电流比和经验 span 是训练
工作约束，不是统计置信区间。恒定平台电流用于条件去嵌入，尚未自洽
重新求解漂移曲线的晶体管压降。

结论：**当前选中谱形 + 两段均在 u≫1 窄谱同一阈值锁定** 不能同时给出
软 RESET 平台和裸低尾部。这不排除有限 u、有限速率、其他被数据允许的
谱形或更准确电路情景。也不能把未量化的逃逸直接当作模型成功。

## 7. 不增加状态的共同能垒/场驱动律：资格与局限

一状态方程可以在数学上使用共同 `E±(u)` 与实际 `Vh` 构造场激活率，
且在负极性从 u=0 打开；从结构上并不强制新增温度、缺陷种类或第二状态。
然而“可写一个方程”远远不足以选择它。至少需要同时满足：

1. 裸低压 HRS 的保持与约 2.7 V 触发，且 1 mA 后的低实际压降仍能达到
   低阻读点；不能把限流后的命令 5 V 当作 hBN 受压。
2. 软 SET 高压低电流的有限状态变化预算；若称真冻结，必须通过第 4 节
   同态电压排序，不能由额外的 β 自由度隐藏该约束。
3. RESET 在 u=0 有有限非零开启能力；能从毫安硬态进入亚微安尾部，又能
   在串联条件下给出 2–4 µA 的有限平台；不使用普适硬电流地板。
4. 相同 `(u,Vh)` 只能有同一 G；不同接法、扫向、循环号不能作为隐藏标签。
   若轨迹反演要求同一点有不同速度，先查扫速/时间与噪声，再判断缺失状态。

无证据的“局部温度”“某一种空位/离子”“极性不同化学反应”均不能从
曲线拟合中直接得到。输运的无源性不等于状态动力学的热力学自洽；若称
能垒/详细平衡模型，还需说明自由能、驱动力及时间协议。当前不能把路径率
参数当作真实活化能或秒级反应常数。

## 8. 下一步的停止规则

现在不值得直接对新 G 做大规模 ODE 拟合。先做共同谱形下的**状态路径反演与
允许速率区间**，检验第 1、4、5 节条件；同时保留晶体管映射敏感性。
这项诊断若显示冻结包络只是错误近似，就量化所需有限状态漂移，并用它
决定是否存在不增加状态的同一个 G。若依然出现同态方向冲突，且协议和
电路不能解释，则应报告缺少哪项独立约束，而不是继续添加自由函数。
只有这些条件通过，才把一个有明确假设的共同路径率律送入自主全轨迹验证。
