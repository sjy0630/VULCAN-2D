# 继续推导还是补数据：按可识别问题安排工作

2026-11-03。针对当前裸 1R / 1T1R 共享材料模型。本文是工作建议；不把建议的
实验条件当作已做实验，不改变训练划分，也不重新启用前三圈异常作为主目标。

当前判断：现有数据仍足以推动有约束的模型筛选。与此同时，唯一微观解释、
真实时间动力学和内部电压分配的某些不确定性，不能靠增加拟合次数消除。
需要的是能解除特定混淆的数据，重复同一协议的更多 I–V 圈数并非第一优先级。

本轮已直接检查四个恢复工作簿的全部 150 张表结构并核对原文件哈希：
主体只有电压/电流；写入文件 C 列每表两项是 A7/B7 与 A498/B498 的电阻
公式，没有逐点时间列或额外协议元数据部件。见 `protocol_column_audit.json`。
这证明当前导出文件没有提供时间协议，不证明原始仪器记录也没有。

## 现有数据可以继续完成的工作

1. 共同材料方程的无源性、闭合极限和连续状态检验；两种接法只改变外部电路。
2. 同时检查裸 SET 非限流区、裸 RESET、软 SET 的低压开启/高压斜率、软 RESET
   峰与平台。一个分支的改善不能抵消另一个分支的明显失真。
3. 在进入昂贵 ODE 拟合前做静态形状、状态顺序和阈值可达性筛选。静态反演
   可以提供必要条件，但使用观测电流反演的状态不是模型预测。
4. 对通过形状关的候选，用同一参数做真实连续的 cycle 4–53 验证、原记录评分
   和独立电路/积分核验。已有内部检验记录不是新的盲测。
5. 复用已存在的 0.9/1.3 V 栅压数据前，核实 cell、初始化、SET/RESET 配对和
   协议。历史报告已探索过这些文件，不能把它们当作从未见过的外部验证数据。

有具体例子说明这些工作有价值：

- 旧共享式在既定晶体管映射下有 SET 电阻趋势的结构限制，调参不能解除该限制。
- 新增 cubic 项的一个静态最优参数组合，要求软/低阻状态落差超过 50，而实际
  限流和冻结条件只允许约 2.97；这是需要先处理的自洽性矛盾。
- Gaussian 谱读出的选中局部解在 SET 返回窗口自主电路误差约 0.083 decade，
  但 2→4 V 端口指数只有约 0.100，训练经验范围为 0.542–0.618。低均方误差
  并不能替代关键形状关。上述结果的前提和范围见各独立审计，均非全族无解证明。

## 为什么有些问题增加拟合次数也不能解决

### 真实时间尺度

设物理过程满足 dz/dt = k H(V,z)，命令电压路径 s=∫|dV_command|，扫描速率 r=ds/dt。
那么在恒速扫描段 dz/ds=(k/r)H(V,z)。只观测 I(V)、不知道 r 时，k 与 r
同时乘相同正数，整条 I–V 不变。当前模型只能标定路径率，不能从电压点距
恢复秒级速率；在停留期间 ds=0，路径模型甚至没有表达实际等待的时间坐标。

这也影响“统一”的具体含义：两组数据共用物理 dz/dt，并不自动要求共用
dz/ds；只有扫描速率等价等条件满足时，两者才等价。当前共同路径率是一个
额外建模假设。若原始协议证实速率不同，应将实测速率放入外部驱动时间表，
继续共用物理材料方程；不能因为路径率不同就判为两套材料理论，也不能在
协议未知时任意给两接法拟合不同速率来掩盖曲线偏差。

### 活化能和尝试频率

即使已有时间，在单温度 T0 下，若 k=A exp[−Ea/(kB T0)]，任意改变 Ea 并
相应改变 A，都可保持 k 不变。没有额外温度或独立约束时，不能从一个温度的
拟合唯一拆出 A 和 Ea，更不能因此指定某种迁移粒子。

### 隐藏状态的尺度

若 y=h(z) 是严格单调可逆的坐标变换，则

    F_new(V,y) = F(V,h⁻¹(y))
    G_new(V,y) = h′(h⁻¹(y)) G(V,h⁻¹(y))

产生相同端口电流。因此电学拟合本身不能证明 u 是多少 nm 的真实间隙。
需要独立结构证据或已标定的几何—输运联系；增加一个状态参数不会提供这类证据。

### 电压分配

准静态串联电路满足 V_supply = Vh + VT(I,VG)。没有额外仪器调压时
V_supply=Vcmd；仪器限流时还需计入命令与实际供电之间的压降。
若独立晶体管映射与实际串联晶体管不同，
这部分压降差可被错误归入材料本构。当前正向 1T 在 VG=1.1 V 没有直接测量。
常见插值变化未消除已发现的趋势，但不能据此消除器件对应关系的不确定性。
所需约 21.1% 的统一电流缩放是敏感性结果，不是已经获证的校准修正。

## 最小补充信息与数据的优先级

| 优先事项 | 最小内容 | 能解除的混淆 | 当前能否先做工作 |
|---|---|---|---|
| 原始协议及来源映射 | 各表 cell 标识、形成/循环身份、限流设置、命令/实际电压列、扫描速度和等待、裸记录时序 | 参数差异、初态差异和协议差异 | 先核对已有记录和文件，不必先新做器件 |
| 同接线的 1T 标定 | 实际工作 VG=1.1 V 下的正/反向曲线；物理 source/body 接法、与 1T1R 的对应关系 | 材料曲率与晶体管分压 | 现有插值敏感性已完成；不擅自采用所需缩放 |
| SET 后低偏压读出 | 多个低偏压点，正反读、重复读稳定性、仪器偏置检查 | 真正 Ohmic LRS 与有限偏压看似低阻 | 现有候选已提供差异明显的预言，可据此选读点 |
| 受控限流/栅压序列 | 尽量同一 cell、相同准备历史，记录实际限流；写后用同一低压条件读状态 | 外电路瞬时限制与保留下来的材料状态 | 先整理已有多栅压数据的来源；不足时才补测 |
| 扫描速率及等待 | 同样极值与初始准备，只改变速率；另设相同写入后改变等待的组 | 路径效应、真实时间松弛、场阈值 | 时间协议未确认前不报秒级机制参数 |

低偏压例子：前一轮两个候选在裸 SET 后 50 mV 读点可给出相近低电阻，
但一个候选在 1 mV 预测约 3.45 kΩ，另一个约 93.48 Ω。这是待验证的条件预言，
不是实测结论或新的谱候选已经做出的开关预测。读点应结合信噪比并验证不改写状态。

Nature 正文还报告裸/串联接法约 300/50 pF 寄生和裸仪器约 70 µs 响应，
为过冲提供了具体方向，但不是各本地工作簿的实测瞬态。若讨论硬态形成的
瞬态因果，应取实际电压/电流时间波形，不能把准静态路径方程包装成已模拟过冲。

## 推进和停止扩展的判据

当前继续数学筛选，不以缺少新实验为停止一切工作的理由。每次修改须先说明
它解除哪条已量化矛盾，再检查是否破坏其他分支、可达性和状态连续性。
若两个满足当前 I–V 约束的机制仍给出等价输出，应把它们的分歧转为具体协议
预言，优先取得可区分的数据；不通过不断增加参数宣称已选出唯一机制。
