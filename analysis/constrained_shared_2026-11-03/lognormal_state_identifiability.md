# 冻结 lognormal 谱形后的 SET 单调状态筛选

日期：2026-11-03。仅使用预定训练记录；只反演 gamma，不新增材料参数、不重新拟合谱形、不运行 ODE。原 Gaussian 审计保持不变。

## 固定谱形与方法

采用 `lognormal_spectral_refinement.json` 中已冻结的 m、sigma、eta、Ron、T，仅允许 gamma 随路径变化。通过原始观测电流去嵌入后反演 gamma；两点 minimax 误差再独立闭合串联 KCL，因此后者不是固定观测电压下的误差。SET 假设为沿原始采集顺序 gamma 不减。主检查窗口为回扫 5→0.06 V，0.04/0.02 V 仅保留诊断。

## 原先冲突是否缓解

| 点对（原始顺序） | 新 gamma 先→后 (eV) | 不减方向冲突记录数 | 均值两点端口误差下界 (decade) |
|---|---:|---:|---:|
| 5→1.4 V (previous_Gaussian_5_to_1p4V) | 0.00263603→0.00290002 | 6/32 | 0.000000 |
| 4→2 V (high_voltage_4_to_2V) | 0.00246648→0.00287395 | 0/32 | 0.000000 |

| 1.56→0.52 V (strongest_lognormal_mean_pair) | 0.00304101→0.00220409 | 31/32 | 0.059754 |

Gaussian 最强均值点对的条件下界为 0.101763 decade；新 lognormal 谱形按 gamma 逆序差选择的最强均值点对为 0.059754 decade，约为 14.8% 的乘性电流偏差。两者均为点对最大误差，不能直接解释成完整曲线 RMSE 的变化。

这证明当前冻结谱形不能以单向 gamma 精确穿过所有均值点，但不是按任何非零残差就否决有用模型。4→2 V 的方向矛盾已在全部 32 条记录中消失，表明同方向 SET 演化可以修正这段静态斜率偏高的问题。新分布对原先问题带来了实质性改善。

## 原始 Q10–Q90 电流区间是否允许单调状态

另外直接把每个见证点的原始训练 Q10–Q90 电流区间映射为允许 gamma 区间，并检查是否存在 gamma后≥gamma前、且两个端口电流同时落入各自区间的解。若没有，则通过重新闭合 KCL 求使两个区间对称乘性扩张所需的最小 log 扩张量。这个诊断不改变原先全曲线主门槛；经验分位区间也不是置信区间。

| 谱形/点对 | 同时落入原区间是否可行 | 最小区间扩张 (decade) | 乘性扩张因子 |
|---|---|---:|---:|
| Lognormal 原Gaussian见证 | 是 | 0 | 1 |
| Lognormal 4→2 V | 是 | 0 | 1 |
| Lognormal 2→1 V | 是 | 0 | 1 |
| Lognormal 5→4 V | 否 | 0.00317132 | 1.007329 |
| Lognormal 新最强见证 | 否 | 0.00100798 | 1.002324 |
| Gaussian 原最强见证 | 否 | 0.0747294 | 1.187762 |

新最强均值见证所需的分位区间扩张仅约 0.23%，另一个高压 5→4 V 点对所需扩张约 0.73%；这是条件诊断的大小，不能写成实验误差估计。Gaussian 原最强见证相应需要约 18.8% 扩张。新谱形确实大幅减轻了此处的方向冲突。

因此，本轮建议是保留 lognormal 作为下一步受约束动力学评估的候选；剩余均值逆序需要评估，但不能作为零误差否决门槛。仍须使用原先全曲线与特征门槛评价动态结果，且需同时处理 RESET 与裸 1R。当前检查既不证明全模型成功，也不自动阻止进一步定量改善。

## 数值范围与限制

每个均值反演状态均检查有限能量积分 32→64 阶，最大变化 3.66e-10 decade；100 eV 以上被截断电流的保守最大 log 误差界为 4.09e-10 decade。代表反演点和共同 gamma 电路见证点另做独立 Z 坐标积分，最大差 2.02e-10 decade。

这把数值证据扩展到本次实际反演的有限 gamma 状态，不认证任意大 gamma 或 Ohmic 极限。默认正向 VG=1.1 V 晶体管仍来自插值，器件配对和真实计时仍未独立确认；所有结论保留这些条件。完整路径、32 条记录的相同点对、数值核验和输入散列见 `lognormal_state_identifiability.json`。
