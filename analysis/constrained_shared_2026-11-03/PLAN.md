# 共同材料模型：有约束推导与筛选

日期：2026-11-03。用户明确设定持续目标：进一步进行有约束的推导与模型筛选，
直至达成较好的模型。此前阶段完成了原式/新增压降候选的比较，但没有完成该目标。
本目录独立保存新证据，不覆盖此前失败、拟合或审计。

## 不改变的研究范围

- 裸1R与1T1R使用相同材料电流方程、状态方程和材料参数。
- 拓扑仅进入外电路；初始化只反映声明过的准备历史，不逐圈调状态。
- 1T从第4圈唯一初态连续传播到53圈；前三圈保留但不参与正常工作主评分。
- 裸记录只有条件同编号配对，不假造跨记录连续时序。
- 保留全部原始记录散布、既定训练/内部检验划分及电流门槛。留出已历史曝光，
  不称盲测。探索性模型选择、调参和拒绝均保留。
- 目标包含较好的曲线预测与物理自洽性；仅有较低训练代价或更多单元测试不算完成。
- 禁止把有效状态宣称为已测原子距离，把路径率宣称为秒级动力学，或将一种
  电学拟合直接指定为已验证离子/金属物种。

## 本阶段顺序

1. 核对去嵌入前提：独立晶体管1.1V点来自插值，正/负向资料的器件对应关系
   未被证明。检查允许的插值选择和需要多大映射变化才会改变Rh趋势。
   敏感性场景不冒充已测置信区间，也不通过任意调电路吸收材料误差。
2. 仅从训练记录提取形状、峰值、回线、读阻和散布约束。将直接端口事实与
   依赖晶体管映射的内部量分开。
3. 推导输运与状态演化的联合可行条件；最多保留两个有明确来源和不同预言的
   最简材料候选。先解决旧模型的约束冲突，再进行昂贵联合拟合。
4. 外电路标定假设须先用独立1T记录检验；同时评估它是否足以解释已有偏差。
5. 候选使用同一原始数据目标，修正之前两圈均值替代目标的首圈权重问题。
   拟合中采用数值检查/检查点与明确的计算上限，保留终止原因和无效试次。
6. 参数冻结后，连续全网格验证、独立负载根/积分、反事实与形状约束检查。

## 判断进步与目标完成

工作验收将同时覆盖四支曲线及裸SET非限流区、关键峰/平台/低偏压读出、
连续状态、材料/外电路分离、数值可信性，以及解释对应的直接证据/替代解释。
训练记录的经验区间用于制定拟合前工作门槛，不把经验散布叫做不可约噪声。
若仅个别分支改善，或需要不受独立数据支持的电路改动，保持研究候选身份。
具体门槛是工作建议，不伪称用户逐条确认；它们不替代持续目标，也不以本轮
容易通过的条件重新定义“较好的模型”。
