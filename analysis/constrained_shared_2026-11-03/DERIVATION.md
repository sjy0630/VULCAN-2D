# 共同材料模型的必要条件与两类最小候选

2026-11-03。本文件只作数学筛选与假设登记，**没有实现或拟合新候选**。数值事实只取自固定训练集：裸 1R 的 14 条训练记录、1T1R 第 4–35 圈。没有使用留出观测选式子或定门槛。

先做一个不增加 h-BN 物理自由度的电路零假设；其后最多保留两类材料候选。这里的“候选”表示尚未被这些必要条件直接否定，**不表示整条曲线已经可拟合，更不表示机制已成立**。

## 1. 优先级：先确定电压分配，再决定改变哪一层物理

当前最值得先做的是共同晶体管映射的有界条件检验。默认去嵌入下的 `Rh↑` 很一致，但它不是无条件的材料事实：独立正向晶体管资料没有直接测量 VG=1.1 V，1.0/1.5 V 间插值以及同一物理晶体管的对应关系仍需区分。

只允许以下二者之一作为一次条件检验，不能同时自由化：

\[
 I_T(V_{DS},V_G)=c\,I_{\rm independent}(V_{DS},V_G),\qquad c>0,
\]

或

\[
 I_T(V_{DS},V_G)=I_{\rm independent}(V_{DS},V_G+\delta V_G).
\]

**同一个参数必须属于同一个物理 1T 端口**，贯穿独立晶体管及其串联使用、全部循环和已声明的正/负偏压。不能把独立 1T 固定不变、只在 1T1R 中偷偷缩放同一只晶体管。若正/负资料来自不同器件，须先记录源对应关系，不能据其文件名虚构“同一个源参数”。若 `c` 解释的是相对独立参考器件的几何/器件差异，必须称为器件映射假设，而不是仪器已知校准误差。

[circuit_constraint_audit.md](circuit_constraint_audit.md) 给出的训练条件结果：

- 24 种常见原始分支/电压插值/栅压插值组合均保留 32/32 圈 `Rh(4 V)>Rh(2 V)`。
- 单一 `c≈0.7890` 可消除全部两点上升；仅无源串联可行性给出 `c≥0.5323`，并不能排除前者。
- 单一有效栅压约 1.0177 V 也可消除全部两点上升；相对标称 1.1 V 的约 −82 mV **不是实测偏置误差**。
- 只增加共同串联电阻无用：`Rh_new=Rh_old−Rs`，两点差严格不变。

因此，必要的零假设检验是：在**有独立来源支持或清楚标记为敏感性情景**的共同映射范围内，原共享材料族能否同时通过四支曲线、连续状态和直接端口特征。消掉一个去嵌入不等式不等于解释了整个器件。也不得由 1T1R 曲线反推 `c` 后，称其为独立晶体管证据。

## 3. 任何共同模型都绕不过的链式关系

在固定极性的一段外扫上，写电流幅值 `i=|I|`、材料状态向量 `x`、端口电压幅值 `a=|Va|`。用电流的单调反函数写材料与外电路。这里 `a` 是实际加在材料加晶体管上的供电电压；仪器限流时它不等于命令电压：

\[
 a=F(i,x)+T_\sigma(i),\quad F(0,x)=0,\quad F_i>0,\quad T'_\sigma\ge0,
 \qquad \dot x=G_\sigma(i,x).
\]

`F≥0` 保证耗散，`F_i>0` 保证固定状态下唯一被动负载根；正/负外电路分支可以不同，但材料方程不能接收拓扑、gate、循环号或目标电流。对 `ν=da/dt>0`：

\[
 \boxed{\dot i={\nu-F_x\!\cdot G\over F_i+T'_\sigma}}.\tag{1}
\]

材料轨迹电阻的变化是

\[
 \boxed{\dot R_h={iF_i-F\over i^2}\dot i+{F_x\!\cdot G\over i}}.\tag{2}
\]

因此，**平台不是“把输出电流 clip 一下”**。若平台由材料演化维持，必须满足

\[
 \boxed{F_x\!\cdot G\simeq\nu}.\tag{3}
\]

若平台由晶体管饱和主导，则是 `T'` 很大使式 (1) 的分母很大。需要先检查独立负向晶体管在约 3 µA 的微分电阻，而不能由平台外观直接判定是哪一种。

对单一增阻状态 `u`、`F_u>0`，固定端电压附近的状态反馈稳定条件是

\[
 \boxed{G_u-G_i{F_u\over F_i+T'}<0}.\tag{4}
\]

式 (3) 是平台平衡，式 (4) 是局部回复性；仅满足其中一个不够。它们也不是全局稳定定理。

若 SET 仅允许 `G_+≤0`，且实测路径上 `\dot i>0`，则 `Rh↑` 必须有

\[
 \boxed{iF_i-F>-{iF_uG_+\over\dot i}\ge0}.\tag{5}
\]

也就是说，**固定状态下电压对电流的弹性须大于 1，并且足以克服状态闭合导致的降阻**。测得路径指数小于 1 不是直接测得冻结状态本构指数；式 (2) 才是正确分解。

这里用真实时间 `t` 便于物理解释。若暂时沿用累计绝对命令电压路径 `s`，只有在命令等于实际供电、且为单调外扫时才可取 `ν=1`；裸 SET 限流时必须使用电路求出的实际 `da/ds`。所有路径速率都只是“每路径伏特”的有效率。不能由点间电压间隔捏造扫描速度，也不能跨未知时序把该率直接叫材料的秒级常数。

## 4. 旧 Gap 与 Access 的可否决范围并不相同

### 4.1 旧 Gap 的符号约束

\[
 F_0(i,u)=R_0i+V_0u\operatorname{asinh}(i e^u/I_0),\qquad u\ge0.
\]

令 `z=i e^u/I0`，则

\[
 iF_{0,i}-F_0=V_0u\left[{z\over\sqrt{1+z^2}}-\operatorname{asinh}z\right]\le0,
 \qquad F_{0,u}>0\quad(u>0,i>0).
\]

所以在单向闭合 SET 中，它不能产生 `i↑且Rh↑`；这不依赖正的输运参数取值。**对实验的否决仍须附带晶体管映射前提**。

### 4.2 `uH(i exp(u))` 的冻结输运与动态锁定要分开

此前 Access 为

\[
 F=R_0i+uH(J),\qquad J=i e^u,
 \quad H(J)=V_0\operatorname{asinh}(J/I_0)+B(J/I_*)^3.
\]

它在固定 `u` 时可以有 `iF_i−F>0`，因此不能沿用 4.1 的全参数否决。

但是，若快速 SET 动力学把 `J` 锁在共同阈值 `Jc` 附近，则

\[
 R_h-R_0={H(J_c)\over J_c}u e^u.
\]

闭合 `u↓` 必然给 `Rh↓`，无论如何调 `B`。**这是否决阈值锁定工作区，不是排除所有有限速率的 Access 参数。**

更一般地，令 `ζ=JH'(J)/H(J)`：

\[
 {d\ln(R_h-R_0)\over ds}
 =(\zeta-1){d\ln i\over ds}+(\zeta+1/u){du\over ds}.
\]

若 `i↑`、`u↓`，要 `Rh↑` 必须

\[
 \boxed{-{du\over d\ln i}<{\zeta-1\over\zeta+1/u},\qquad\zeta>1}.\tag{6}
\]

该 cubic Access 有 `ζ≤3`；右边最多 `2u/(3u+1)<2/3`，而 `J` 锁定给左边为 1。因此，先检查候选训练轨迹是否满足式 (6)，比再盲目扩大 `B` 更有用。这里的状态反演若使用目标电流，必须标为 **oracle 条件诊断**，不能计作自主预测或直接状态测量。

## 5. 一个可以在拟合前排除的“简单 RESET 解决方案”

不要设一个所有状态共用的约 3 µA 硬阈值，并规定 `i≤Ip` 时 RESET 完全停止。

对只有一个状态的被动连续模型，如果 `G_-(i,u)=0` 对所有 `i≤Ip` 成立，那么在递增 `a` 的扫描中，轨迹到达 `i=Ip` 时

\[
 \dot i={\nu\over F_i+T'}>0.
\]

从上方下行的电流不能穿过该边界。裸 RESET 没有 1 mA 外限流，14/14 条训练记录在 −2.5 V 的外扫电流却已经低于 1.904 µA。因此，**普适的微安硬电流地板被直接端口数据否决**，与正向 1T 去嵌入无关。

这个结论不排除状态依赖阈值、无硬截止的有限速率、储能导致的持续演化或多状态模型；这些必须各自明确，不可用积分过冲或离散 state reset 偷渡。

## 6. 材料候选 A：独立实际电流的被动压降 + 载流子供给限制的有限速率

这是“尽量保留单一 gap 状态”的明确试验式，**不是旧 Access 只再调一次 B**。

### 方程

\[
 \boxed{F_A(i,u)=R_0i+V_0u\operatorname{asinh}(i e^u/I_0)
             +Bu(i/I_*)^3},\quad B\ge0.\tag{A1}
\]

`I*=1 mA` 只固定单位。与旧 Access 的关键区别是额外项取决于**实际电流 `i`**，没有 `exp(3u)`。它表示一个假设的材料内部限流压降，不是再次计入已经测量的外部晶体管。

设 `e=V0 asinh(i exp(u)/I0)`，初始最小速率选择为

\[
 G_{A,+}=-k_S(i/I_*)\sinh\!\left({[e-E_S]_+\over E_S^{\rm scale}}\right),\tag{A2}
\]

\[
 \boxed{G_{A,-}=k_R(i/I_*)\exp[-A_n e^{-u}]}.\tag{A3}
\]

在 `[0,u_max]` 边界只投影向外流。`A_n≥0` 是闭合连接更难开启的有效概率抑制，不称实测成核能垒。正向的 `i/I*` 是载流子供给假设，可让高电流裸器件较快、低电流串联器件较慢，而无需拓扑标签。负向没有固定微安硬截止，所以不会直接落入第 5 节的禁区。零电流时两率都为零。

A3 中固定取一次电流，不同时拟合一个任意幂指数。温度未变化时，常数激活概率与 `kR` 不能独立识别，故不另加一个可吸收到前因子中的“基准能垒”。若后续必须把 `i` 改成高次幂、再加迁移窗口，属于**新增假设**，不能悄悄当作本候选的自由参数。

### 数学上真正修复了什么

A1 有 `F_i>0`、`F_u>0`，并在 `u=0` 精确还原 `R0 i`；给电压加符号即可得到无源奇本构。

\[
 iF_{A,i}-F_A=V_0u\{z/\sqrt{1+z^2}-\operatorname{asinh}z\}
                      +2Bu(i/I_*)^3.
\]

所以式 (5) 有可能满足，但不是自动满足。即使正向暂时仍接近 `J=Jc`，令 `Hc=V0 asinh(Jc/I0)`（仅 gap 项），有

\[
 R_h-R_0={H_c\over J_c}u e^u+{B J_c^2\over I_*^3}u e^{-2u}.
\]

沿闭合 `u↓` 要 `Rh↑`，须 `u>1/2` 且

\[
 \boxed{{R_{\rm access}\over R_{\rm gap}}>{1+u\over2u-1}}.\tag{A4}
\]

与旧的 `uH(J)` 不同，确有一块代数可行区域。若反演状态只能在 `u≤1/2`，则阈值锁定区仍失败；不能靠画出一条合成曲线忽略这个限制。

### 对微安 RESET 平台的严格筛选

在 A3 的动态平台上需

\[
 F_u k_R(i_p/I_*)e^{-A_n e^{-u}}\simeq\nu.
\]

沿近似平台，假设该窗口的实际电压扫描速率 `ν` 恒定，隐式微分给

\[
 \boxed{{d\ln i_p\over du}=-
 {\partial_u\ln F_u+A_n e^{-u}\over1+\partial_{\ln i}\ln F_u}}.\tag{A5}
\]

若 `ν` 随状态/时间变化，A5 的分子还须减去 `d ln ν/du`，不能在未知扫描速度时直接应用恒速形式。

这说明有限速率本身不保证平平台。若 gap 项导致 `F_u` 随 `u` 明显增大，平台会下斜；必须把式 (A5) 在训练允许的整段状态区间检验，而不是只调某一个峰值。

还存在跨相位的幅值约束。若在正向高压点，访问压降不超过该点 `Vh,S`，则

\[
 B\le {V_{h,S}\over u_S(i_S/I_*)^3},\quad
 F_{u,\rm access}(i_R)\le{V_{h,S}\over u_S}(i_R/i_S)^3.\tag{A6}
\]

软态 RESET 约 2.7 µA，而 SET 高压约 30–44 µA，立方比约 `2e-4–7e-4`。**足以改变几十微安 SET 的 cubic 项，不会自动在几微安 RESET 中仍占主导。** 不可仅因 A4 可行就声称平台问题已解决。

### 来源、预言与停止门槛

- 来源/用途：内部电子流受限、迁移反应受载流子供给限制是待检验的有效解释；Nature 的限流/电应力讨论只支持“外电路改变状态”，并未测出 A1–A3。`V∝I³` 也不是传统 `I∝V²` 的 SCLC，不能借用后者名称来背书。
- 预言：平台若由有限速率维持，将随扫描速度改变。固定状态热平衡的额外压降本身不生成零电流等待松弛；A2–A3 在 `I=0` 立即冻结。
- 停止门槛：同一参数必须满足条件 SET 式 (5)/(A4)、完整 RESET 平台式 (3)/(A5)、裸大电流峰和低电流外扫尾端、低压近 Ohmic 极限及连续交接。若 A6 使平台要求与正向压降预算不相容，或只能靠另加 state-dependent 阈值窗口救回，则**先判本最小形式不够，不继续堆函数或扫大参数网格**。
- 顺序：只做代数/训练 oracle 可行区间检查后才考虑自主拟合。即使可行，仍要比较它与“有限速率的原 Access”是否真有可识别区别，不能因前次优化失败就抹去原族。

## 7. 材料候选 B：保留原输运，增加一个储热状态并允许 SET 中的竞争演化

这是另一种结构选择：**不加 A1 的额外电子压降**，而放弃“正偏下 gap 只能闭合”。引入一个有守恒约束的温度状态 `T≥T0`，用它保存电应力历史。

### 一个最小的显式方程组

保持 `F=F0`，使用有符号的局部驱动 `e_s=V0 asinh(I exp(u)/I0)`：

\[
 C_\theta\dot T=I V_h-{T-T_0\over R_\theta(u)},\qquad C_\theta>0,\ R_\theta(u)>0,\tag{B1}
\]

\[
 a(T)=\exp\left[{E_a\over k_B}\left({1\over T_0}-{1\over T}\right)\right],
\]

\[
 \boxed{\dot u=\Pi_{[0,u_{\max}]}
 \left\{k_b[a(T)-1]-k_d a(T)\sinh(e_s/E_d)\right\}}.\tag{B2}
\]

`Π` 只抑制边界的向外速率，不改变内部微分方程。`a(T)-1` 表示相对于环境平衡的额外开启过程；它不是声称环境下没有任何热激活事件。先共用一个激活因子，避免立即引入两套不可识别激活能。

这里 `Ea` 是与 `kB` 单位一致的激活能；`Ed` 是有效驱动的电压尺度，不是第二个激活能。`Cθ` 为 J/K，`Rθ` 为 K/W；`u` 无量纲，反应率用 s⁻¹（或另行声明的路径率）。

正向既可闭合也可开启；负向两项都可使 `u` 增大。热态未完全冷却时，即使电流已经降低仍可继续演化，因此不受“普适微安硬地板”的同样限制。`u=0` 的**冻结**输运仍为 `Ron I`，但是否能稳定保持闭合要由 B2 检验，不能由本构极限替代动力学证明。

B1 是忽略结构反应焓的首阶热平衡；若结构能量变化不可忽略，需要显式减去 `dU_struct/dt` 或说明其能量预算，不能因此声称已完成热力学闭环。`u` 仍是有效状态，`e_s` 仍是有效驱动，不把零 gap 极限下的有限代理量叫作已测局域电场。

B1 的输入功率是实际材料功率 `I Vh`，不是 `I Vcommand`；source regulation drop 和晶体管耗散不能重复算入 h-BN 发热。若要加入晶体管热耦合，需要新的空间/热耦合证据，不能隐含加入。

### 这个方案怎样通过或失败

对 B 的一个增阻状态 `u`，条件 `Rh↑` 所需的正向开启率为

\[
 \boxed{G_{B,+}>{F_0-iF_{0,i}\over iF_{0,u}}\dot i>0}.\tag{B3}
\]

B2 可以在正向热开启超过场闭合时做到，而在降压返扫时热驱动衰减、场闭合占优，仍有机会给出同电压返扫电流较大。不能仅展示 `G+>0`，还必须实际满足 B3 的幅值和整条回线顺序。

同时须满足：

1. 裸正向闭合态不能被其自身 SET 功率持续破坏：在相应状态上须 `kb[a(Tb)−1]≤kd a(Tb)sinh(e_b/E_d)`，使边界投影保持 `u=0`。
2. 软态 RESET 平台需 `F_u G_-≈ν` 并有稳定反馈；温度的线性化还包含 B1，须检查二维 Jacobian，不能只借用标量式 (4)。
3. 裸 RESET 大峰后需有足够的持续开启/储能释放，使电流降到训练高压外扫尾部，而不是重新卡在一个微安硬地板。
4. 若解释诉诸两接法相同的“热阈值温度”，必须交代功率量级：裸峰的代表性端口功率是毫瓦级，软平台是数微瓦级，差约 `10³`。这要求相应热阻、局域体积、脉冲能量或场致势垒贡献的独立约束。不能只加一个自由的 `Rθ(u)` 让它自动成立。

最小初始检验取共同常数 `Rθ`，并用同一环境 `T0`。`u,T` 都必须跨 SET/RESET 和周期连续传递；`T0` 不是每一支或每一圈的自动重置值。初始温度是否已回到环境也需作为准备条件声明。若必须引入 `Rθ(u)=Rθ0 exp(βu)` 等几何依赖，`β` 是**新增物理假设**，需由狭窄导电路径/热边界的文献或独立实验支持后再开放；不按 1R/1T1R 给不同热阻。

### 来源与可证伪预言

- 论文已讨论限流响应和寄生电容导致不同电应力，并观察同类器件可处于不同线性程度的状态。这支持检查动态应力，不直接证明热机制。当前文件没有把能垒、温升或热时间常数写成测量值。
- B 预言脉冲宽度、占空比和短等待对开关后继续演化有影响；热态冷却期间 `I=0` 时仍可能出现有限的 `u` 漂移，区别于候选 A 的即刻冻结。时间尺度必须由实际时间数据检验，不能从命令电压点数推断。
- 本候选需要真实时间或可独立约束的扫描速度。现有仅 V/I 的文件不能同时识别 `Cθ`、`Rθ`、反应率和未知扫描时间。若不补充时序，只能讨论一个无量纲约化假设，不能报告摄氏温升、微秒热过程或独立材料热参数。
- 若独立读出证实正向高压时增阻趋势来自纯电路，而没有 SET 中反向状态演化或热记忆证据，则 B 没有增加状态的必要性；应优先保留更简单的共同材料模型。

## 8. 何时才进入拟合

本轮建议的次序是：

1. 先执行电路零假设的独立约束/有界条件比较，并保留名义映射结果。给出一项映射条件后的内部约束与不依赖映射的端口约束，二者不能混成一个“材料真相”。
2. 若材料结构仍有必要改变，只在 A、B 两类中根据外部物理证据选一类。先做训练特征条件下的可行性筛选：A 的式 (5)、(A4)–(A6) 与无硬地板；B 的式 (B3)、闭合态稳定、真实能量/时间约束。
3. 用目标电流反推 `Vh`、`u`、`G_required` 或温升，全部属于 **oracle 诊断**。它可否决不可能假设或构造测试区间，不能作为预测曲线、不能当独立状态测量，也不能为每圈手动设置状态。
4. 自主预测时只输入声明过的命令与初始条件；同一材料参数、同一方程连续传播。训练目标采用真实时间顺序的权重，不能让两圈替代目标把第 4 圈权重从 `1/32` 改为 `1/2` 后仍叫完整顺序损失。
5. 同时通过四支曲线、裸 SET 非限流段、RESET 平台/峰/尾部、低压有限读出与零偏极限、连续交接及独立数值检查。总损失下降不能抵消硬特征失败；没有一项电学拟合单独证明某种金属、离子或缺陷物种。

**本文件的选择建议：目前先做共同电路参数的有界检验。A 是一状态的最小代数逃逸方向，但微安平台的跨相位预算可能使它失败；B 有储能与反向状态演化的明确预言，但在时序/热约束缺失时不宜立即扩大自由拟合。**
