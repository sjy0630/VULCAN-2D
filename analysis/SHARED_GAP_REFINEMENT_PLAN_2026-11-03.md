# 统一模型的下一轮改进：先修校准与可检验的系统失配

用户要求同时提高统一解释和准确度。本轮继续使用相同材料方程/参数、外电路
分离和连续状态约束。旧结果及内核保留，不覆盖既有数值证据。

1. 只用训练数据分解误差，区分系统偏差与同波形的循环/器件散布；后者不自动
   叫做测量噪声。用 log 均值定义单一确定曲线的经验参考下限。
2. 先解决上一轮粗积分影响拟合、优化未收敛的问题。使用独立验证过的自适应
   积分重新联合优化全部现有参数，不先增加状态或器件专用规则。
3. 标定目标使用训练记录 log 电流的充分统计量。各原始记录的电流门槛分别
   处理；裸 R SET 的非限流正扫、非限流返扫和平台分别等权，再使四相等权。
   两个连续 1T1R 回线约束周期衔接，最终仍从第 4 圈唯一初态推进到第 53 圈。
4. 若需要修改动力学，必须先给出可复现的状态轨迹/曲线形状矛盾，并保留原式
   对照。反演状态只用于诊断，不作为预测输出，不用留出数据选择物理假设。
5. 沿用裸 R 前 14/后 8 记录、1T1R 第 4–35/36–53 圈划分与原始评分门槛。
   数据已参与历史开发，所有留出称内部检验，不称新盲测。
6. 每条分支、裸 R 非限流 SET、峰值位置与完整连续性都要报告。不得用平台或
   某支改善掩盖其他支恶化；不得把代码测试/优化收敛当作物理机制验证。

参数的可辨识性、状态边界、负载线和数值加密与曲线精度一起核查。秒级过冲、
原子物种和几何单位不能由准静态 I–V 拟合自行确定。
