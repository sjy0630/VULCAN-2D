# 初三圈反向抑制的顺序检验约定

本检验是在已经看到初三圈现象之后作出的探索性检验，不能称为独立验证。
目的是检验“每圈响应向量可交换”的零假设，不指定离子、陷阱或真实状态数。
拒绝该零假设也可能反映器件之外的条件变化，不能单独证明器件内部记忆。

每圈只取三个预先已有的低压特征：原生0.10–0.30 V的SET回程平均log10电流、
RESET去程平均log10电流，以及两者之差。以完整53圈向量为置换单位，保留
特征相关性；不把一条曲线上的点当作独立样本。不删初三圈或其他异常圈。

对每个特征，在全部52个切点计算标准化CUSUM：
abs(sum_(i<=k)(x_i−mean(x)))/(sd(x)*sqrt(k*(n−k)/n))。
主统计量同时取三个特征和52个切点的最大值，置换时重复相同搜索，因此不
把事后挑选第3圈作为固定切点来报告未经校正的p值。各特征单独搜索的结果
作辅助记录，主判断用联合最大统计量。

作200,000次置换(seed=92153)，再作100,000次独立种子复核(seed=92154)。
有限蒙特卡洛p值用(b+1)/(B+1)，报告超越次数和其二项抽样区间；该区间只表示
蒙特卡洛精度，不是物理效应的置信区间。另给最低三个比值的名次位置及恰好
连续的精确组合概率，明确其只是探索性秩描述，不替代主统计量。

处理敏感性：另将每条SET电流增加其最大零偏幅值、每条RESET电流也增加其
最大零偏幅值，以检验低信号的常规正参考平移；只作为敏感性，不当作仪器
校准误差模型。这不是为每圈选择不同方向来最大化显著性。观测电压、配对和
顺序均固定。若顺序证据成立，后续随机候选需要保留跨圈相关性或显式条件
演化，不能仅用独立每圈噪声解释；仍须给完整路径概率与电流读出。
