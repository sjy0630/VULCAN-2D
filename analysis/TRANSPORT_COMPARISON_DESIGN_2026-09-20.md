# 输运候选比较：执行前方案

本方案在本轮候选拟合结果生成前保存。已有数据此前参与模型开发，因此这是后续内部检验，不是外部盲测。

## 问题与候选

稳定支的非线性能否由物理参数合理的简约输运方程解释？先比较以下核，每圈允许一个电流幅值，形状在同一支路共享。振幅不能用来识别陷阱能、接触面积或缺陷数。

| 核 | 电流幅值形式 | 形状参数与解释 |
| --- | --- | --- |
| Ohmic | A v | 无形状参数，必要基线 |
| Power | A v^n | 1 个有效指数，经验基线，不据此证明 SCLC |
| PF free | A v exp(beta sqrt(v)) | 1 个自由曲率，复核旧有效核 |
| PF constrained | 同上 | beta 对应假设 300 K、6 nm 及 epsilon_r=2–8；范围是比参照 3.1 更宽的审查假设，不是目标测量 |
| Schottky free | A exp(beta sqrt(v)) [1-exp(-v/V_T)] | 1 个曲率；高偏压势垒降低与热发射的候选。括号保证零偏置正反流平衡，是当前有效接触分支假设，不声称已解整个双接触体系 |
| Schottky constrained | 同上 | 势垒降低系数为 PF 的一半，采用相同 T/d/epsilon 条件；须按自身前因子重拟合 |
| Hopping | A sinh(alpha v) | 1 个曲率；最近邻、对称跳跃的电流核候选，alpha=q*a/(2*d*kBT)；条件上限 a<=d，不能由拟合直接证明离子运动 |

各核均以 v_ref=0.1 V 归一化；完整电流 I(0)=0，按极性恢复符号。归一化不增加形状自由度。所有误差都在 log10 电流域计算，不比较各自线性化坐标的 R²。

## 数据和数值筛选

主对象为 1.1 V 已确认的全 53 对；先对 SET pre、SET return、RESET initial、RESET return 四支做比较。使用已保存的实测正反晶体管查表、实际栅压及快速精确分段线性反解。

- 主窗口：SET pre 内部 0.50–1.20 V 且端口<=1.25 V；SET return 0.15–0.80 V；RESET initial 0.10–0.35 V 且端口<=0.45 V；RESET return 0.50–1.20 V。
- 较宽窗口敏感性：两个低导电支改为 0.30–1.20 V；其余不变。
- 排除零电压、非有限/非正电流、越界反解、非正内部电压；晶体管压降<=端口50%，电流<=同端口1T容量70%，避免接近不可逆求解的限流区。这些是数值门槛。
- 主要形状对照再要求 I>10倍该扫描最大绝对零偏置读数；与不设此门槛的结果一并报告。此门槛仅是读数敏感性处理，不是经校准的噪声方差。记录每圈和每支的排除数量，不默默删除 R1–R3。
- 不插值成密集独立样本。每循环等权；每圈幅值和共享形状只在相应训练数据计算。

## 评价

1. 留一循环自主支路预测：形状和中心幅值从其他循环估计，目标电流仅评分。幅值波动与形状误差均计入。
2. 留一循环且留高电压区的形状预测：共享形状只使用其他循环的低电压 60% 窗口；目标幅值只用目标低压区确定，预测其高压40%。明确标为“低压读出条件化”，不与自主完整周期混同。
3. 前35圈训练、后18圈的自主支路预测：检查循环顺序变化。
4. 同数据全窗口形状残差只作诊断，不当成留出预测。

输出每个循环误差、共享参数、活跃边界、条件物理换算、点数、异常与方法限制。暂不按这轮结果自动覆盖 M13。经典场发射的适用性仍需检查局域分压、介电响应和候选稳定支是否真的保持状态；数学排名不能单独认定机制。
