# 从固定 m=2 SET 组件到连续有符号历史：接入就绪度

当前可以进入跨极性、跨圈检验，但还不能把单圈 SET 成绩称为统一 1R/1T1R 模型。最小下一步应是：**冻结现有正向 m=2 参数，从真实模拟的第4圈 SET 末态接 RESET4，再接 SET5；不在 RESET 或第5圈重新设置状态，不先激活额外通路 a。** 本文件只是只读设计，没有实现新函数、运行 ODE、扫描或拟合。

现有 `final_refined.json` 的第4圈条件 SET 原500点 RMSE 为 0.133894906 decade；这是同圈校准成绩。其返回零电压时的 `terminal_u` 已保存，可作为下一相位的实际模拟入口。不能用 RESET 数据重新反演一个更方便的入口替换它，也不能把第5圈的 0.2 V 观测再设为锚。

## 2. 保持现有正向 law 不变的最小 signed 映射

已有正向组件为

\[
q'=\kappa_+v\left[\frac{i}{J_+}(1-q)-e^{\lambda v}q^2\right],
\qquad v=|V_h|,\quad i=|I|.
\]

若将 `SOFT_FEEDBACK_NEXT_DECISION.md` 的有效极性骨架扩展到同一固定 m=2，则候选表达为

\[
q'=\kappa_qv\left[\frac{i}{J_0}e^{\sigma b}(1-q)
 -e^{-\sigma b+\lambda v}q^2\right],\qquad \sigma=\operatorname{sgn}V_h.
\]

用

\[
\boxed{\kappa_q=\kappa_+e^b,\qquad J_0=J_+e^{2b}}
\]

即可对任意 b 保持正电压下已校准的整个率式完全不变。负电压下相应为

\[
\boxed{q'=\kappa_+v\left[\frac{i}{J_+}e^{-2b}(1-q)
 -e^{2b+\lambda v}q^2\right]}.
\]

用现有 u 坐标积分时，负向等价式为

\[
u'=\kappa_+v\left[e^{2b+\lambda v-u}
 -\frac{i}{J_+}e^{-2b}\operatorname{expm1}(u)\right].
\]

这里 b 只是待约束的有效极性参数。正向数据只能识别 κ+、J+，不能单独确定 κq、J0、b；不能给 b 标上已经测得的能垒、物种或离子方向。把 m=2 用到负极性也是一个待检验的结构延拓，不是 SET 拟合自动证明的结论。

σ必须由求得的实际 hBN 电压决定，不由“SET/RESET”文件名、扫出/扫回方向、圈号或拓扑标签决定。正向返扫仍是正电场，负向返扫仍是负电场。电流使用统一预声明的总材料电流幅值；此处先令 a=0，因而总流恰等于 soft 流。以后不得根据拟合需要在两种驱动定义间切换。

## 3. 将来接入 a 的最小结构及不能跳过的约束

旧决策文件中的候选材料读出与第二状态为

\[
I=F_{\rm soft}(V_h,\Gamma(q))+aV_h,
\]
\[
a'=\kappa_av\left[e^{\sigma b}q(a_{\max}-a)
 -\rho e^{-\sigma b}(1-q)a\right],\qquad 0\le a\le a_{\max}.
\]

这仍是待检验骨架，本轮没有实现、校准或运行。a是有效近欧姆电导，单位S，不预设已成形的金属丝或具体迁移物种。同一个 b 同时控制 q 和 a 是额外简约假设，尚无数据证明；若以后改变，必须作为新结构假设计入，不能暗增不同 b。

必须先处理三个具体问题：

1. **a=0通常不是激活后的不变子空间。** 若κa>0、q>0、amax>0，正场下在a=0有a′=κav exp(b)qamax>0。新增通路会改变总电流、局部电压和q速率，故不能承诺正向0.1339成绩自动保留。需检查series中实际新增电流和反馈是否与原误差相容，再进行完整联合验证。
2. **当前.2 V条件锚在a>0时不再单独确定q。** 旧反演依赖I=Fsoft；新观测只给I=Fsoft+aV的一条关系。不能同时自由调a并继续把旧u锚当精确材料观测。应明确状态入口的条件假设或利用多个已有非扰动读点约束，不能每圈增加一组自由初态。
3. **旧bare限制没有因“两个变量”自动消失。** 同极性RESET排序反转、record10纯损失/静态背景约束、record15高信号谷后恢复，仍需真实连续轨迹解释。旧a单峰结论假定RESET u不减且soft背景受限；新q可逆只改变了该证明的前提，不证明新轨迹已经能产生所需恢复。

在理想数学边界上，固定m=2仍有q=0时q′≥0、q=1时q′≤0；上述a式在a=0、amax分别指向域内。数值实现仍需保留有限Γ表域检查，不可据此夹取状态。q=a=0时若总流也为0，绝缘端仍可能吸收，不许用每圈加种子绕过。

加入a后，soft的Ron不再能直接等同裸总LRS电阻；总电流也不再受纯soft的|V|/Ron界约束。原有固定谱幅度与a会在窄窗口互相补偿，需检查多电压形状与RESET尾给出的a上界。现有净电流驱动依旧是有效动力学假设，不是已推导出的局域捕获通量。

## 4. 共享参数、状态接口与最小工程修改

完整候选应由一个材料对象提供同一个 signed readout 与同一个 signed RHS，两种拓扑只换外部电路。固定谱形状、Γc、Ron及m的来源应保留；新阶段若改变其中任何量，必须单列变更与重新验证范围。

在保持上述骨架时，至少应明确共享的λ、J+、κ+、b、κa、ρ、amax，而不是为裸/串联、各圈或SET/RESET文件分别提供材料参数。三个已观察训练段各有一个入口状态；未来两状态模型的入口是(u,a)对，不能继续只记录一个u。段入口是边界条件，不等于有三套材料规律；但新增自由度仍要如实计数。

最小接口改动应集中在新阶段适配层：

- 材料电流接口接收带符号Vh和完整状态，返回Fsoft+aV；状态RHS接收求解后的同一Vh/I及完整状态。
- 相位积分返回原生电流、`state_u`、`state_a_s`与完整终态；SET→RESET→下一SET只使用该终态，既不投影也不重反演。
- 电路求根针对总材料电流闭合，裸限流时使用真实受限Vh驱动状态；串联使用固定实测正负晶体管分支。不能在状态按命令电压演化后才裁电流。
- 保留原评分器、掩码和来源哈希，另记录每相位入口、SET末态、RESET末态及跨圈衔接差。先用已知合成两状态轨迹核对接线，再做有限物理试验；不能把接线验证写成物理验证。

这不是要求立刻编写或拟合完整双状态模型。下一项跨极性试验先a=0，只需要signed soft相位接口及无重锚的状态串接，不需要先决定κa、ρ、amax。

## 5. 时间、缺圈与原评分合同

用户已确认裸数据是同一器件的连续重复循环，编号为实际顺序，同号先SET后RESET；第4、23圈实际测过但未提供。扫描速度、每点时间与等待设置仍拿不到，不再反复追问，也不补造数值。

| 范围 | 必须执行的历史规则 |
|---|---|
| 裸训练1–3 | 一个入口状态，逐圈SET→RESET连续传播 |
| 裸训练5–15 | 第4圈缺失，允许一个单独的段入口；不得把第3圈末态直接当第5圈入口，段内禁止重置 |
| 串联训练4–35 | 一个入口状态，全部32圈连续；不得用同一条稳态pair复用各圈 |
| 将来裸16–22保留段 | 必须从训练第15圈末态接续；本设计不读取或拟合这些数据 |
| 将来裸24 | 前面缺第23圈，不能用第24圈观测反演自由初态后称无条件保留集预测 |

训练联合评分仍是46对、92相位、原27023维记录残差。四个拓扑/相位块等权；裸SET内部非限流外扫、非限流返扫、限流三组各1/3，SET阈值1e−11 A、RESET阈值1e−12 A及非零电压规则保持。单圈500点RMSE不等于该联合目标，也不等于原20项聚合特征已通过。

当前率的自变量s是累计命令电压路径。跨极性共用κ实际上包含对未知协议的有效假设；如果正负扫描速度不同，b可能吸收部分时钟比例，不能把它唯一解释为材料极性。两种拓扑测试时间未知，也不能因为路径率相同就宣称每秒材料率已共同标定。

不插入未知等待，重复零电压端点不产生额外路径时间。因此连续状态检验属于**未显式建模间隔/零场等待演化的条件试验**，不是已证实实际测试无等待。即使方程在V=0冻结，也不能据此预测0.1 V读压下7小时保持。

## 6. 唯一建议的最小下一实验：RESET4校准一个b，SET5不重定锚检查

这是一项尚未执行的有界计算实验设计，不是新增自由函数或当前执行授权。

**固定输入与范围。** 固定本阶段已数值核验的m=2正向λ/J+/κ+、Ron、Γc、谱与晶体管；a严格设0作为soft组件试验条件。只读取现有训练内的series RESET4和SET5原生数组。起点使用本阶段保存的SET4返零`terminal_u`，不重跑SET4拟合、不从RESET首点重置状态。

**唯一新校准量。** 使用上节严格保持正向law的signed映射，只校准一个b。建议在预声明有限窗口b∈[0,ln10]内做一次至多20次目标调用的一维有界校准，仅以RESET4全部原评分点的log电流误差为目标。该窗口仅对应此假设内负向相对系数的有限探索，不是实验测得的物理边界；不得失败后自动扩域或追加起点。root应在执行前固定具体求解精度、时间与次数上限。

**真实状态接续。** 每次RESET4都从同一个保存SET4末态开始。选定b后，以RESET4实际终态作为SET5在零电压的入口，完整积分SET5；**禁止再使用第5圈0.2 V条件锚、重新估初态或调整正向λ/J+/κ+**。SET5数据不参加这次b选择，但它属于原训练集，应称“本次拟合未使用的跨圈检查”，不能称原保留集或独立新实验预测。

**记录与停止。** 保存每次b、原生电流和u/q、失败/表域退出、RESET4→SET5边界、两精度current/state差和正负KCL/legacy审计。最终分别报告RESET4和SET5原掩码RMSE、低压分组、RESET峰/尾及状态闭合偏差，不能只报告合并RMSE。两精度只验证同一个最终b，不再选更有利参数；遇到预算或数值域失败保留失败，不写成物理反证。

**它能回答什么。** 若一个有效极性参数已无法同时给出RESET4和未经重锚的SET5，则当前soft组件尚未建立最短跨极性历史闭环；应明确是这一signed延拓、有限b窗口及未知协议条件下失败，而非证明所有q/a物理不可能。若成功，才有理由把同一signed q组件接入a并接受裸训练段及完整46对历史的检验。它仍不证明裸器件已解释，更不授权继续只在第4圈SET上增加自由度。
