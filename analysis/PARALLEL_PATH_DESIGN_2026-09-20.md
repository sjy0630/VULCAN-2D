# 低偏压约束下的能级分布、并行通道与状态交接

本方案在本轮拟合前保存；属于基于既有失败结果提出的探索性研究，不是外部预注册。M13保持原样。

## 假设与方程

每一通道是连接两端电极的非相互作用局域能级，完整化学势差为qV；冻结结构、电压无关接触率下，净流正比于 `f((E-eta*V)/VT)-f((E+(1-eta)*V)/VT)`。VT对应300 K，不以升高有效温度拟合。对均匀能级分布 `[E0-W/2,E0+W/2]` 积分得到一类通道的净电流。W=0为单能级。分布形状是有效假设，不是目标器件的缺陷谱测量。

两类通道并联时电流相加，正负方向共用能级和权重；每条通道保持零偏置零净流、被动性及完整电压差。用各通道在正向0.1 V的电流归一化为F1/F2，不独立拟合反向幅值。

比较以下候选：

1. 一类分布 + 每圈幅值（band_amplitude）。
2. 两类分布 + 共享混合比例 + 每圈幅值（two_band_fixed）。
3. 两类分布 + 共享端点电流A1/A2 + 每圈比例z：`I=(1-z)A1F1+zA2F2`（two_band_conserved）。这是通道转换、总通道数固定的一标量状态候选，并不代表所有一标量模型。
4. 两类分布 + 每圈总参考幅值和比例：`I=A_i[(1-z_i)F1+z_iF2]`（two_band_free）。具有两个有效状态；A并非未经假设就可等同通道数，z也不是直接测得缺陷浓度。
5. 两个离散能级 + 每圈幅值和比例（two_level_free），检查能量分布是否有额外价值。

共享参数E0在0–1 eV、W在0–1 eV、eta在0.01–0.99；混合logit在−20至20；log10电流在−18至−2 A。报告触界与各初始点结果。这些搜索边界不是材料测量置信区间。

## 数据和评价

使用1.1 V的全部53对。固定网格：SET回程内部0.10–0.30 V，步长0.01；0.35–3 V，步长0.05；RESET初始内部−0.10至−0.30 V，步长0.01，外加幅值<=0.45 V。仅在相邻、单值、有效原始点间插值，不跨缺失点或外推。沿用之前晶体管保护条件；正向保留10倍零偏参考的门槛，负向主分析保留全部正读数以不隐去初始异常。输出选择与来源。

每圈等权；正向低压、正向较高压、负向低压的平方误差权重分别1/4、1/4、1/2。正向低压不再被较多高压采样点稀释。网格插值点不是独立重复实验；没有仪器噪声模型，因此不将拟合差异当统计显著性。

首先报告全53对描述性容量，以及初3圈/其余50圈。所有候选固定四组起点。然后在按整对排除的五折（1–11、12–22、23–33、34–43、44–53）和顺序前35→后18检验中，用训练对估计共享通道；目标圈只用完整SET回程识别局部状态并预测RESET，RESET不进入状态识别。读取目标两支的拟合仅作描述性上限。保存未收敛与触界，不能把失败拟合悄悄当最优物理解。

检验能级积分的64/128节点一致性与独立数值积分；检验平衡极限、被动性、单能级极限、候选嵌套与目标RESET不泄漏。更高节点仅用于数值收敛诊断，不增加物理自由度。

## 可判别内容和边界

拟合改善只表示并行谱的描述能力。只有SET识别的状态能通过RESET预测，才对共享状态交接提供正面支持；这仍不是完整扫描演化方程。比较两坐标和特定一坐标候选不能证明慢变量的唯一数量。共享通道/参数可交换和其他简并须明确。保留初始三圈，不用自由RESET幅值修补。

下一步连接全SET/RESET状态轨迹和先前循环信息；本轮只检验SET末态到RESET初态，不将其称为完整自主周期。

## 提取审查后、拟合前的补充

相邻原始点检查发现部分较高正向电压存在内部电压折返，不能强行插值或删除整圈。保留全部53对及全部低压点，只将有歧义的较高电压格点权重设零；各圈三个窗口重新归一到1/4、1/4、1/2，输出逐点缺失原因。

同阶段推导发现该整个独立固定率能级类满足 `exp(-|V|/VT) <= |I(-V)|/I(+V) <= exp(|V|/VT)`，对任意非负并行谱权重同样成立。在投入完整五折计算前先核对精确界限。如果目标数据明确超界，保留描述性计算说明拟合折衷，并停止把大量交叉验证算力用于已被更强约束否定的类；原计划中的状态预测成绩届时明确标为未运行，不伪装成已完成。这一改变是对新数学约束的响应。
