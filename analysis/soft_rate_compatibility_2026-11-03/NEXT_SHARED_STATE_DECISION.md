# 下一共享状态模型：先筛可成核的竞争通道组件

**本轮已用有限区间筛查拒绝下面这条最简组件在“小soft幅度＋RESET u非减”场景下的可行性，建议停止给它拟合速率。** 名义14/14圈不具单峰硬通道序列；原电流±20%敏感性下仍有7/14圈失败，均有三点高信号证书。不是优化失败，也不宜继续给该组件增加阈值或逐圈参数。

最强见证来自圈15：电压幅值0.075→0.725→0.950 V。在±20%带下，较早/较晚的a下界为9.856206/0.301852 mS，中间a上界只有0.152900 mS，较弱一侧仍高出1.97418倍。因此该场景需要先损失后再增强，无法容纳在“最多先升后降一次”的组件内。此结论不排除所有双向通道或其他保留状态。

以下是**硬通道组件候选，不是已闭合、已通过的完整统一模型**。根任务的新SET预算表明：固定β=6、JS及现有停止面时，任意非减的电压单变量迁移率仍不能兼容早期到达与外扫2 V→返扫4 V的状态余量；保守数值口径下所需/允许速率比约56.5。因此，不能只在裸1R中开启硬通道、在1T1R中保留原soft律，然后宣称数学模型已经解决。完整候选还必须修复由真实保留状态控制的soft驱动、停止条件或读出；本文件不凭空指定一个已成功的耦合函数。

## 为什么先考虑生成/移除，而非仅调纯损失率

权威的已完成圈10预算给出：如果a从前SET读点起只损失，名义/±20%原读数敏感性下，0.975 V外扫软支路分别必须承担至少5.15852/0.465058 mA，要求Γ至少0.969054/0.091518 eV。后者仍为既有series软状态最大Γ的50.25倍；到返扫0.2 V还需至少Δu=12.5628。数值表内反演与4端点直接积分已核实，但这不是实测的软份额或状态。

因此有两条不同路线：允许soft输运真正跨越这段宽状态范围；或者允许硬通道增强/改变读出，使纯损失预算的前提失效。不能一面称u只是小幅调制断裂率，一面又让它暗中承担所需mA级电流。

已核对文献支持把近欧姆联结的生成/消退作为有效候选，并未证明本器件存在两个可分离支路，也未识别金属或离子物种。Nature的VG=1.1 V稳定器件被解释为非丝状；SI对小器件形貌有明确限制。这里的a是有效电导，不是已测细丝尺寸。

## 一个明确、可被拒绝的最小组件

仍使用共用材料读出

\[
I_h=F_{soft}(V_h,u)+aV_h,\qquad 0\le a\le A,
\qquad q(u)=e^{-u}=\frac{\Gamma}{\Gamma+\Gamma_c}.
\]

对 \(V_h\ne0\)，记 \(v=|V_h|\)、\(\sigma=\mathrm{sign}(V_h)\)，定义

\[
\boxed{
\frac{da}{ds}=v\left[
k_n e^{\sigma b}q(u)(A-a)
-k_d e^{-\sigma b}(1-q(u))a
\right].}
\]

在V=0令右端为0。s仅沿用现有的声明路径坐标，不是已识别秒钟；若改用实际时间，速率单位和标定需相应重新定义。

| 量 | 含义与约束 |
|---|---|
| A>0，单位S | 同一材料候选的通道容量；只由训练数据给必要下界，不能给每圈不同容量，也不等同soft支路Ron的倒数 |
| k_n,k_d≥0，路径口径单位V⁻² | 单位局部场下的生成、移除系数；所有圈及两接法共用 |
| b≥0，无量纲 | 固有场方向不对称：正场偏生成、负场偏移除；不由topology、VG或文件相位标签选择 |
| q(u) | 直接使用已有状态坐标，不新增一个可逐圈拟合的门控阈值；其耦合意义是待证假说，不是实测占据率 |

此式在a=0处仍可产生通道，在a=A处不再生成且可移除，避免 \(a'\propto a\) 模型需要人为给每圈一个非零种子。它同时引入了必须认真检验的尾部再生成：低尾不能靠忽略生成项获得。

u必须从之前的SET/RESET和已知分段历史连续保留。若u被重置、被瞬时写成a的函数，或对所有圈只有同一条外部指定轨迹，便不能据此声称已经解决高信号的标量排序反例。真正两状态也不自动保证正确反序。

## 不拟合就能检验的必要条件

负场中令 \(R_-=k_n e^{-b}/(k_d e^b)\)，瞬时平衡为

\[
a_{eq}(u)=A\frac{R_-q(u)}{R_-q(u)+1-q(u)}.
\]

若本次最小候选保持RESET的u非减，则q和a_eq非增；a的导数符号只由a_eq−a决定。a最多先增后减一次：一旦处于a≥a_eq，不能再跨到a<a_eq而重新增长。电压返扫改变速率大小，不改变这个结论；负向扫描的转折点没有改变场极性。

这个条件比“有两个变量”更具体：**多次明显的下降后再生成若确实属于a，就会拒绝这条最小竞争律。** 不能看到失败后给u添加未预声明的回升或按电压分段切换生成规则。

已发生增长后进入损失区时，还需有

\[
a_{eq}(u_t)\le a_t\le I_t/v_t.
\]

这给生成/移除比的条件限制。但现有返扫Γ_eff只是Γ上界；若没有Γ或q的正下界，就可能没有有限的R_-上界。**不能把Γ_eff代入当实际q，制造一个虚假的尾部速率排除。** 同样，A至少要大于可确定的硬电导下界，但数据暂未给唯一A。

## 本轮已执行的训练区间筛查

目标是先检查“避免宽soft状态”的具体场景，而非宣称裸器件必须沿用series状态范围。预声明并保持 \(\Gamma\le\Gamma_{cap}=0.0018213724515\) eV，数值来自已经完成的series探针最大Γ；它是待检限制，不是裸1R的实测上界。

在固定Ron、谱形及原生RESET节点上，计算 \(B_{cap}(v)=F_-(v,\Gamma_{cap})\)。名义及已用±20%原电流敏感性下，a必须处于

\[
L_i=\max\left(0,\frac{(1-\delta)I_i-(1+\eta)B_{cap}(v_i)}{v_i}\right),
\qquad
U_i=\frac{(1+\delta)I_i}{v_i},
\]

其中η=0.003仍为既有数值敏感性包络，不是新误差证书。

实际执行范围明确限定为：

1. 原训练14圈、原2799个评分有效RESET点；不读保留集、不重定义评分、不把缺圈补成连续。此处只检查每条已观测RESET内的形状。
2. 对每圈沿实际采集顺序，判断是否存在某个峰节点p及一条 \(a_i\in[L_i,U_i]\)，使p以前非减、p以后非增。用区间顺序判断即可；不求物理速率，不增加逐圈物理参数。p仅用于必要条件放松，不能冒充预测的峰位。
3. 保存全部失败记录以及最小的高信号“先降后升”见证；≥10 µA只用于证据分级，不替换原评分掩码。名义小波动与±20%下仍不相容的见证分开报告。
4. 区间单峰不可能的结果拒绝上述组件在“有限soft幅度＋RESET u单向”场景下的可行性，k_n/k_d/b/A如何选择都不能修复；没有扩扫这些系数。个别圈在20%带下可行，也仅取得必要条件资格，不说明完整曲线已经拟合。

新脚本`hard_path_single_peak.py`一次完成，用时4.713 s；保留原2799点。±20%下失败标签为1、6、9、12、13、14、15；每圈均有三个电流≥10 µA的谷见证。216组小整数区间的独立序列穷举与6个较长控制通过。执行没有ODE、反演、直接谱积分、拟合或保留集访问，全部计划、区间、峰可行索引和反例保存在同名JSON/MD。

即使拒绝，仍不能推出必须采用宽Γ：也可能需要非单调保留状态、明确随机事件、非欧姆读出或协议因素。这些是不同模型假设，不能作为本次筛查失败后的隐蔽自由度。

## 接触读出是竞争解释，不同时加入

一种明确的读出对照是 \(I_{path}=a\phi_\sigma(V_h)\)，例如固定有效电压尺度下的 \(\phi(V)=V_c\sinh(V/V_c)\)。它能使有限偏压I/V超过低压读值，从而改变原vG_SET上界；这里的V_c是有效非线性尺度，不能未经推导称为已知接触势垒或温度。

但共同、静态的非线性乘子并不能独自改变唯一标量状态的同极性排序。若接触透明度成为独立历史状态，它必须有可检验的演化方程；不能把任意逐点读出函数当“接触物理”。单纯串联被动接触也不能把固定、狭窄soft支路约8.57 µA的供给提升成圈10的14.31 mA。

当前动态扫描不等于冻结状态的多电压读取，直接拿峰前曲率拟合V_c会混入状态演化。现阶段不同时增加接触参数：先筛上述单峰条件，再决定是否需要把非欧姆接触作为独立候选。已有文献仅提供界面/应力动机，不能代替目标器件的接触参数证据。

## 与soft结构修复的边界

两接法必须调用同一读出和同一状态方程；VG通过晶体管KCL改变局部V_h和支路电流。原u律若在a≈0的series条件下仍落在已失败的固定β/JS、非减电压迁移率类，则硬组件无论在裸器件表现如何，都不能补齐统一模型。

“a电流可忽略但仍调制u”也不是免费的出口。若硬贡献满足 \(av\le\epsilon I\)，则a/A≤εI/(Av)；一个平滑有限灵敏度的耦合对u驱动的影响也受此小量限制。若要求它产生大效应，需要独立的强耦合机制或另外保留的界面状态及可观察预测，不能仅把一个任意大系数乘上a/A，也不能由topology直接开关驱动。

因此本轮决策是：**停止当前被拒绝的硬组件；soft驱动修复仍是同等必要、尚未解决的另一项，没有当前可直接推广的完整两状态模型。** 下一次若改变u的单调性、通道读出或事件规则，应明确列为新的模型选择并提出独立必要检验，不能把改动混入旧组件继续扫参。本轮没有许诺“两状态必然治好”。
