# 同一材料模型的联合检验：执行前方案

用户已明确要求实际使用同一模型解释裸 1R 与 1T1R。本轮在恢复的原始工作簿上
检验一个连续瓶颈候选，不按器件类别切换输运/动力学，也不继续优化前三圈。

## 材料方程

令 u 为无量纲有效瓶颈长度，不把它解释成已经测出的纳米间隙：

`V_h = R_on I + V_0 u asinh(I exp(u) / I_0)`, `0 <= u <= u_max`。

u=0 连续退化为欧姆导通；u>0 为非线性瓶颈加串联电阻。局部驱动取
`e = V_0 asinh(|I| exp(u)/I_0)`，包括 u=0 时的连续极限。正偏压使 u 减小，
负偏压使 u 增大：`du/ds = -k_set sinh(max(e-e_set,0)/e_scale)` 或
`+k_reset sinh(max(e-e_reset,0)/e_scale)`，边界只禁止向外演化。
s 是累计指令电压变化（V），不是秒。回扫继续演化，SET→RESET 不换方程、
不重置状态、不用经验比例交接。几何相同不代表不同记录初态相同。

固定电流下，正向阈值由 `I_* = I_0 sinh(e_set/V_0)` 决定：
`I < I_*` 时存在 `u_* = ln(I_*/I)` 的停止点；`I >= I_*` 时可到 u=0。
这是此候选的可证伪数学性质，不是已发现的微观机制。

## 电路与数据

- 两个接法调用同一材料对象。1R SET 为 1 mA 理想限流；1R RESET 无此限流。
- 1T1R 使用已存档的正/负向晶体管曲线，VG=1.1 V；不利用目标电流调晶体管。
- 4 份工作簿从本地 Git HEAD 恢复，来源与哈希见 `shared_hbn_2026-11-03/data_inventory.json`。
- 裸 R 的 96 Ω 有原始低压数据支持，不用 SI Fig.6 的另一示例 1 kΩ 替换。
- 1R 同编号 SET/RESET 暂作为条件配对检验，21/22 对低压电阻相容；24 号另报。
  这不证明每条记录的形成/循环身份、时序或等待条件已明确。

## 联合标定与验收

- 1T1R 第 4–35 圈训练，第 36–53 圈留出；第 1–3 圈保留但不评分。
- 裸 R 按原表顺序前 14 对训练、后 8 对留出，不能称为已确认的时间外推。
- 使用训练中位曲线约束共同材料参数，每种未知历史仅一个初态；不得逐点反演
  状态后把重构冒充预测。保留全部四支预测与失配，不仅报整体误差。
- 裸 R SET 的限流平台占约 72%，训练与报告都单列非限流区，防止平台掩盖失配。
- 同时检查连续状态传播、限流反馈、KCL、步长加密和独立积分。
- 验证数据曾参与历史模型开发，本次留出是本轮内部验证，不是外部盲测。
- 若没有成功联合复现，保留失败结果及具体原因；不将测试通过冒充物理验证。

本候选不模拟限流的 70 µs 响应、寄生电容或原子物种。原文使这些成为有依据的
后续方向，但缺少时钟/协议时，不把电压路径速率伪称秒级动力学。

首个训练试跑后纠正了抽样问题：均匀每三点抽样会漏掉裸 R SET 返扫唯一的
非限流正电压读点 +0.05 V，导致软态终点也得到较小损失。后续保留全部低压
读点，裸 R SET 的非限流正扫、非限流返扫和限流平台分别等权。原试跑结果
保留为 `gap_joint_initial_fit.json`，不作为最终标定。修正只使用训练数据。

## 基于训练失配的一项嵌套修正

完整训练曲线首轮结果显示裸 R 的 RESET 启动过早，而 1T1R 峰值过晚。仅检验
`e_reset(u)=e_reset + e_init exp(-u)` 这一额外全局参数，保持其余方程不变。
共同 `e_reset` 可以下调，新项主要提高小 u（近乎闭合）路径的启动门槛。
单独增加正的新项只会推迟两者，不能声称它自动产生两个方向的改善。

`e_init` 是有效驱动电压，不是已测成核能垒；exp(-u) 的形状及尺度 1 是本轮
假设。此解释受原文完整/不连续导电结构对比启发，但尚非原子证据。e_init=0
恢复原候选。原候选优化以 xtol 停止、optimality 较高，不能据此排除整个原家族。
只按训练目标选择参数；已展示的内部留出不得再宣称全新盲测。
