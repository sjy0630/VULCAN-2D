# 无需拟合谱形的两点 Landauer 必要界

2026-11-03。对 root 提出的窗口界作独立推导和现有见证点核对。结论：**公式正确；
一个 0.9 V 栅压 SET 返扫见证点对，已可否决比固定 lognormal 形状更广的条件
模型类。** 这不等于排除所有统一的 1R/1T1R 方程。

## 1. 点态窗口界及其精确 supremum

能量用 eV，电压数值按 eV/q 换算，τ=kBT>0，分压 a∈[0,1]，b=1−a。
在冻结透射的能量参考系中，μ_L=aV、μ_R=−bV。V>0 时

\[
 W_V(E)=f(E-aV)-f(E+bV)
       =\frac{z(A-B)}{(z+A)(z+B)},
 \quad z=e^{E/\tau},\ A=e^{aV/\tau},\ B=e^{-bV/\tau}.
\]

直接求导：

\[
 \partial_V\ln W_V(E)=\frac1\tau\left[
 a\frac{z}{z+A}+b\frac{B}{z+B}+\frac1{e^{V/\tau}-1}\right].
\]

因为 A≥B>0，z/(z+A)+B/(z+B)≤1，前两项之和不超过 m=max(a,b)。
对 0<V_l<V_h 积分得

\[
 \boxed{\frac{W_{V_h}(E)}{W_{V_l}(E)}\le
 e^{m(V_h-V_l)/\tau}
 \frac{1-e^{-V_h/\tau}}{1-e^{-V_l/\tau}}=:B_a(V_h,V_l,T).}
\]

E→+∞ 的比值趋于 e^{aΔV/τ} 乘末项，E→−∞ 趋于 e^{bΔV/τ} 乘末项。
因此当允许任意 E 时，上式是点态比的精确 supremum；有限能量处不必取到。

对任意非负且偏压无关的冻结透射 \(\mathcal T(E)\)，只要积分有限且低压电流
为正，乘以透射并积分直接给出 F(V_h)/F(V_l)≤B_a。无须透射是 Lorentz、
lognormal、有单个能级或具有已知归一化。所有 a∈[0,1] 的统一宽松界取 m=1。

## 2. 原谱模型是否属于该类

`vulcan2d/shared_spectral.py` 的两个能量差是 ε+ηV 和 ε−(1−η)V。
相对于刚性移动的谱，可改写为固定谱配 μ_L=(1−η)V、μ_R=−ηV，因此 a=1−η，
且 m=max(η,1−η)。**固定 η 的线性刚性能级移位不逃脱该界**。

其每个谱分量的透射正比于

\[
 \mathcal T_\Gamma(E;\epsilon)=
 \frac{\Gamma^2}{(E-\epsilon)^2+\Gamma^2},\qquad
 \partial_\Gamma\mathcal T_\Gamma=
 \frac{2\Gamma(E-\epsilon)^2}{[(E-\epsilon)^2+\Gamma^2]^2}\ge0.
\]

非负能级权重积分保留此单调性。若正向返扫的早期高压状态 Γ_e 与晚期低压
状态 Γ_l 满足 Γ_l≥Γ_e，则

\[
 \frac{F(V_h,\Gamma_e)}{F(V_l,\Gamma_l)}
 \le\frac{F(V_h,\Gamma_e)}{F(V_l,\Gamma_e)}\le B_a.
\]

这不需要知道扫描速率、Γ 的实际值或状态变化幅度。现有 SET 方程令 u 不增、
Γ=Γ_c/expm1(u) 不减，满足该前提。更一般地，只要后态在低压的导电电流
不低于前态，就可用同样比较；单纯“状态是标量”本身不保证这一方向。

## 3. 已有见证点的定量结果

来源是 `cross_gate_lowbias_robustness.json` 中既有最强见证：栅压 0.9 V，
SET 记录编号 12，raw_index 973→983。原端口电压是 **0.28→0.18 V**，
当前统一晶体管映射去嵌入为 **0.2682652183→0.1799326815 V**。电流为
1.08218 µA→6.2081 nA，比值 174.3174。

以下采用 300 K、**任意 η∈[0,1]** 的宽松界，不用拟合谱参数：

| 电流敏感性预算 | 最有利电流比下界 | 相应窗口比上界 | 超界倍数 |
| --- | ---: | ---: | ---: |
| 原值 | 174.317 | 30.5014 | 5.7151 |
| 1% 乘性区间 | 170.883 | 30.6396 | 5.5772 |
| 5% 乘性区间 | 158.111 | 31.1720 | 5.0722 |

预算区间定义是 [I/(1+p), I(1+p)]，不是统计置信区间。保守端点为早期电流
I_e/(1+p)、晚期电流 I_l(1+p)，同时用这些电流重新去嵌入 V_h，未固定名义
内部电压。晶体管反演在两段均单调：减小早期 I 会抬高早期 V_h，增加晚期 I
会降低晚期 V_h，恰好同时放宽窗口界并缩小观测比。这保证上述端点对整个
声明的独立乘性电流区间是最有利于模型的选择。

5% 时内部电压为 0.2688240174→0.1799293156 V。现有固定 η 的名义界更紧
（约 7.7363），但上述否决不依赖它。这里只计算已选两点，不统计其他记录有
多少满足新界，也不把两个不同约束的通过/失败数量混用。

复核脚本 `fermi_window_bound_audit.py` 只做解析式和两个电流的映射，不跑 ODE、
不拟合、不逆解谱态、不搜索新见证。JSON 保存源文件哈希、观测、联合敏感性
端点与条件。源是已有缓存观测，未声称本次重新打开原工作簿。

## 4. 这个结论排除什么、没有排除什么

违例排除的是以下前提的交集：

1. 两点测到的是准静态 h-BN 导电电流，且当前晶体管去嵌入有效；
2. 两点的电子库等温且具有同一固定温度 300 K；
3. 冻结状态具有非负透射，除可规约的固定线性刚性位移外不随偏压重排；
4. SET 返扫的导电状态按上述方向不减；
5. 给定电流敏感性范围及采样顺序有效。

它可将这一条见证从“该固定 lognormal 谱形不行”推广到“上述被动冻结谱类
都不行”，也包括该类中的任意能级分布和任意常数 η∈[0,1]。因单一 1T1R
记录已违例，它当然也阻止这一受限模型类用同一材料定律联合通过两种接法。

以下情形不能由此排除：返扫发生状态回退/松弛；透射谱随偏压非刚性变化；
状态改变 η 或谱中心而失去上述传输排序；不等温或温度随历史变化；额外的
电荷/结构记忆；位移电流或瞬态读出；晶体管映射失配。允许这些并不意味着
它们已经有证据，不能据此自动新增自由参数。若只在两点使用同一个更高恒温，
窗口比约束反而更紧；这也不等于已排除任意电热历史。

所以合理的下一步是核实**返扫状态只能继续 SET**这一物理限制是否成立，以及
低压点是否确属准静态导电电流。继续改变冻结谱形、增加能级混合或扫 Γ 参数，
都不能解决此见证在已声明前提下的违例。
