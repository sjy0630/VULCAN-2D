# 下一候选：保留的接触不对称性改变电荷动力学

状态：物理设计，尚未实现或检验。不能写成已经解释初三圈或已识别的界面结构。

## 从现有证据得到的动机

1. S3/S4低压SET读出近似相同，R3/R4却差约260倍；循环响应向量的顺序检验
   不支持将这一排列简单视为每圈可交换波动。它不定位记忆的物理载体。
2. 全局随机选择四个离散电荷/构型读出，沿用旧参数时支持误差很大；增加有效
   域可使曲线电流等级更细，但仍只有逐点Oracle下限，未得到合法路径概率。
3. 已验证的恒等式：条件(q,m)电流仅依赖
   B=e*N*Gamma_L*Gamma_R/(Gamma_L+Gamma_R)。交换Gamma_L/Gamma_R，B保持不变，
   但电子占据F=[Gamma_L*fL+Gamma_R*fR]/(Gamma_L+Gamma_R)改变，从而改变旁侧
   电荷与构型的动力学。这提供了“读取近似不变、后续极性响应改变”的候选。

## 最小受控假设

引入一个保留的接触配置c，先检验两个有效耦合速率互换的理想极限。电极材料、
电势参考和几何杠杆臂保持目标器件的定义；c描述有效接触耦合的重排，不表示
两种金属材料交换。接触键合变化也可能移动能级，暂时忽略这一反馈是需要
审查的近似，而不是已知实验事实。

设g=ln(Gamma_L/Gamma_R)，两配置g0=−g、g1=+g。用B作为读出幅度，令
A(c)=B/expit(g_c)，则每个条件(q,m)读出严格相同。A=e*N*Gamma_R只是一种
参数表示，交换速率后可能超出旧拟合的A范围；旧边界不是独立测得的速率上界。
不能悄悄裁剪补偿幅度，否则会破坏这个受控比较。

在c固定的扫描片段内，用已验证的连续P(q,m;E)模型传播；发生c转换时，完整
P(q,m;E)必须连续传递，不重新初始化RESET，也不给每圈自由参数。接触耦合c
影响全部通道的速率，已有q,m分布仍可给平滑的常规回线。这里c是一个共同的
随机配置，不能用其平均值代替两种配置的概率路径。

若c主要改变跃迁矩阵元而不改变导电能级能量，c的裸能量可作为独立结构坐标
加入完整能量函数；每条电子库跃迁仍保持原来的局部详细平衡。其电子动力学
消去、零偏分配关系与带偏压电路的能量限制都须重新核对。不能仅凭B恒等式
就宣称整个耦合模型在偏压下满足平衡详细平衡。

## 先做可以失败的反事实，再决定完整模型

第一步不拟合：用两个匹配训练集的已有参数，测试正/反两种接触配置顺序。
先把切换位置固定在第3对结束的零偏边界，检查完整P传递、S4/S3与R4/R3及
整个53对误差。这个人为指定的切换只是机制反事实，不是发生位置或路径概率
的预测；也不能把固定边界的零测度事件当成连续时间概率。

零偏下fL=fR，交换接触速率不改变条件电子占据，便于先隔离动力学路径影响。
若有必要，再检查临近的已知零偏边界以判断作用窗口；不通过就保存失败，
不能只展示最有利的一个边界。核对续传与一段连续模拟的等价性，并作加密。

如果该反事实确实能产生正确方向和数量级，再加入共同能量差及激活势垒约束
的c转换率，将切换位置作为隐随机路径推断。不能在正式模型中写“第4圈切换”，
不能只拟合这一个事件；初三圈、普通SET/RESET和50圈保持共同约束同一组率。
前35圈用于参数和状态推断后，后18圈要给不读取目标电流的分布预测。

整个协议仍使用电压路径单位，不虚构扫描时长、秒级寿命或原子尝试频率。
电荷—接触配置这一概念的新颖性、是否真的对应Au–Ti/hBN/W界面重排都未验证。
尚需与接触幅度改变、能级改变以及随机电荷模型竞争，不预设这一候选必然胜出。
