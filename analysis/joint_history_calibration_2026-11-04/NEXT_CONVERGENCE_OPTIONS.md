## 推荐：先核验 request 57，再做有明确停止尺度的局部坐标检查

1. **先确认小幅改善真实存在。** 对 old 与 request 57 各按原 nominal / refined 精度连续计算 SET4→RESET4→SET5，沿用实际状态传递、完整原掩码、RHS 与独立原生读出检查。比较同精度分数；若数值验证失败，先记录未解决，不启动搜索或自动换求解器。此步最多 12 个相位、90 s 数值预算。
2. **方程、四参数域和单一整段初态不变。** 从验证通过的 request 57 开始，以同一 nominal 精度评价原三相位 mean MSE。另预声明建模目标：SET4、SET5 的 RMSE 均不得超过同精度 old control；RESET5 / SET6 不进入任何约束、排名或选参。超出 SET 目标的完整结果仍保留，不能删点、换权重或伪装成数值失败。
3. **用可复核的有限邻域判断停止。** 在四个归一化坐标上依次采用步长 **0.02、0.01、0.005**。每次完整评价域内的 ±轴方向（至多 8 点），接受满足 SET 目标且使 mean MSE 降低至少 **1e−4 decade²** 的最佳点；有改善则保持步长继续，无改善才减半。最终步长的完整邻域无此类改善，才报告“在声明的坐标网格上未发现进一步改善”。保存每个邻点、可行性与停止原因；这不是连续空间驻点或全局最优证明。
4. **硬上限与最终验证。** 最多 **96 个搜索请求 / 180 s**（失败、越界、缓存均计数）；耗尽就报告“核查未完成”，不追加重启。固定选定参数后，仅对三校准相位做两精度完整验证，最多 6 相位 / 90 s。总数值预算 ≤360 s，读写不计；原每相位 12 s / 最终验证 20 s、超时停块规则保持。只有最终 refined 仍满足 SET 目标且改善超过所见数值差异，才保留“改善”的表述。
