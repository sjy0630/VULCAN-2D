## 原生波形与数据角色

完整命令波形为 **0 → +5 → 0 → −1.7 → 0 → +5 → 0 → −1.7 → 0 → +5 → 0 V**，五相位起始命令电压均为 0 V。

- 校准：1179 原生点，**500 + 170 + 500 = 1170** 评分点，低压 60 点全部保留。
- 延续检查：676 原生点，**170 + 500 = 670** 评分点，低压 40 点全部保留。
- 数据合计：1855 原生点、1840 评分点、低压 100 点；这个总数不是新的校准目标。

原掩码：`isfinite(abs(I_obs)) & (abs(I_obs) >= floor) & (abs(V) > 1e-12)`；SET floor = 1e−11 A，RESET floor = 1e−12 A。它们是评分约定，不是仪器噪声证书。每相位低压组沿用 `original_mask & (abs(V) <= 0.2 + 1e-12)`，外扫和返扫各 10 点。所有低压点留在其原角色的完整评分中，不能删去。

第一个最大 |V| 点归外扫，重复顶点归返扫。每相位有重复顶点与重复末端零点：全序列共 10 个内部零路径连接，另有 4 个相位交接零路径连接。非零重复顶点仍分别计分，零电压点按原掩码不计分。总路径距离 36.8 V（校准段 23.4 V，延续段 13.4 V），非零步长均为 0.02 V；它们不是测量时长。

原电流列均为正幅值，包括 RESET 的负命令区。保留原列，残差比较幅值，模型电流正负由有符号电路决定。有效原观测处模型幅值非正或非有限时判无效，禁止裁剪预测或删除残差。

## 连续状态与延续检查纪律

只允许 SET4 起点有一个段初态，其校准方法由实验计划声明。RESET4、SET5 必须继承同一候选实际前相位终态，不能另设初态、在分支重置或用实测 0.2 V 反演重锚。

**候选选择完成后**，以最终选定候选的实际 SET5 终态初始化 RESET5，再用实际 RESET5 终态初始化 SET6；使用相同选定参数，不新增初态或调参。RESET5/SET6 指标不得回流用于此次候选排名、优化、参数选择或重新启动搜索。

RESET5、SET6 已属于原训练范围，也已出现在先前必要界筛查中。它们只能称为“训练内延续检查”，不能称为原 holdout、独立预测或此前完全未见数据。

路径时钟为累计命令电压距离；重复电压不增加路径距离，不暗中赋予停留时长，同一路径坐标须保持同一连续状态。真实扫描速度、停留和等待仍未知；“无等待演化”只是条件假设。

## 目标、报告与完整合同

**本轮校准目标固定为 mean phase MSE = (MSE_SET4 + MSE_RESET4 + MSE_SET5) / 3。** 只在这三个相位上排名，不能把 RESET5/SET6 或合计 1840 点混入。SET5 已参与本轮校准，不再是未参与参数选择的下一相位检查。

原基线只由已存 RMSE 算术合成：mean phase MSE = 0.263505917437 decade²；其开方 = 0.513328274535 decade；all1170 点加权 RMSE = 0.444364046971 decade。

校准仍报告 all1170 点加权 RMSE、各相位、各分支、各相位低压 20 点指标。延续检查另报告 RESET5 all170、SET6 all500 及各自分支/低20；如汇总 670 点，必须明确只属延续诊断，不能用于排名。

**原统一模型合同仍是 46 对、27023 个残差、20 项跨记录聚合特征；本轮审核未评估或替代它。** 不把原 20 项聚合特征改成逐圈硬误差带。
