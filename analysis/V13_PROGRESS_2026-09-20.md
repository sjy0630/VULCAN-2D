# v0.13 第一轮推进：完整样本验证与跨阶段状态边界

日期：2026-09-20。基于已复现的 v0.12 提交 `8b20aaa`，本轮修改保存在本地工作区。

## 主要结论

本轮保留了原模型的数值结果，同时把此前未评分的循环纳入检验。当前最突出的缺口是**最初几次循环的 RESET 初始低压导电状态，以及后期 RESET 转变分布的变化**。仅把两个归一化状态变量直接接在一起，并不能解决这些问题。

1. 新接口明确采用“充分 SET 后的协议包络换算”，检查模拟末态是否满足这一近似，不再把 SET 与 RESET 的局部包络坐标拼成统一物理态。
2. 全 53 对样本都完成目标排除预测；按循环顺序留出的后 18 对也完成检验，两种模式合计 142 条记录均成功生成并评分。
3. 原 51 对及顺序留出的 80 个可比数值，保留三位小数后与 v0.12 全部一致，最大绝对差 `1.63e-10`。本轮没有通过改公式降低原误差。
4. 84 项测试全部通过（19.556 秒）；前端构建通过，UI 仍使用旧版交互模型。

## 1. 全部样本揭示的误差

以下为同协议 RESET 模式的留一验证，单位 decade。汇总 RMSE 包含所有符合评分规则的非零偏置采样点。

| 评分集合 | SET 汇总 RMSE | RESET 汇总 RMSE |
| --- | ---: | ---: |
| 旧筛选保留的 51 对 | 0.166 | 0.293 |
| 全部 53 对 | 0.167 | 0.370 |
| 原筛选排除的 S2/R2、S3/R3 | 0.180 | 1.200 |

全部 53 对的 RESET 中位回线误差为前向/回程 `0.183/0.125`，相较旧 51 对的 `0.192/0.124` 并未体现出明显恶化。这与汇总逐点误差上升并不矛盾：**中位曲线会弱化少量大偏差循环的影响，必须同时报告逐循环/汇总误差。**

逐循环 RESET 误差最大的三个样本恰为最初三次：

| 循环 | 旧训练资格 | 整段 RMSE | 前向 RMSE | 回程 RMSE |
| --- | --- | ---: | ---: | ---: |
| R1 | 通过 | 0.969 | 1.336 | 0.306 |
| R2 | 未通过 | 1.296 | 1.759 | 0.514 |
| R3 | 未通过 | 1.094 | 1.522 | 0.249 |

因此，旧筛选并没有识别出所有预测困难的循环；不能把“包络可分”当成预测可靠性的保证，也不应再按预测误差删除 R1。

## 2. SET 看似接近，随后的 RESET 起始电流却不同

在固定**端口**电压幅值 0.3 V 处，读取实测 SET 回程及 RESET 前向电流，与其各自旧有效 51 对的中位数比较：

| 配对循环 | SET 回程/其他 SET 中位数 | RESET 前向/其他 RESET 中位数 |
| --- | ---: | ---: |
| S2/R2 | 74.7% | 0.171% |
| S3/R3 | 94.0% | 0.424% |

这不是把正负向电流直接相除：每一列均在相同极性、同一支路和相同端口电压下比较。它说明 S2/S3 在该 SET 回程读点没有呈现与 R2/R3 同量级的衰减，而随后的 RESET 前向电流明显偏低。

从曲线看，R2/R3 的两支路更接近高阻包络，模型却从典型的较高导电初态开始 RESET。该现象提示需要研究跨阶段初始导电幅值及未解析历史；现有数据尚不能区分跨扫描松弛、其他状态变化或测量过程因素，更不能唯一归为某种离子迁移。用户已确认循环配对，不重新把配对问题当成已知未解决项。

![原先未评分的两对曲线](figures/22_v13_previously_excluded_pairs.png)

新接口的饱和检查针对**模拟末态**。本轮全部预测的 `x_end=1`、参考包络相对偏差为 0；这证明接口的近似条件满足，不能据此证明实测器件在每次 SET 后具有同一微观状态。两类问题须分开处理。

## 3. 循环后期变化仍然存在

固定使用前 35 次训练得到的 RESET 输运包络，从实测电流回顾性重建状态。在旧有效样本中：

| 循环组 | 数量 | E50 中位数（MV/cm） | 四分位区间（MV/cm） |
| --- | ---: | ---: | --- |
| 编号 1–35 中有效 RESET | 33 | 0.753 | 0.696–0.816 |
| 编号 36–53 | 18 | 0.870 | 0.803–0.951 |

中位数差为 `0.117 MV/cm`。统一参照后仍有分布变化，不能单靠各折重新拟合的包络差异解释。它仍是由实测电流识别的有效阈值变化，模型没有自主预测这种漂移，也未建立唯一的物理成因。

## 4. 零偏置评分已明确化

原脚本按“预测电流大于零”筛选对数误差，因此会隐式跳过零偏置点。本轮改为先按固定电压规则 `abs(V_app)<=1e-12 V` 分离这些点，并另报实测读数；非零偏置处的无效预测不能据此跳过。

53 个 SET 和 53 个 RESET 分别含 159 个零偏置记录，实测绝对电流中位数分别为约 **0.458 nA** 和 **0.223 nA**。本轮没有擅自扣除这些读数或引入电流偏移去改善拟合。它们不能直接进入零电流静态模型的对数误差，但被完整保留用于后续测量/残差分析。

首次运行暴露了这一评分问题，原始审查及日志保存在工作区的 `verification/2026-09-20/v13/`；修正后重新运行了完整验证。最终报告中无失败或被静默删掉的预测。

## 6. 下一轮研究重点

首先检验 **η 配对换算相较于独立 RESET 初态分布，究竟提供多少额外预测信息**：两者须在相同目标排除划分下重新拟合并对比。这直接检验现有跨阶段连接的必要性。

同时，把最初三次的大偏差与后期阈值上移分开诊断，不用一个新增自由参数同时吸收它们。进一步的输运包络和 SET 驱动简化对照已写入证据表，尚未执行；本轮不声称已解释这些异常的微观成因或已完成整个项目。
