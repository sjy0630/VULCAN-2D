# 未知真实时间与共同路径速率：前提审查

本页只做方程、已有报告和适用范围审查，没有运行模型、调参、生成新表读出、
改动验收门限或读取正在进行的入口剖面轨迹。它不是本次入口剖面的冻结输入。

**结论：若目标是共享真实时间下的材料动力学，则两种接法共用同一个数值的
每电压路径速率，额外假定了相同的有效扫描时钟。这个假设目前没有实验设置
支持。** 但一个整个协议共用的正时间倍率不能修复同一协议内部的系数符号、
积分排序或动力学方向矛盾；它也不改变静态输运容量和不变区域。是否值得
对当前 q¹+a 模型做有限对照，应等入口检查结束后按剩余误差的位置决定。

## 1. 时间变换及不可辨识性

记 s=∫|dVcommand|，真实时间下 dz/dt=F(z,V;θ)，z=(q,a)。则

    dz/ds = τ(s) F(z,V;θ),    τ(s)=dt/ds.

若每个协议均以恒定命令扫速 ν=|dVcommand/dt| 进行，τ=1/ν。按当前
方程将场因子 v 保留在速率中，真实时间系数 kq、ka 的单位为 V⁻¹s⁻¹，
路径系数 κq=kq/ν、κa=ka/ν 的单位为 V⁻²。两个协议共用相同材料 kq、ka
且又要求相同 κq、κa，就要求相同 ν。若仅把路径模型当经验描述，可以直接
假定共同 κ；但不能再把它未经限定地称为已共享并识别的真实物理时间模型。

以裸 1R 的路径时钟为参考，定义本页唯一的协议倍率

    r_clock = τ_1T1R/τ_1R = ν_1R/ν_1T1R > 0.

裸器件保留原右端；串联器件必须同时使用

    dq/ds = r_clock Fq_path(q,a,V),
    da/ds = r_clock Fa_path(q,a,V).

同一 r_clock 乘捕获、恢复、形成和损失的全部项，跨 SET/RESET、外扫/返扫
和连续循环保持一致。它不乘读出电流、不改变 KCL/KVL，也不能只加快 RESET
或只缩放 q 而保留 a。固定材料速率比 κa/κq 不变。

全局时间规范不可辨识：把全部真实材料速率乘 c，同时把所有 τ 除以 c，
观测到的路径动力学不变；等价地，把真实材料速率和所有扫速同时乘 c。
所以即使估计到相对 r_clock，也不能凭 I–V 数据得到绝对秒数或绝对活化频率。
r_clock 还可能与入口状态、材料速率和近稳态轨迹退化，不能把某个最小误差
情景直接报告成测出的扫速比。

若仪器逐点停留、外返扫速度不同或自适应延长切换附近的积分时间，τ(s) 未必
为常数。固定电压等待时 ds=0 而 dt>0，单纯路径方程无法表示这段时间。
未知设置不是任意逐点/逐圈时钟的授权，也不能由电压点距反推出秒数。当前
方程还在 v=0 时令两条速率都为零；引入真实零偏松弛是另一结构假设。

## 3. 已核对的经验积分结论：哪些对任意正 r_clock 不变

已直接读到 `EMPIRICAL_INTEGRAL_RESULTS_2026-11-04.md`、
`empirical_integral_2026-11-04/EXPERIMENT_PLAN.md` 和
`LAMBDA_NECESSARY_BOUND.md`。其数据仅为 **1T1R 的 SET4、RESET4、SET5**，
不含裸器件；固定 a=0 软读出，以反演 u 和指定插值构造

    A = ∫ v exp(λv−u) ds,    B = ∫ v i expm1(u) ds,    y = Δu.

为避免记号冲突，把正支写作 y=Kp A−Lp B，负支写作 y=Kn A−Ln B。
一个整个 1T1R 协议共用的正时钟倍率使四个有效系数同比变化，不改变下表。

| 既有条件结论 | 正的整协议倍率是否能修复 | 不变性前提 |
|---|---|---|
| 固定 λ=0.447… 的 RESET 两外扫窗要求负系数 | 不能；正数缩放不翻转系数符号，η=y/A 对 ρ=B/A 的反常排序不变 | 同一 RESET 协议常数时钟、固定 a=0 重建和 λ |
| SET4 两返扫窗分别要求 J>约3.7726 mA、J<约2.0425 mA | 不能；y 的符号和 B/A 界不变 | 两窗共用 J/常数协议时钟；尤其小窗 Δu 的不确定性仍未被控制 |
| RESET 正系数必要条件 S<R(λ)<T，其中 R=AH/AL、S=BH/BL、T=yH/yL | 不能改变这条条件或已推导的 λ 必要界 | 原两个 y 为正、T>S、原有限节点重建；同一倍率乘两窗 |
| 同一固定重建上，已识别的外扫系数对返扫 Δu 预测方向错误 | 不能靠整个协议的正倍率翻号 | 使用同一系数及同一返扫 A/B；不是改变模型后重新得到的状态轨迹 |

对应的 λ>约2.374 V⁻¹ 必要下界和约5.12 V⁻¹ 必要上界由这些窗口比值及
正权节点推得，不是因为把绝对时钟设为 1 才出现。它们仍不是可行参数区间的
精确识别、真实未知连续轨迹的误差界或当前 q¹+a 模型的约束。加入 a 或改变
恢复阶数后，观测电流对 u 的反演和 A 被积式都改变，原反证不能直接继承。

若把真实时钟写成时间积分，A_time=τA、B_time=τB，R、S、T 不变；若
使用路径积分，拟合的有效系数本身已包含 τ。两种写法给出相同结论。即使
固定系数后直接把预测 y 乘正数，也只能改幅值，不能改其符号。

## 4. 共同 λ 的负 b 根：已证明的代数与尚待核对的来源

在同一协议、SET/RESET 共用时钟且四系数为正时，共享模型要求

    Kn/Kp = Lp/Ln = exp(2b),    Kn Ln = Kp Lp.

因此 b_F=0.5 ln(Kn/Kp)、b_G=0.5 ln(Lp/Ln)，以及共同 λ 的乘积一致性
方程，都对四系数的共同正倍率不变。若后续共同 λ 检验确实仍只用上述同一
1T1R 协议窗口，则负 b 根不能由跨接法 r_clock 修复；在固定重建上出现的
RESET 返扫方向反号也不能由该倍率修复。

**来源核对限制：** 根代理转述了已核对的后续报告结论：“四种有限节点重建
共同根要求负 b，即便放宽 b，RESET 两返扫窗口预测方向相反”。本次读取
`COMMON_LAMBDA_FEASIBILITY_RESULTS_2026-11-04.md` 和该目录
`EXPERIMENT_PLAN.md` 时，云文件内容尚未返回。因此这里只证明上述代数
不变性，尚未独立核实该后续报告是否完全使用同一窗口/同一协议系数及具体
根值；不新增或改写其数值结论。需要恢复该小组原文件后完成来源对应。

以下两种情况必须区分，不能凭“负 b”三个字直接判断：

- 若系数比的分子分母来自不同接法，时钟比会进入系数比；固定 r_clock=1
  的跨接法幅值/共同参数冲突不一定对任意 r_clock 成立。
- 若允许同一接法的 SET/RESET 各有不同时间密度 τ+、τ−，则
  Kn/Kp=(τ−/τ+)exp(2b)，Lp/Ln=(τ+/τ−)exp(2b)，且
  Kn Ln/(Kp Lp)=(τ−/τ+)²。这会改变原共同条件，但它是**另一个极性时钟
  假设**，不是本次单一整协议 r_clock，不能偷偷引入。更一般的窗内非恒定
  时间密度还会改变 A/B 的权重，现有数据没有识别它。

## 5. 当前 q¹+a 模型中哪些障碍仍不能靠 r_clock 解决

1. 静态读出、被动电路、有限状态范围给出的电流容量不受时间倍率改变。
   固定初态满足某不变矩形时，其边界流向在正倍数下不变。此前 qcap 与
   A fcap 容量推导属于这一类，但新估计入口若不满足矩形前提须重新核对。
2. 同一 V、q、a 下，两状态零流线、形成/损失符号及 F_a/F_q 方向比不变；
   固定电压平衡点不变，自治线性化特征值乘同一正数而不改变稳定性类型。
   这不表示整个扫压轨迹不变：V 随路径变化，r_clock 会改变状态跟随速度。
3. 相同协议内依赖两个正积分系数排序/状态变化符号的矛盾，在满足各自
   前提时不能靠公共正因子消除。它不能提供只影响某一极性或某一状态的
   独立时间尺度。
4. 以裸 1R 为参考、只缩放串联器件时，固定材料与裸入口下的全部裸曲线
   完全不变。因此仍然突出的裸器件误差不能通过这个单一相对倍率修复。

相反，尚未被上述不变量约束的动态幅值、开关位置、滞回和尾流，可以随
r_clock 改变；不能把所有“曲线形状不对”都宣布成时钟无效。此前依赖固定 κ
剂量的关断预算、早 SET 下界在被缩放协议中通常需要重算；它们不是无条件
时钟不变量。真实物理时间未知与数学模型内部的条件反证必须分别陈述。

## 6. 是否值得在入口检查后做有限条件对照

**有条件地值得，不应立刻重复旧 alpha 扫描。** 当前两状态 q¹ 结构与旧
单状态情景不同；排查未被证实的共同扫速假设符合“共享真实材料模型”的目标。
但若入口验证后主要误差仍在裸 1R，或者剩余关键障碍已有同协议符号/容量
证明，单纯串联倍率不是优先出路。若两组各自形状已有解释、差别集中于相对
演化速度，则一个预声明、很小且包含 r_clock=1 的固定情景集合有辨别价值。

届时需另行批准明确运行范围：冻结材料、读出、入口、原训练/门限与所有
剩余源；只对串联两状态完整右端同时乘一个固定正数，整段传播；保留失败
和数值验证。不输入秒数，不用极性/分支/逐圈倍率。情景值只表示敏感性，
不能称为物理先验范围。应先验证 r_clock=1 与现有结果一致，避免包装器
改变状态或电路。若入口固定于 r_clock=1 下的估计，所得结论也只是这些
固定入口下的条件敏感性；不能据失败排除联合未知入口与时钟的全部情形。

本页没有选择情景值、调用新模型、扩大参数域或更改当前入口剖面的运行。
