# 场驱动局域高导路径 RESET 条件试验：独立审核

审核日期：2026-11-03。审核人：`shared_kernel_review`。

**结论：实现与所声明的受限试验基本一致，结果不足以将该衰减律升格为统一 1R/1T1R 模型。** 保留它作为有明确失败项的机制筛选对照有价值；下一步应先检验“前 SET 导电态只改变幅度、所有圈共享同一归一化衰减形状”这个假设，而不是扩大参数搜索或直接拼接完整双状态拟合。

## 留一评估：折内正确，但不是端到端无泄漏验证

新增三个参数 `Vr, log10 κ, log10 Γ_leak` 每折仅使用其余 13 条 RESET 拟合；三个起点均是固定值，没有用全训练最优解暖启动。最优起点按该折训练目标选择，没有查看被留出 RESET 进行起点选择。

条件模型的被留出圈输入只取同圈先前的 SET 返扫 50 mV 电导；被留出 RESET 仅评分。对照的常量电导是该折其他 13 圈 SET 电导几何均值，独立复算确认没有混入被留出 SET。条件输入属于合法的已观测前态信息，不能当作未知未来 SET 的预测。此阶段无 a0 截零，且初始总电导与条件输入的数值差为零。

**仍须明确外层预选信息：** Ron=58.463 Ω 来自原 14 圈读态上界的预先选择，包括当前被留出圈；背景谱形也沿用了此前已选定的模型。`RON_CALIBRATION_SCOPE.json` 明确这个值是 `0.95 × min(V/I)` 的诊断点，而非独立外部校准值。最终谱形细化主要用系列器件训练圈 4–35，但其选择历史及 Ron 不是本次折内重建的完整流程。

因此准确表述是：**“固定全训练预选骨架后，只对三个新增参数重拟合的内部条件 LOO”**。这不是嵌套交叉验证，也不是新器件、按时间向前或原保留集泛化误差。所有圈来自同一物理器件，其他训练圈可以晚于被留出圈；不能将 2799 个点当作独立样本声称显著性。两个模型共用骨架，使其受限对照仍有描述价值，但不会消除绝对误差估计的外层选择偏倚。

另一个仍未验证的物理假设是：SET 返扫 50 mV 读到的 a 与 RESET 起点 a0 之间没有进一步演化。读点不是严格的 SET 结束时刻；最后 50 mV→0 的扫描及未记录的间隔没有由模型传播。应将它称为“以前 SET 读态初始化”，不应称为已经证明完整边界连续。

## 解析 D、极性、掩码与特征

取 `v=|V|`，裸 RESET 的 `s` 为累计扫描路径，单位 V。在单调外扫及返扫、忽略端点停留的条件下，

`da/ds = -κ (v-Vr)_+ a`

对应外扫 `D=(v-Vr)_+²/2`，返扫 `D=(Vmax-Vr)_+²-(v-Vr)_+²/2`。两分支在峰端连续，D 非减，a 非负且非增。κ 的单位为 V⁻²，绝非 s⁻¹；重复的峰端电压点没有增加路径长度，也没有被隐含当成等待时间。独立正部驱动积分检验与闭式 D 相符。

对仅有 a 路径的电流，外扫峰位为 `min[Vmax,(Vr+sqrt(Vr²+4/κ))/2]`，返扫 `d(av)/dv=a[1+κv(v-Vr)_+]>0`，因此沿返扫扫描方向下降。这些式子不直接等于加入非线性背景后的总电流峰位。

背景正确使用负极性表预测 RESET，用正极性表的 +50 mV 电导扣除 SET 背景，没有擅自假设背景严格奇对称。所有 RESET 保留其存储的电流幅值约定，不加 1 mA 限流，也不把 SET 限流复制到 RESET。

2799 点掩码只由观测决定：非零电压且观测幅值至少 1 pA。除每圈两个零电压点外，只有第 7 圈返扫索引 200 低于原评分阈值而被排除。没有按预测误差删点，也没有把阈值当成实测仪器噪声下限。汇总直接合并所有合格点，不平均各折 RMSE。

四项特征沿用原定义，判断对象是 14 条预测的中位数；逐条落入区间的数目只是描述。冻结经验区间由原训练数据产生，不是置信区间或每圈必须满足的硬区间。通过四项中一项只表示这个 RESET 子集的结果，不是原完整 20 项共同模型合同的通过率。

## 90 次求解与边界

90 次是 `2 个模型 × (1 次全训练 + 14 次留一) × 3 个起点`，并非 90 个不同的全局搜索起点。三个起点都固定 `Vr=0.5 V, log10 Γ=-6.3`，只改变 log10 κ。

所有 90 次都记录了有限结果与成功标志，没有评估上限停止；全部由 `ftol` 触发停止。各拟合内三个起点的残差平方和差不超过 `3.6e-6`，说明这三个预声明起点给出很一致的目标值。但保存的最优性值约为 0.19–0.51，不是满足 `gtol=1e-8` 的证明；不能据此声明全局最优或严格驻点证明。

90 次均在 Vr 下界附近：Vr 最大约 `2.43e-14 V`；κ 与 Γ 未贴边。它说明这个受限模型偏好没有正电压阈值的平滑损失。**不能把 Vr≈0 称为测出了物理临界场，也不能把它用于证明不存在激活势垒。** 正阈值未被当前拟合识别；允许负 Vr 会改变机制含义，不应为减小误差自行扩域。

## 结果实际说明了什么

| 项目 | 前 SET 条件模型 LOO | 常量输入 LOO |
|---|---:|---:|
| 全 RESET RMSE / decade | 0.896634 | 0.918556 |
| 外扫 RMSE / decade | 1.094327 | 1.129541 |
| 返扫 RMSE / decade | 0.640370 | 0.641341 |
| 全点中位倍数误差 | 2.66951 | 2.72162 |
| 原四项聚合门槛 | 1/4 | 1/4 |

前 SET 条件输入降低 RMSE 约 2.39%，MSE 约 4.72%；14 圈中 10 圈平方误差下降、4 圈上升。这是有限的描述性改进，没有显著性或独立泛化结论。0.896634 decade 的 `10^RMSE≈7.88` 也不等于中位误差倍数；原报告正确分开了两者。

三个失败项都不能被较好的低压电阻抵消：

- 条件 LOO 返扫 0.2 V 电流中位数 `7.96e-10 A`，超过区间上限 `4.77e-10 A`。
- RESET 峰值中位数 `2.59 mA`，低于区间下限 `3.11 mA`。
- 峰位中位数 `0.375 V`，低于区间下限 `0.475 V`。

低压电阻 `99.56 Ω` 落在原区间内，但这项与作为输入的 SET 低压电导紧密关联；它的通过并不等价于独立解释了 RESET 断裂过程。

本阶段保存轨迹还给出两个比总 RMSE 更有信息的限制：

1. **幅度与峰位：** 全训练条件解 14 圈峰位全部是 0.375 V，观测峰位为 0.45–0.975 V。模型峰处背景占比最多约 `3.7e-6`，因此此解中 a0 主要控制幅度，共同 κ/Vr 固定归一化形状和峰位；前 SET 幅度条件无法生成观测峰位变化。LOO 的轻微参数变化也只产生约 0.375–0.400 V。此处是这一衰减假设的失败，不是排除了所有场驱动损失。
2. **尾部与背景：** 全训练解在返扫 0.2 V 已有 `a/a0≈2.58e-19`，总电流的背景占比大于 `0.999999999998`。因此该处偏高由冻结背景承担，继续增加 κ 已几乎无法降低尾流。应先检查背景曲线/状态假设，不能把这个失败解释为“路径还没断干净”。

## 对统一模型扩展的建议

不建议现在把这条三参数衰减律作为已验证扩展接入完整统一模型。加性 `F_soft+aV` 仍是可以保留的候选输运结构；失败的是本次“共同静态背景 + 前态只给 a0 + 所有圈共同电压路径衰减”的组合，不能据此排除整个加性模型族。

下一步优先进行一个小而可证伪的训练数据诊断：在背景可忽略或明确量化的电压区间，考察

`h_i(s) = [I_i(s)-F_soft(v(s),Γ_leak)] / [v(s) a0_i]`

是否可以由相同、非增的归一化损失函数解释。当前律要求 `h_i=exp(-κD)`，在可取对数处 `-log h_i=κD≥0`，且所有圈共用同一形状。必须保留背景相减为负、h>1、局部增大的位置，不能截零后再取对数使其“符合”；也不能把未知测量散布直接宣布为仪器噪声。这个检验首先区分“前态幅度足够、衰减形状需要修正”与“还需要另一种状态/非确定性/协议差异”。它可以只用原训练集，不需要打开保留集或重跑大拟合。

若这一步支持共同形状，再提出受约束的最小损失律；若明显不支持，先查证峰位/归一化衰减是否与已测前态或其他可观测特征有关，再比较状态耦合与随机模型，不能直接给每圈添加自由 κ 或阈值。

最后才进入完整统一模型所必需的检查：共同材料方程给出 a 的形成与损失；a 从 SET 经边界连续传递到 RESET；串联接法使用负载求解后的材料电压/总电流；1T1R 的 a≈0 必须由同一动力学产生，不能按拓扑手工关闭。时间、扫速、间隔未记录时，电压路径率仅是协议条件下的有效参数，不能声称已辨识热时间常数、离子速率或真实瞬态过冲。

文献允许对强应力裸器件考虑局域高导路径，但此试验不证明金属丝/缺陷种类，也不把文献中稳定 1T1R 的非丝状解释改写为同一已证实金属丝机制。
