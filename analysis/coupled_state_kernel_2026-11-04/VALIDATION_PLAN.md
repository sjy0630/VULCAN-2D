# 联立两状态材料内核：首次有限实现检验

状态：执行前计划。此阶段不拟合参数，不宣称改善实验准确率。旧单状态文件和已保存结果不改动。

## 固定模型

共用同一个材料对象：I=Fsoft(Vh,Gamma(q))+a Vh；q=exp(-u)，Gamma=Gamma_c q/(1-q)。沿用已有 q² 恢复项（明确的动力学结构选择），不是纯坐标变换。

令 sigma=sign(Vh)、v=abs(Vh)、i=abs(I_total)，

q' = kappa_positive v [(i/J_positive) exp(-(1-sigma)b)(1-q) - exp((1-sigma)b+lambda v) q²]。

a' = kappa_a v [exp(sigma b) q(A-a) - rho exp(-sigma b)(1-q)a]。

J_positive=J0 exp(-2b)，kappa_q=kappa_positive exp(b)。两个转变共用 b 是额外待检的简约假设。内部可积分 (u,x=a/A)，但不得剪裁状态；相位交接同时传递 q、a。

两接法只更换外电路。反馈统一使用总材料电流及实际局部电压。裸 SET 理想限流必须降低实际 Vh，不能只截断输出电流。

近零采用谱表最低局部电压 delta 处的支路斜率向零线性延拓，全程积分两状态；旧 soft-only 省略界不适用。这是数值延拓，其对原谱的偏差须独立检查。

## 判据和运行控制

- 数值精度建议 nominal：rtol=1e-7、atol_u=1e-9、atol_x=1e-11、max_step=.02 V；refined：1e-9、1e-11、1e-13、.01 V。最终 API 对应值在冻结 runner 中明确。
- 原生禁用 a 与旧控制、两精度的电流差：评分点最大 log10 差 ≤3e-4 decade。状态精度差 abs(delta u)≤1e-3、abs(delta x)≤1e-5。
- 独立根电流差 ≤1e-18 A + 1e-7*abs(I)，电压差 ≤1e-9 V；同时核验 KCL/KVL、限流及局部／总电流一致性。
