# 守恒电荷反馈能否自行提供零偏置记忆？

本检查针对四态候选及各有独立旁侧电荷的谱积分，不是对所有陷阱/结构动力学的否证。每个位置的总尝试率与偏压、占据无关；热激活信息只在Fermi加电子概率内。未加入额外结构势垒。

精确一阶矩方程为`dot n=a(F0−delta_F*m−n)`及`dot m=b(c0−delta_c*n−m)`，其中`a=Gamma_L+Gamma_R`，`b=Gamma_t`，`delta_F=F0−F1>=0`，`delta_c=c0−c1>=0`。二值闭合无需独立占据近似。衰减矩阵的两个正衰减率为

`lambda_fast,slow = [a+b ± sqrt((a−b)^2+4abP)]/2`，`P=delta_F*delta_c`。

慢率用`ab(1−P)/lambda_fast`稳定计算，分母`1−P`沿用已验证的正项展开，避免强阻塞时相减。有限温度下仍有唯一平稳均值；小慢率允许长弛豫，但不等于多个稳定平衡。

对任意a,b>0与0<=P<1：

`1−sqrt(P) <= lambda_slow/min(a,b) <= 1`。

证明下界：取a>=b，需证明`sqrt((a−b)^2+4abP) <= a−b+2b*sqrt(P)`；右平方减左平方为`4b(a−b)*sqrt(P)*(1−sqrt(P))>=0`。a<b对称。

零偏置时F0=f(E_d)，与接触比及位置无关；故`P0<=delta_F<=f(E_d)`。对于支持[E_min,E_max]的独立能谱，每条通道均满足

`lambda_slow(0)/min(a,b) >= 1−sqrt(f(E_min))`。

同一偏压无关尝试率下，任意电压的`lambda_slow(V)<=min(a,b)`，所以

`lambda_slow(V)/lambda_slow(0) <= 1/[1−sqrt(f(E_min))]`。

这给出**相互作用所能提供的零偏置慢、加偏压快的慢模态分离上界**，不需知道绝对速率或扫描时间。它不是对任意初态每条观测电流的开关时间上界，也不包含结构能量变化、占据相关矩阵元或其他动力学。若E_min显著为正，上界接近1；令Gamma_t整体变慢只会一起减慢相应模态，并不自动建立写入/保持分离。

新增`charge_moments.py`按分段常电压准确传播两个平均占据，连续跨越正负扫描，不按RESET边界重设状态。已与完整四态生成矩阵的指数传播比较。时间输入是Gamma_R*delta_t，尚未校准成秒；它是状态传播器，**不是已经接好位移电流与晶体管的瞬态端口模型**。

对已拟合参数的应用必须限定到那些选中解；参数触及先验边界或其他等好解未排除时，不能推广为整个模型类都无记忆，更不能推出目标器件没有电荷记忆。
