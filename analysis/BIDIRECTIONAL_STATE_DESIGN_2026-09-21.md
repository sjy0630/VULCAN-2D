# 下一阶段：受能量与电路约束的双向状态模型

状态：候选设计，尚未实现或拟合；不能作为已验证的器件机制。前一阶段结果见`RESET_HISTORY_RESULTS_2026-09-21.md`。目标仍是统一解释原始电学曲线并提供可检验的物理证据，不以增加一个拟合核替代目标完成。

## 必须继承的事实

- 1.1 V正常RESET可以被多种单向历史核近似描述，但输运曲率和状态衰减严重简并，没有选出唯一机制。
- 固定被动负载和单向降低导电能力预言同电压处回程电流不高于去程；254条负向曲线中有5条强烈违反这一顺序。
- 严格持续阶跃检测保留5条先下降再恢复的曲线。大幅电流上升本身不是导电状态增强的充分证据。
- 有限步进上界进一步检验全部7个上升阶跃：其中5个对全部指定处理仍超界。1.3 V第23条在1.08→1.09 V幅值变化时，固定/减弱导电能力只允许电流升至1.392 µA，实测61.158 µA；对指定的晶体管/零偏敏感性处理仍至少超界27.61倍。
- 0.9 V第6条的两个上升阶跃未通过上述稳健超界判据，必须保留。不能把两个不同的“5条/5个”集合混为一谈。
- 最初三个SET→RESET配对的强极性差异、S3/S4正向读取近似相同但负向读取差异约260倍、后期转变漂移仍未解释。

## 先检验最小双向状态，不预设状态数量

设`s`为可导电配置的占比，尚不赋予具体离子、空位或几何宽度意义：

`ds/dt = k_01(V_h,s)*(1-s) - k_10(V_h,s)*s`。

使用共同过渡态能量`G^‡`和两个构型的能量`G_0,G_1`定义正反速率：

`k_01 = nu*exp[-(G^‡-G_0)/(k_B*T)]`；

`k_10 = nu*exp[-(G^‡-G_1)/(k_B*T)]`。

在这个单通道、共同前因子的假设下，`ln(k_01/k_10)=-(G_1-G_0)/(k_B*T)`。若引入简并度、不同通道或不同前因子，必须显式修改自由能/局部详细平衡关系，不能分别任意拟合两个指数。

候选按物理假设逐步增加：

1. 单一带电构型坐标、能量随有符号内部电压线性倾斜，过渡态的电荷投影位于两构型之间。这类最小跃迁的正反势垒对同一电压方向响应相反，未必能同时解释低压削弱与高压恢复；仍应保留为可被排除的对照。
2. 若前者失败，检验有明确定义的共同势垒降低，例如过渡态相对极化率引入的二次电压项，或具有独立温度方程的电热反馈。仅用电压或功率代理拟合速率不能直接称为温升证据。
3. 只有当单状态候选在完整扫描及交接上系统失败时，才增加缓慢激活/稳定性坐标。先降后升和回线方向变化本身不证明必须两个标量状态。

所有势垒在所用电压范围内应保持物理定义，不得各自截断为零来掩盖参数越界，因为分别截断可能破坏原定的正反速率比。若使用无势垒极限，须另写一致的动力学。

## 电路、输运和状态必须同时闭合

- 用预测电流和实测晶体管查表正向求解`V_app=V_h+V_T`。跃迁改变分压，可能反过来增强或减弱跃迁；不能把目标实测电流作为动态驱动。
- 固定状态的输运核必须由低压、稳定支和跨极性共同约束；先沿用此前较可接受的输运候选作竞争，报告有效参数，不将其对应的状态轨迹当作实测结构。
- 同时保留一个接触/电荷状态改变读取能力的候选。它与结构形成/消除可能在准静态I–V上等价，应明确可辨识组合，不能用给变量换名字完成机制区分。
- 首先检查数学上能否生成下降—恢复和随后返回状态；示意参数下的生成能力只是实现检查，不是实验验证。
- 继而检验完整SET→RESET→下一SET交接，不为每次目标RESET重新指定独立初值。暂时只做去程条件化预测时，须在任务名称和结论中明确。

## 时钟与保持约束

现有记录缺扫描速度、驻留和间隔。恒定扫描速度假设下可在电压路径域实现动力学，但识别的是`nu/r`等组合，不能给出绝对寿命、势垒或尝试频率的唯一估计。重复电压点不能自动算作已知时长。

原文+0.1 V读取下数小时保持是文献约束，不等于这些原始曲线的同状态零偏保持测量。拟合候选须计算零偏/读偏速率及所需时标，并区分同器件直接检验与跨实验条件比较。保持证据与扫描条件不匹配时，不得强行宣称已通过或已被否证。

## 预先约定的评价与可区分预测

- 保留全部正常和异常循环；报告全部数据结果，以及早期、后期和特殊事件的分组结果。分组属于观察后的研究，不能冒充外部盲测。
- 使用整圈留出和按时间顺序预测；严格记录目标中哪些点参与状态初始化。数据筛选不根据模型残差进行。
- 0.9/1.3 V端点为1.5 V，1.1 V为1.7 V，器件身份/采集顺序待确认。分组分别检验后再讨论可转移性，不能先假设为同器件纯栅压干预。
- 在合理参数范围内检查：负向最大幅值是否改变返回状态；扫描速度是否移动下降/恢复位置；停止于恢复前后是否产生不同低压读取；同电压等待是否继续改变状态。现有数据能检验的部分先做，其余作为可区分预测，不称为已验证结论。
- 物理支持至少包括模型类排除、参数可辨识性、未参与初始化的数据预测和独立文献相容性。当前上界的数学形式及其具体应用仍需文献新颖性检索。

不把“界面离子交换”“软退化”“纳米间隙”本身列为本项目新发现；这些已经出现在目标Nature原文。可能的新贡献是共同约束下的定量机制与可检验预测。
