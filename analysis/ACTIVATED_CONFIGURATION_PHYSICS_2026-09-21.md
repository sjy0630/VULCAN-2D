# 电荷读取与保留构型的能量一致性

这是一个待数据检验的有效模型。下面证明其条件热力学一致性，不证明其就是
目标器件的微观机制。温度固定 300 K，能量以 eV 表示，`V_T=kBT/e`。

## 1. 同一个能量函数

每个导电能谱通道有导电占据 n、单库旁侧占据 m 和保留构型 q，各取 0/1。
导电谱通道之间独立；电路负载把其总电流共同耦合起来。令内部器件电压为 V，
左、右电子库化学势分别为 V 和 0，旁侧位点仅与右库交换。

`E_qnm(V) = q(G01-d*V)`
`           + n[E_d+(1-q)*DeltaEd+(1-x_d)*V]`
`           + m[E_tq+(1-x_t)*V] + U*n*m`。

导电位点和旁侧位点的电荷跃迁都由该能量差与对应库的 Fermi 因子确定。
因此两个位点之间的 U 反馈相互对称，不能只让陷阱影响导电位点而忽略反作用。
局部构型变化的能量差自动为

`DeltaG_nm(V) = G01-d*V-n*DeltaEd+m*(E_t1-E_t0)`。

构型过渡态位于两构型平均能量之上 `B-lambda*V²`，于是两个方向满足

`log k01_nm = ell0+lambda*V²/V_T-DeltaG_nm/(2*V_T)`，
`log k10_nm = ell0+lambda*V²/V_T+DeltaG_nm/(2*V_T)`。

两式的比严格为 `exp(-DeltaG_nm/V_T)`。电场在共用鞍点上的二次项同时加速
两个方向，不得单独用它更改平衡比。该鞍点形式仍是条件假设；详细平衡并不
唯一决定过渡态高度、对电荷的依赖或其偏压曲率。

## 2. 必须保留快速联合概率

当 q 固定时，快速电子网络有四态 `(n,m)=(0,0),(1,0),(0,1),(1,1)`。
记导电总尝试率 `a=Gamma_L+Gamma_R`、旁侧尝试率 `b=Gamma_t`，导电条件
填充概率 F0/F1，旁侧条件填充概率 c0/c1。由原四态主方程可得，例如

`(a+b)*p00 = a*(1-F0)*(1-<m>) + b*(1-c0)*(1-<n>)`。

其余三个联合概率有同样的正项表达，已用独立生成树稳态解检验；没有采用
`p_nm=p_n*p_m` 的独立占据假设。有效构型转移率为

`K01 = sum_nm pi_nm(q=0)*k01_nm`，
`K10 = sum_nm pi_nm(q=1)*k10_nm`。

它们平均的是指数速率，不能先平均 DeltaG 再指数化。相同理由，输运平均的是
各构型及谱通道的电流，不能将平均 q 或平均能级代入非线性读取公式。

## 3. 零偏的精确配分函数关系

V=0 时两个电子库平衡，令 `Z_q=sum_nm exp[-E_qnm(0)/V_T]`，则
`pi_nm(q)=exp[-E_qnm(0)/V_T]/Z_q`。代入上式得到共同分子

`C = exp(ell0)*sum_nm exp[-(E_0nm+E_1nm)/(2*V_T)]`，

以及 `K01=C/Z_0`、`K10=C/Z_1`，故

`K01/K10=Z_1/Z_0`，`P(q=1)/P(q=0)=Z_1/Z_0`。

因此零偏构型分布与完整八态玻尔兹曼分布一致，而不是由条件平均能量差
构造的近似分布。八态生成矩阵的每条微观边也满足详细平衡。非零偏下电子
网络受外部电源驱动，不能把条件稳态概率仍当成单一平衡玻尔兹曼分布。

## 4. 连续状态、电路与适用界限

传播方程是 `dq1/ds = K01*q0-K10*q1`，`q0+q1=1`；s 是记录的外加电压
路径长度，单位 V。数值上分别存储 q0/q1，避免极小互补概率在相减时丢失。
首点统一 q=0 是未测初态的假设；后续所有扫描只接续先前状态，不读取目标
电流或在 RESET 前重新初始化。重复电压没有已知停留时间，赋零路径长度。

速率单位为 V^−1。若实际扫描速率为 r，则 ell0 代表
`ln[(nu/r)/(1 V^−1)]-B/V_T`。共同路径时钟是固定 DC 协议的有效假设；
尚未验证 SET/RESET、转折点或扫描间隔有相同的实际时间映射。未知绝对
时标不能阻止本协议内的比较，但不能据此报告秒级寿命、独立 B/nu 或跨扫描
速度预测。本轮没有引入未知等待时间作为每圈可调参数。

模型电流通过独立的正/反晶体管查表满足串联电流守恒。若有多个负载交点，
按标量电容负载吸引域及上一个内部电压选支，并报告多根；不得按实测目标
电流挑根。该准静态处理假设电子稳态与电路弛豫快于构型变化。

八态生成矩阵在电子速率不断增大的极限下逼近此降阶动力学，且另用自适应
ODE 和直接电路求根核验连续扫描。但这只验证了近似的数学极限；没有独立
测得目标器件的电子/结构绝对时标分离。慢构型转换后的电荷重新分布会产生
额外瞬态电流，本模型忽略这些高阶项，不能冒充脉冲或位移电流模型。

## 5. 不能从一致性推断的内容

正确的详细平衡、正概率和电路守恒是模型可接受的必要条件，不是对某种空位、
离子或界面反应的鉴定。共同鞍点、两种有效构型、独立能谱通道、固定旁侧尝试
率以及初始 q=0 都需要面对数据。若完整循环预测失败，只能判定此条件候选
未通过，不能排除所有带电构型模型，也不能由失败直接推出必需的状态数。
