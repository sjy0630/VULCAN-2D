# VULCAN-2D v0.5：协议纠正、CAFM 空间先验与跨栅压留出检验

日期：2026-07-26

## 这一步实际推进了什么

这次没有继续增加一个只能降低训练误差的隐藏变量，而是把三条新证据变成了
可运行的约束和可失败的检验：

1. 将裸 1R SET 的限流从错误的 10 mA 改为老师确认、原始曲线也直接显示的
   1 mA，并在测试中强制检查模拟电流不得越过该值；
2. 将 sputtered h-BN CAFM 导电斑面积分布变成一个**可选的几何空间先验**，
   同时保留“面积不等于电流、不等于阈值、不等于细丝直径”的边界；
3. 去掉全部 1.1 V 直接栅压锚点，只保留 0.9 V 和 1.3 V，再预测 1.1 V，
   从而第一次把栅压依赖从“拟合三条曲线”升级为“允许被留出数据证伪”。

数值结果见 `analysis/v5_validation_summary.json`，实现见

## 1R：协议变量现在与数据闭合

22 圈裸 1R SET 的最大电流中位数为 `0.999990 mA`，确认其平台是 1 mA。
模型修正后中位数为 `1.000000 mA`，且每一圈都不超过限流。1R SET 中位曲线
的 forward/return RMSE 从错误协议下的 `0.752/0.959 decade` 降到
`0.285/0.000 decade`。

这项改善不能称为“模型预测成功”：1 mA 是实验协议输入。但它证明原来 1R
回扫的大误差主要来自协议写错，而不是必须再发明一种导电机制。修正后仍由数据
独立约束的量包括约 `2.70 V` 的硬路径进入电压和约百欧的导通路径尺度。

对应的物理解释是：

```text
I_raw = (1-h) I_pre + h |V| / R_hard
I_terminal = min(I_raw, 1 mA)
```

`h` 表示端口电学进入强贯通/强渗流工作区。它仍不能被唯一命名为 Ti、Au 金属
细丝或硼空位通道；化学归属需要状态分辨的结构证据。

## CAFM：已经能约束空间异质性，但不能直接决定动力学

面积文件包含 4866 个分割导电斑、59 个面积 bin（21 个非零 bin）。按斑点
个数加权得到：

| 量 | 数值 |
|---|---:|
| 面积中位数 | 1759 nm2 |
| 等效圆直径中位数 | 47.3 nm |
| 面积 P90/P95 | 4575/5982 nm2 |
| 等效圆直径 P90/P95 | 76.3/87.3 nm |
| 面积分布 CV | 0.860 |

为了与 `K=10` 的粗粒化模型连接，程序把斑点按面积排序后分成十个近似等数量
分层，并以各层占总投影面积的比例构造 `w_k`。得到的等效 patch 数

```text
N_eff = 1 / sum_k(w_k^2) = 6.86
```

这说明“少数较大空间组贡献较多面积”是可由数据支持的。它不说明器件只有
6.86 条通道，也不说明 CAFM 的约 47 nm 是原子级导电丝直径。

接入该先验后，1.1 V SET forward/return RMSE 从 `0.214/0.115` 变为
`0.196/0.108 decade`，有轻微改善；RESET 则从 `0.219/0.427` 变为
`0.460/0.410 decade`，前向明显变差。这一结果很重要：**面积异质性有用，但
面积本身不足以决定 RESET 阈值与局部电流密度。**

因此当前把 CAFM 只写入几何权重：

```text
G_soft = I_s sum_k w_k [(1-phi_k) exp(xi_k) + phi_k G_on]
```

其中 `w_k` 可由 CAFM 面积分布约束；`xi_k` 仍代表局部陷阱/电流密度差异，
`phi_k` 与阈值仍由电学约束。模型刻意不假设“更大的斑一定更早 SET/RESET”，
因为当前 CAFM 文件没有逐斑的开关阈值或电流。

Nature Supplementary Note 1 进一步收窄了 1T1R 软工作区的解释：作者用无 h-BN
对照、不同顶电极和电流形态等证据，把 `V_G=1.1 V` 的渐进高阻转变归因于软
退化 h-BN 与电极界面之间的离子交换，而不是 TiOx 单独开关；`V_G=1.5 V` 时则
观察到线性 LRS 与非线性 LRS 的随机切换，说明较高允许电流可使器件在丝状与
非丝状工作区之间跳变 [@Zhu2023Hybrid]。因此当前 `phi_k` 最适合解释为“局部
界面离子交换/层间缺陷重构所形成的高传输连接度”，而不是直接等同为硼空位数；
`h` 则保留给更强应力下的贯通工作区。

## 跨栅压留出：SET 可以插值，RESET 仍然缺少统一电路解释

留出检验把所有显式 1.1 V 参数替换为 0.9/1.3 V 端点的 log-linear 插值。
这不是外推，只是测量窗口内的插值检验。

### SET

- 端点预测 1.1 V 电流上限：`58.69 uA`；直接测量锚点：`51.46 uA`，高约 14%；
- 留出模型的 1.1 V SET forward/return RMSE：`0.217/0.090 decade`；
- 使用 1.1 V 直接锚点时：`0.214/0.115 decade`。

因此 SET 的整体曲线对栅压可以由一个平滑关系近似描述。它还不是独立晶体管
模型，因为电流上限仍来自三档 1T1R 曲线，而不是 Fig. 2b 的 `I_D-V_DS-V_G`
负载线。

### RESET

- 端点预测 1.1 V 峰值锚点：`3.025 uA`；直接测量锚点：`3.774 uA`；
- 留出模型在 -0.2 V 的初态电流为 `0.0566 uA`，实测为 `0.361 uA`；
- 留出模型回扫 HRS 为 `0.104 nA`，实测为 `1.163 nA`；
- forward/return RMSE 从直接锚点模型的 `0.219/0.427` 恶化到
  `0.977/1.058 decade`。

这证伪了“RESET 的所有栅压系数只需在两个端点间平滑插值”的简化。当前
RESET 实际使用了多组栅压相关经验因子（connected/off scale、field coefficient、
drive scale 和 stability factor），所以三条曲线拟合得不错，但迁移性不足。

最合理的下一次结构更新是：

```text
measured transistor I_D(V_DS, V_G)
             +
self-consistent V_app = V_hBN + V_DS
             ->
one shared h-BN RESET transport/state law
```

也就是优先删掉栅压相关的 h-BN 经验系数，让 `V_G` 主要通过实测晶体管负载线
改变内部 `V_hBN`；只有负载线解释不了的剩余差异，才允许进入阻变状态模型。

目前 Fig. 2b 的正向 1T 曲线已经能建立查表接口，但直接代入曾在 1.1 V 给出
约 91 uA，而 1T1R 实测平台约 51 uA。这说明还需明确 1T 与 1T1R 的 W/L、器件
对应、源漏方向、源/体连接、串联/接触电阻，以及 RESET 时的端口方向。不能用
一个随意的 gate offset 把差异抹掉。

## 当前可以写入文章的证据分层

### A 层：当前数据直接支持

- 1T1R 与 1R 分别处于晶体管限流的渐进软路径区和 1 mA 限流的突变硬路径区；
- 无 h-BN 对照不发生阻变、去掉 Ti 仍可阻变，支持 h-BN/电极界面离子交换而
  不支持把 TiOx 作为唯一开关层；
- h-BN 厚度约 6 nm、约 18 层可用于换算平均内部场，但 XTEM 不是阻态对比；
- CAFM 显示明显的横向导电斑面积异质性；
- SET 后状态可连续传给 RESET，裸 1R RESET 的低压支路约为百欧尺度。

### B 层：与数据一致、可作为模型工作假说

- 多个二维限域弱区逐步激活形成 1T1R 的渐进转变；
- 裸 1R 的局部正反馈形成一个或少数强贯通路径；
- 空位/晶界/层间无序提供低能路径，金属迁移可能在较高应力下增强路径；
- RESET 的分段下降可由若干粗粒化完整跨层路径依次断裂解释。

### C 层：当前不能声称已证明

- `phi_k` 就是硼空位浓度；
- `h_j` 就是一根 Ti/Au 金属细丝；
- CAFM 等效直径就是导电丝直径；
- 用准静态电压步长反演真实迁移速率、脉冲时间或激活能；
- 仅凭端口 I-V 唯一分离金属离子迁移与硼空位迁移。

## 后续最值钱的三项工作

1. **先完成 1T 到 1T1R 的电路映射。** 明确晶体管身份、W/L、接线和 RESET
   极性，用 Fig. 2b 查表取代栅压相关的 terminal-current anchors；然后再次做
   1.1 V 留出，目标是把 RESET 留出 RMSE 从约 1 decade 降到 0.4 decade 内。
2. **把 CAFM 从面积直方图升级为逐斑联合数据。** 最有用的不是更多图片，而是
   `spot area-current-switching threshold-position` 的同点联合表，并说明扫描面积、
   分割阈值、样品/批次与电学器件的对应关系。这能检验面积是否与阈值或电流密度
   相关，决定 `w_k` 与 `dtheta_k` 是否应耦合。
3. **用时间/温度或阻态结构数据辨别微观物种。** 脉宽/温度依赖可约束迁移势垒；
   virgin/LRS/HRS 的 XTEM-EDS/EELS 可检验金属富集；二者都没有以前，保持一个
   mechanism-neutral 的状态变量比硬拆“金属”和“空位”两个不可辨识变量更可靠。

## 当前完成度判断

从“能拟合已有端口曲线”的角度，模型已经较完整；从朱老师要求的“电学 + 二维
限域 + CAFM + XTEM + 迁移物理共同解释”看，当前已经搭起可写文章的证据骨架，
并把 CAFM/XTEM 真正接入了模型约束。最大缺口不再是多画几条拟合线，而是：

- RESET 的栅压依赖还没有被统一的晶体管负载线解释；
- CAFM 只有边缘分布，没有与阈值/电流的联合关系；
- 缺少能区分金属迁移和空位迁移的时间、温度或阻态结构证据。

因此更准确的阶段表述是：**器件级物理解释已形成，微观物种级解释尚未闭环；
模型从拟合器推进到了可证伪的物理工作模型，但还不是唯一机理模型。**
