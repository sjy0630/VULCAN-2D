# 载流子供给预算：独立只读审核

2026-11-03。审核 `carrier_supply_budget_screen.py`、已保存 JSON/MD 与 jump
谱矩阵；未重跑谱、ODE、优化或筛选。脚本及所有登记输入的哈希均匹配。

**结论：所查必要界方向及分类合理；新增跃迁界完整计入低电流阶段。**

1. **128 片 jump 下界成立。** 连续单向 SET 必须穿过
   `[gamma_pre_upper,gamma_after_lower]` 的全部分片。在每片内，
   `Vh≤Vcommand≤Vafter`、`gamma≤gamma_hi`，故
   `I≤min(Icc,F(Vafter,gamma_hi))=Iupper`；同时
   `u≤ln(1+gamma_c/gamma_lo)=uupper`。
   函数 `h(I,u)=(I/I*)[ln(I/JS)+u]+` 对 I、u 均不减，所以
   `h≤hupper`。穿越该片至少需要 `delta_u/(kS*hupper)` 的命令路径长度，
   各片顺序相加给出
   `kS≥sum(delta_u/hupper)/delta_commandV`。
   非零状态片若 `hupper=0`，则不能穿越，记无穷下界正确。
   未将命令电压冒充限流后的实际材料电压；全程 Icc 的旧辅助界仍是更宽松的必要界。

2. **未跳过微安阶段。** 保存矩阵为 14×128 片；14 条记录首片电流上界
   均低于 Icc，范围为 **25.02 nA–2.166 µA**，全部进入倒速度求和。
   起点使用有利于模型的 `gamma_pre_upper` 只省去可能额外的初始路程，
   不会凭空增加形成时间。主预算取 14 条中的最小下界，也是在放宽可行性。

3. **slow 与 RESET 方向正确。** 慢段每片用 `F(Vleft,gamma_lo)` 和
   `u(gamma_hi)`，利用 h 的逐变量单调性得到下界，再取所有 Γ 片最小值；
   固定状态电流随电压不减，左和合法，不要求实际归一化驱动沿轨迹单调。
   RESET 用每片电流/状态上界构造最大驱动、用裸低读电流下界构造积分下界；
   **没有给裸 RESET 加 1 mA 限流**。共享时钟方向是 SET bare 上界乘 alpha、
   RESET bare 下界乘 alpha，正确。

4. **无穷上界分类正确。** 有限正下界配无穷上界记为相容但欠约束，
   `ratio=0` 不代表拟合完美；未据此选种子。只有两极性各有有限正上下界交集
   才进入已选条件种子。无穷下界不会因上界也无穷而被误算相容。

已选种子数为 0；这些陈述与产物一致。本审核未发现需要修改结果的方向错误。
