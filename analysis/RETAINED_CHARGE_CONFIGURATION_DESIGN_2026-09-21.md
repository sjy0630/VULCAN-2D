# 下一候选：保留旁侧电荷与构型的联合动力学

状态：执行前约定，尚未实现、拟合或验证。

## 动机和所检验的假设

已完成的激活构型候选将 n、m 都当作瞬时条件稳态，只传播 q。选中解在重复
扫描中迅速进入周期轨迹，预测 R4/R3≈1，实测为约260。固定参数下改变旁侧
交换率会改变部分电流曲线，却仍没有恢复该历史变化。这不排除重新拟合后的
速率效应，也不证明必须再增加一种结构变量。

下一步优先检验此前尚未检验的时标排序：导电占据 n 快速弛豫，而旁侧电荷 m
与构型 q 都有可保留的动力学。沿用已有物理自由度，暂不新增独立缺陷积累
坐标。目标是判断有限电荷响应能否与构型转换共同产生初期条件化和随后的
普通循环，而不是只改善稳定支平均误差。

## 模型约定

沿用当前同一能量函数 E_qnm、导电能谱、U、几何和两构型能级映射。每个谱
通道传播四个慢态 P(q,m)，保留 q–m 相关性，不以两个平均占据相乘替代。
构型跃迁 q0↔q1 保持 m；旁侧充放电 m0↔m1 保持 q。n 在每个(q,m)下的条件
占据为对应导电能级的两库加权 Fermi 概率 F_qm。

构型转移率对 n=0/1 的微观详细平衡速率作条件平均；旁侧充放电分别对出发
态的 n 条件概率平均 `Gamma_t*f(E_tq+U*n+(1-x_t)*V)` 和其反过程。
在 V=0 时必须恢复原完整八态的配分函数关系和逐对详细平衡。非零偏采用
驱动下的条件电子分布，不误用平衡能量平均。

新增一个共享旁侧充放电尝试率/扫描速率组合，单位 V^-1。构型仍沿用共同
鞍点及其可选二次场项；不先增加电荷相关过渡态参数。n 的绝热消去要求其
弛豫比两个慢自由度更快；其适用条件要明确，不能从电流尺度擅自分离通道数
和绝对电子速率。

当前仅q模型固定 Gamma_t/Gamma_R=1，不是新模型的严格嵌套极限。新模型在
旁侧电荷相对q很快、但相对n仍慢的极限，应与旧模型
Gamma_t/Gamma_R→0 的条件稳态版本相符；必须验证正确极限，不能声称它必然
包含旧固定比1的候选。

初始 q=0，m 采用该构型零偏热平衡边缘分布作为主假设；之后所有电荷和构型
联合概率跨 SET/RESET/下一圈保留，不逐圈重置。其他初始电荷选择只能作为
透明的敏感性，不从目标 RESET 反推。未知扫描间等待保持未建模，不以补齐
时间元数据作为继续工作的前提。

读出平均各(q,m)条件电流，并接同一正/反晶体管。电荷变化引起的导电电子
重新分布瞬态在准静态近似中仍忽略，必须标明；不扩展为脉冲模型。

## 必须完成的检验

1. 零偏配分函数、概率守恒及正性；与独立完整八态在导电电子快极限比较。
2. 旁侧电荷快极限与旧 Gamma_t/Gamma_R→0 模型一致；不错误比较快率顺序。
3. 原生电压电路、重复点零路径、完整连续历史及数值加密。
4. 同一八窗评分、53对描述、前35→后18预测；全部低信号和首三圈保留。
5. 特别报告 S3/S4 与 R3/R4 的同电压比、模型何时进入周期轨迹、以及是否
   仅改善稳定读取。分别核查模型分布与单次随机曲线，不能许诺每次跳变时刻。
6. 所有起点、失败、边界和绝热条件保留；对应训练集合初始化，不借全数据
   参数初始化顺序预测。若失败，先定位读取映射/鞍点/未测时标假设，不直接
   以更多结构状态补偿平均误差。

整体机制和创新性仍未建立。该候选的价值在于检验“旁侧电荷始终平衡”是否
正是遗失扫描历史的原因，而非给现有曲线再贴一个机制名称。
