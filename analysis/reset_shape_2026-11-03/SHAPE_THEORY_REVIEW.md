# RESET 形状与下一候选：理论及独立审核

2026-11-03，`shared_kernel_review`。本阶段没有新拟合、ODE、谱扫描或原保留集访问；只审查公式、复算已有训练结果，并按根任务授权完成一次同极性排序检查。旧冻结目录未改动。

**结论：只把断裂率由 λ(v) 改成 λ(v,a)，不足以解决现有问题。** 这类修改可以移动峰位，却仍保留确定性标量连续流的排序。训练数据中存在远离低电流区的排序反转；同时，单纯损失、静态背景、前 SET 欧姆读态上界的组合也有独立反例。这两个结论约束的是数学结构，尚未确定第二状态、随机性、非欧姆读出、跳变或测量协议中哪一种解释正确。

## 1. 不依赖谱拟合的必要界

设 `v=|V_h|`，负极性观测幅值为 `I_i=B_i+a_i v`。若前 SET 50 mV 的读态满足 `G_i=a_read,i+B_SET/0.05`、背景非负，而且从该读点至 RESET 只有 a 的损失，则

`0 ≤ a_i(s) ≤ a_read,i ≤ G_i`。

这个上界不需要假定 SET 最后 50 mV→0 或中间等待期间完全冻结；只要求这些阶段不使通道增长。它也不要求损失率仅依赖电压。

### 任意跨圈共同背景

若某一相同分支、相同材料电压节点的背景在各圈相同，则必须存在

`max(0,max_i[I_i-vG_i]) ≤ B(v) ≤ min_i I_i`。

两个端点若冲突，任何非负共同背景都无法挽救“欧姆路径＋纯损失＋前读态上界”，无需选择 Γ。若背景具有各圈不同的动态状态，此界不适用；通过此松弛界也不证明完整轨迹存在。

### 同圈静态背景相消

更少依赖跨圈假设的界是：同一圈背景若在外扫与返扫的相同材料电压下不变，即使各圈背景不同，仍有

`0 ≤ I_out(v)-I_ret(v) = v[a_out(v)-a_ret(v)] ≤ vG_SET`。

它不需要 λ(v) 相同、不需要知道背景谱、不要求返扫电流足够大到可取对数。

如果允许每个原电流读数独立处于 ±δ 相对带，最宽松差值区间为

`[(1-δ)I_out-(1+δ)I_ret, (1+δ)I_out-(1-δ)I_ret]`，

并必须与 `[0,v(1+δ)G_SET]` 相交。这是原电流的诊断敏感性窗，不是仪器误差、置信区间或逐节点可重新设置的物理初态。

## 2. bare 代理新诊断的独立复核

已只读审查 `reset_shape_diagnostic.py` 的区间接触、共同背景界、分支差界、原生配对和计数；用上一阶段保存的 14 条训练数组独立复算两项必要界计数，与 JSON 一致。

- 配对为原生外扫索引 k 与返扫 `201-k`，包含重复峰端的一对，不发生插值。
- 原 RESET 掩码仍为 2799 点；原生同电压配对 1400 对，两支原评分均有效的为 1399 对。
- 零背景固定 SET 的共同形状区间接触为 `δ=(R-1)/(R+1)`；原 RESET、SET 读数同时同带时为 `δ=(sqrt(R)-1)/(sqrt(R)+1)`。实现正确。
- 固定非零背景先对原电流区间减背景，再除以相应 SET 导电区间；未把相同相对误差直接施加到小余量。下界触及非正时显式保留不可计算状态，没有截零后取对数。
- 逐点接触只给乐观必要条件。同一 SET 误差必须用于全部电压，且还须存在公共、单调、连续的实际轨迹。
- 双分支乘积在两情景中均为 **0/1400 个强可用配对**。报告正确写为未获得强检验，而非恒等式失败。10 µA 与背景占比 1% 是预声明诊断窗口，不是仪器分辨率。

同圈静态背景上界在 ±0/5/10/20% 下分别有 64/24/22/6 对失败；20% 的六对均来自圈 10。最强见证：

| 圈 10，电压幅值 0.975000024 V | 数值 |
|---|---:|
| 外扫电流 | 14.3129202 mA |
| 相同电压返扫电流 | 3.0254255 nA |
| `(I_out-I_ret)/(vG_SET)` | 1.563501612 |
| ±20% 最宽松差值下界 | 11.4503325 mA |
| ±20% 允许的 `vG_SET` 上界 | 10.9852784 mA |
| 下界仍超过上界 | 0.4650540 mA，即 4.23343% |

返扫的 nA 数值对这个 mA 级差值影响不到百万分之一；微小低流偏置不能在数值上消除该见证。不过，未标定的电压误差、强异常测量、前 SET 非欧姆读态或未记录的状态增长仍是该模型前提之外的可能性，不能从 ±20% 自行推断其概率。

与之相反，分支差低于零的反例均处于双支低于 10 µA 的区域，只作条件性描述。跨圈共同背景界应优先引用全部 14 圈均高于 10 µA 的反例，不能只引用由 nA 分母放大的最大 L/U。

## 3. 不依赖 SET 边界的同极性排序反例

授权的一次检查保存在 `reset_scalar_order_check.py`、`RESET_SCALAR_ORDER_PLAN.json`、`RESET_SCALAR_ORDER_CHECK.json/.md`。以同圈 RESET 外扫 −50 mV 为排序锚，检查全部随后 98 个外扫节点和 91 个记录对，共 8918 个配对节点，没有拟合或背景扣除。

| 原始电流敏感性窗 | 严格反序配对节点 | 不同记录对 | 不同后续节点 |
|---|---:|---:|---:|
| ±0% | 2859 | 91 | 92 |
| ±5% | 2085 | 76 | 85 |
| ±10% | 1548 | 62 | 80 |
| ±20% | 803 | 38 | 79 |

这些计数共享记录和节点，不能当作独立实验样本。最强单个见证已经足够表达结构矛盾：

| 固定节点 | 圈 11 | 圈 14 | 排序 |
|---|---:|---:|---|
| RESET −0.05 V | 0.1551515 mA | 0.7901519 mA | 11 < 14 |
| RESET −0.725 V | 1.4211589 mA | 0.1253062 mA | 11 > 14 |

全部四个电流都大于 100 µA。即使允许每点 ±20%，两端区间仍严格反序；最少到 δ=0.671742387 才有一端区间接触。这个数是敏感性所需宽度，不是测出的噪声。

数学原因：在共同后续协议下，解唯一的标量连续 ODE 保留状态排序。若初始及后续电流读出对该状态具有相同单调方向，则电流也保留排序。共同加性背景只平移同节点的所有电流，不改变排序。

这个检查使用同一负极性中的两个读点，因而无需假定正 SET 的 50 mV 导电值恰好等于 RESET 初态，也无需知道 SET→0 的末端历史。仍然需要共同的后续电压/时间协议和适当的观测模型；未记录的不同停留时间不能被自动当成相同。额外状态、随机性、非单调读出、不保序的跳变或不同协议均可能规避；当前证据并未选定其中哪一种。

## 4. a 依赖危险率能做什么、不能做什么

一个明确的最少参数推广是

`da/ds = -κ(v-Vr)_+ a (a/a_ref)^m`。

`a_ref` 是固定单位基准，不是新增可拟合参数；m=0 恢复原律。取 Vr=0 且背景可忽略时，有

`a=a0[1+(mκ/2)(a0/a_ref)^m v²]^(-1/m)`，

在存在内部峰的 m<2 范围，

`v_peak² = 1/[κ(a0/a_ref)^m(1-m/2)]`。

m>0 让高初态的峰更早，m<0 则相反；m≥2 没有该路径的内部峰。m<0 还可能有限路径消失，需定义非负吸收边界而不能计算负底数。它显示仅凭“峰位不同”不能断言一定需要第二个状态。

但这个推广只要仍是解唯一的标量连续流，就不能改变上述固定节点排序。甚至加入平滑增长项也不会自动打破保序性。因而**当前不值得直接给 m 加一个宽范围拟合**，也不能通过每圈自由 κ、阈值或 m 绕过反例。

已冻结 14 条特征中，log G_SET 与 log V_peak 的 Pearson 相关为 −0.3644，Spearman 为 −0.2190，仅有弱的负向趋势；不是对某个幂律反馈的支持。圈 10 与圈 12 的 G_SET 只差约 2.8%，峰位却分别为 0.975 V 和 0.500 V。峰位的有限采样和近峰平坦性已另存，不可将一条关联直接升级为机制证据。

非保序的断裂跳变是光滑 ODE 以外的模型：例如越过压力阈值后不可逆跳到另一导电分支。它可以在很少连续变量下改变排序，但跳变规则/存活记忆本身必须显式列出；不能把它伪装成无记忆瞬时 λ(v,a) 后声称仍属于已检验的光滑标量族。

## 5. 如何区分动态背景与路径增长/断裂反馈

若坚持 a 纯损失，但允许背景在同圈中变化，则有必要预算

`B_out(v)-B_ret(v) ≥ I_out(v)-I_ret(v)-vG_SET`。

圈 10 的 0.975 V 见证要求名义背景差至少约 **5.158518 mA**；在同时允许原电流 ±20% 的最宽松口径下仍至少约 **0.465054 mA**。所以“背景稍微变化一点”不足以修复这个受限模型，候选必须实际提供相应幅度。此预算并不意味着实验已经证明背景就是这部分电流。

另一种可能是路径本身非欧姆：若 `I_path=a φ(v)`，前 SET 读数约束的是 `a φ_+(0.05)/0.05`，原来的 vG_SET 上界就要相应替换。有限偏压读数不自动等于零偏微分电导。共同非线性 φ 可以解释部分 I/v 增大，但若读出仍对唯一标量 a 单调，则仍不能逃过同极性排序反转。

本阶段软背景反演只能给 `F_soft(v,Γ)≤I_obs` 的 Γ 上界。没有独立背景份额下限时，不能因 Γ_eff 随路径变化便宣称真实 Γ 必须动态变化；足够小的静态背景仍可能允许。设计代理的 soft≥50% 是明确条件情景，不能当成已测分解。旧冻结背景降低可修复尾部上界，却不会自动提供上述 mA 级峰前动态预算。

因此比较两种候选时，需同时看：是否产生所需的同电压背景差、是否产生高信号跨圈反序、是否保留 SET 读态到 RESET 低压尺度的传递，以及是否在串联接法使用同一方程与求解后的材料电压。只改善某一条尾曲线不能完成此比较。

## 6. 有界的下一步提案

当前最省计算、已有约束足够明确的动作，是根任务已预声明的两个软 SET 前向探针，而不是再拟合裸 RESET 的 a 依赖率：

- β=4、JS/上界=0.95，κ 取名义必要区间的几何中点约 2.066 V⁻¹。
- β=6、JS/上界=0.8，κ=2×必要下界约 0.890074 V⁻¹；返扫上界无穷仅表示未排除。

这两个点固定谱形、Ron、Γc 和 JS，只从已用的 cycle 4 的 0.2 V 状态反解初态，再完整传播 0→5→0，低压残差全部保留；各一次精度复核，不追加起点、不据结果再调 κ。0.2 V 条件锚不是独立预测点。若反解或正向越出原状态/输运表域，应记录失败，不投影或裁剪。该测试仅决定软状态反馈是否值得继续，完全不宣称裸器件 RESET 或统一历史已通过。

对硬路径的下一候选，先限定模型类别而不自由增参：保留已有软状态 u，允许共同断裂率依赖 **连续传播得到的 u**，例如 `a'=-κ r(v)a f(u)`；`f≡1` 是冻结对照，最多引入一个全局耦合强度，不给每圈设定 f 或 u。完整电流仍为 `F_soft(v,u)+aφ(v)`，两接法只改变外电路。仅把 u 瞬时写成 a 的唯一函数且读出仍单调，会退回已排除的标量类；需要的记忆/耦合必须在动力学中明确存在。

这一候选目前只是可立项的最小结构，不是已获物理证据支持的定律。其执行前必须由现有传播模型给出 u 的历史、固定耦合函数及有限比较点，并将上面的背景差和排序见证写成必过检查。若选择随机/跳变替代方案，应预测共同的分布或事件规则，不能给每圈拟合一个专属噪声轨迹或断裂阈值。现有证据不允许直接指定金属丝、离子种类、温度或新微观状态。

## 7. 根任务 20 项 β 必要预算审核

已审 `soft_beta_relaxed_budget.py/.json`。实际坐标是 `u=log1p(Γc/Γ)`；输运电流随 u 递减、随命令 A 递增，β≥0。

- 早期状态分片 `[u_low,u_high]` 的驱动上界 `ln I_T(2,u_low)-ln JS+βu_high` 方向正确。`Σ Δu/Dmax /1.8` 给出乐观 κ 必要下界；非正 Dmax 对应不能穿过，不可跳过该片。
- 返扫每片下界 `ln I_T(A,u_high)-ln JS+βu_low`，再对状态片取最小，并按 A=2→5 的左节点积分，是正确的保守路径下界。κ 上界由总允许 Δu 除以积分得到。
- 两段均须先满足端点状态的单调顺序；实际代码已检查。零返扫下界积分记无有限上界/未排除，不是通过。
- 固定 4×5=20 个点，不新增低偏 5% 硬门槛。0.3% 输运包络是敏感性口径，不是新全域误差证书。
- β=1/2 的这五个 JS 点不满足两预算，不能扩大成连续参数域不可能；β=4/6 的未排除点也不能替代实际传播。两个前向探针的选择规则与保存的预算一致。

本审核没有运行这些前向试验；其结果应另行按实际曲线和数值复核报告。
