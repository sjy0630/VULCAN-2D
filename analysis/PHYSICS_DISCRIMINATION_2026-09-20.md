# h-BN 1T1M 电学曲线：物理解释与证据判别

日期：2026-09-20。研究对象：Zhu 等 Nature 2023 的 Au–Ti/h-BN/W–CMOS 器件。用户明确的贡献目标：解释电学曲线并给出证据。当前任务优先级是物理判别；论文写作、界面更新和进一步降低整体拟合误差不作为主线。

## 1. 当前结论及工作假设

v0.12/v0.13 已建立可复现的准静态曲线模型，但还没有完成微观机制的定量鉴别。现有模型可作为电路求解器和现象基线。其状态、PF 类曲率、幂律及跨极性系数不能直接当作离子浓度、间隙宽度或迁移效率。

有原文依据、值得检验的工作假设是：**晶体管限流使器件保持局部、部分退化的工作区；不完整连接中的残余间隙及界面势垒限制电荷输运，电应力改变有效输运状态，产生渐进 SET/RESET。** 这是待检验的具体物理图像，不是本项目已证明的机制，也不是本项目首次提出“纳米间隙”。

我们可能增加的贡献是：从实测晶体管约束下的内部 I–V 出发，定量区分电路分压、输运形状和状态演变的贡献，排除无法同时解释多条观测的简单机制。新颖性须结合后续同主题文献检索与实际结果判断，不能只因原文未给出本项目的方程就认定新颖。

## 3. 先完成哪些物理判别

## 4. 已完成的配对低压支直接判别

定义 `eta_i(v)=abs(I_RESET_initial_i(v))/abs(I_SET_return_i(v))`，其中 v 为扣除各自晶体管压降后的内部电压幅值。直接用实测正反查表和原始电流，不使用 PF、幂律、sinh 等 h-BN 包络，不输入任何拟合状态。

主窗口事先指定为内部 0.10–0.30 V，同时检查 0.08–0.25 / 0.15–0.35 V；原始支路只取 SET 回程端口电压不超过 0.60 V、RESET 初始支不超过 0.45 V。这是候选低扰动窗口，不能独立证明状态完全冻结。过滤超出查表、接近限流或反解敏感点，不跨无效原始点、不外推。数值门槛及逐点排除原因均保存。零偏置读数未扣除；其幅值只用于处理敏感性检查，不作为已估计的噪声或置信区间。

**主要结果：**

- 1.1 V 全 53 对均覆盖主窗口。每支窗口内约 10–11 个原始点，21 个插值网格点彼此相关，不能当作新增独立样本。最大晶体管压降份额为 SET 5.86%、RESET 10.27%。
- 每循环最佳常数比例的中位数为 **0.532**，10–90% 分位 **0.196–1.002**。各循环各自拟合常数后的残差中位 **0.0686 decade**；44/53 不超过描述性参考值 0.1 decade。这支持将幅值变化保留为简单近似，尚不能宣称所有循环都需要势垒形状改变。
- 一个全局比例的残差为 **0.6246 decade**。事后单独看第 4–53 圈，仍为 **0.2460 decade**；该分组用于检查早期异常的影响，全 53 对始终保留。逐循环拟合增加了自由度，其残差不等于对未见循环的预测精度。
- 第 1–3 对在相同内部 0.30 V 下的比值约为 **0.00364 / 0.00106 / 0.00236**。因此在已匹配查表的条件下，早期幅值差异不能仅用瞬时晶体管分压解释。但这没有区分极性相关注入与跨扫描阶段状态变化。
- R2 在内部 0.30 V 的零偏置参考读数占比约 **18.2%**，故其细致曲率不可靠。将各支电流分别扰动正负自身零偏置参考值并重新去嵌入后，R2 的比值范围约 **0.000863–0.001249**；该示例敏感性不足以消除其很大的幅值差异，但不是校准误差界限。
- 替换为晶体管升支查表，主窗比例中位为 0.53224；改变电压窗后为 0.52404/0.52375。主要描述对这些处理选择稳定；它们没有覆盖晶体管器件失配等所有实验不确定度。

这里的直接曲线比值与 v0.12 在特定参考电压处用两种拟合包络定义的 `eta≈0.258` **不是同一个估计量**。不能把两者差别称作参数漂移。

0.9/1.3 V 同名表也完成探索性处理，主窗完整覆盖分别为 90/100、59/101。由于配对及跨栅压组条件未在本次判别中独立建立，且数值筛选覆盖不同，暂不据此推断栅压因果律。

当前证据支持的下一问题是：**为何早期扫描的跨极性导电幅值与后续循环显著不同，以及一个受历史约束的初始输运状态能否解释这种变化。** 暂不把它指定为离子松弛、缺陷积累或某种接触机制。现有数据同时保留了普通循环中的近似幅值换算规律和无法由统一比例描述的早期异常。

## 5. 已完成的经典 PF 条件一致性检查

当前电流包络为 `I=A*v*exp(beta*sqrt(v))`。若额外假设整个 6 nm 膜均匀承受已去嵌入电压、经典库仑陷阱 PF 热发射成立，则：

`beta = sqrt(q^3/(pi*epsilon_0*epsilon_r*d)) / (k_B*T)`。

beta 是自然指数系数，单位 `V^(-1/2)`；`log10(I/v)` 的斜率是 `beta/ln(10)`。用已存档标定的 SET pre `6.5376046`、RESET HRS `6.2858693`，条件反推如下：

| 假设温度 | SET pre 表观 epsilon_r | RESET HRS 表观 epsilon_r |
| --- | --- | --- |
| 250 K | 48.39 | 52.35 |
| 300 K | 33.61 | 36.35 |
| 350 K | 24.69 | 26.71 |

这不是介电常数测量。温度不是目标实测温度序列；三档数值只是敏感性检查。Pierret 等研究的不同 Au/h-BN/Au 电容报告动态介电常数约 3.1；按这个参照值、300 K 和 6 nm，经典系数应约为 `21.53 V^(-1/2)`。目标为退化 CVD 薄膜及界面，不能直接等同该参照样品，但这一量级差异说明**当前 beta 尚不支持未经额外论证的经典均匀场 PF 解释**。也不能用这项检查排除所有缺陷辅助输运。

单纯“更短的间隙”或“场集中”不能修补这一差异：若 `E_loc=f*v/d_eff`，则 beta 随 `sqrt(f/d_eff)` 增大；按 6 nm 均匀场反推的 `epsilon_app=epsilon_true*d_eff/(f*d_nominal)` 反而减小。部分电压落在其他内部区域是不同的额外假设，须独立约束。

Schottky 发射的温度前因子与 PF 的场前因子不同；不能把这组 beta 原样换入 Schottky 公式并宣布选中了接触机制。需要对同一原始电流数据按各自完整方程重新比较。

## 6. 现有异常如何进入物理研究

此前审查在端口 `abs(V_app)=0.3 V` 发现：S2/S3 回程电流分别为典型 SET 中位的 74.7%/94.0%，紧随其后的 R2/R3 前向仅为典型 RESET 中位的 0.171%/0.424%。这已经是待解释的事实，不能因旧筛选拒绝这两圈就删除物理问题；也不能直接命名为“离子松弛”。这里是端口电压，不能与本次内部电压网格混写。

晚期有效 E50 上移仍是另一问题。固定早期包络排除了一种重新拟合效应，但状态识别依赖包络和单调约束；“不可逆损伤积累”尚未被证明。应先检查变化是否同时出现在合理包络、初始阻态控制和直接曲线特征中。

对我们而言，一项物理结论至少应同时具备：明确观测、给出不同预测的竞争解释、合理且可约束的参数、对窗口与循环分组稳健的结果，以及与目标器件结构证据的相容性。若现有数据不能区分，应报告可辨识的组合，而不是强行指定原子物种。
