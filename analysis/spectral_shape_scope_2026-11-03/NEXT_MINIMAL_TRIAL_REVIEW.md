# 下一项最小试验：先检验既有共同谱形的允许域

2026-11-03。独立方案审查；本轮只执行另附的有限必要条件筛选，不改 core、
不干预正在进行的拟合，不新做 ODE 优化。

## 优先判断

**先重新检查已有谱形参数，比先放开 cell 参数或未知时钟更可证伪。** 当前
固定谱形来自局部、近冻结软态窗口；固定这个点也是额外假设。让原有
`Emedian、sigma、eta` 在此前声明的算法域内变化，仍保留同一电流公式及
同一材料参数数量，能直接检查现有训练曲线是否允许更合理的共同状态路径。

不能再用“整段 SET 返回都冻结”作所有形状的入场条件。某些候选需要返回
时继续闭合，这正是要检验的可能性。低偏共同冻结读态仍可作为更强的条件
单列，不能与一般有限速率下的必要方向条件混在一起。

## 统一方程下的有界比较层级

| 层级 | 同一方程内允许什么 | 当前证据与限制 |
|---|---|---|
| 完全共同基线 | 共同材料参数、名义晶体管、共同路径率；只保留已声明制备初态差别 | 当前严格试验，失败只否定该组合 |
| 共同谱形允许域 | 只重新选择原有三个谱形参数，仍共同用于两接法 | 本次优先；固定点嵌套于该域，参数种类未增加 |
| 有依据的 cell 差异 | 仅由实际 cell 身份、已测几何/读出或准备历史支持的差别 | 目前足以区分准备初态，不足以任意分开 Ron、能谱、阈值或速率；裸表编号不等于已确认独立 cell |
| 外电路敏感性 | 一个共同源参数，零偏移/单位尺度包含基线；同时贯穿关联的正负数据 | 是条件检验，不能只给1T1R改映射并声称独立1T仍是同一只器件；不与材料自由度一起开放 |
| 共同时间律、未知相对时钟 | 单一 alpha=rT/rR，同时作用于 SET/RESET，两接法仍共用物理 H | 可作条件 profile，不是实测扫速；当前没有已验证的 alpha≥20 完整可行 seed |

## 本次实际执行的有限筛选

上限为 **47 个预登记形状点、300 秒**：现选点，旧局部域的6个轴点和8个
角点，以及旧全局域内固定种子的32个分层点。域直接取已有 JSON，不根据
结果自动扩大。不同积分域下无效点与预算终止均保留。

每个点只作以下训练诊断：

1. 在原电流经验区间下反演允许 gamma 区间，检查低偏正返回/负外扫各自
   的状态方向。另列共同低偏冻结状态是否存在，不把这项强假设藏进筛选。
2. 检查高压 5→4→2 V 与低偏端点能否由同一单向 SET 状态连接；不要求
   每个点精确拟合均值。1%/5%仅是显式敏感性，不改变原主门槛。
3. 对方向可行的参数点重新计算裸同态穿带时间界。若仍强制
   `rT/rR>1`，则当前共同路径率假设仍有条件冲突；若该比较不再适用，
   只称“未被此必要条件否决”，不称已经解释了动态曲线。
4. 对反演端点做积分加密检查，数值不合格的点不进入候选列表。

这与重跑旧静态拟合的区别是：目标是共同状态方向和可达性的允许域，而非
继续压低单一冻结包络 RMSE。Gamma 在这里是 oracle 状态区间，不是预测，
也不是新增加的逐点材料参数。只有通过后才值得把一个候选送入既有动态
框架，以相同原始目标进行一次有预算的完整验证。

## 未知扫速是否允许作条件 profile

允许。固定一个 alpha 情景，再对原有共同参数作有限条件优化，可以说明
“在这个模型下，需要怎样的协议差异才能同时解释两接法”。它不能说明
“实际实验就是这个速度”，也不能据优化出的 alpha 推断微观活化机理。

已有必要预算在大 gamma_c 下给 alpha≥约20 留下交集，说明这一逃逸尚未
被完全排除；但这不是现成成功 seed。原两个 diagnostic q 的 SET/RESET
时钟区间互斥，不能直接乘上20就称为可行。若后续需要该诊断，最多预设
alpha=1、20、50三个情景、每个情景固定同一正负倍率；先复用现有参数作
前向比较，再决定是否值得有预算的条件 profile。固定参数敏感性与重新
优化后的 profile 要明确区分。

本次优先筛谱形，因为它利用已有曲线约束、没有补入未知协议。若有限筛选
没有找到候选，应报告这个离散样本范围的结果；既不立即发明新机制，也不
宣称整个谱形域空无一解。

## 什么才算进步

通过必要条件仅是进入动态验证的资格。实际进步应包括：同一方程和连续
状态下，原有四支曲线评分与关键特征同时改善；原先的状态方向/可达性冲突
解除，且没有依靠重置、报告 floor 驱动物理、逐接法改材料或数值误差。
仅静态 RMSE 更小、某个分支更好、或未知 alpha 的条件最优点，均不足以
宣布统一模型已完成。所有参数的可辨识性仍须与真实时间协议分开解释。
