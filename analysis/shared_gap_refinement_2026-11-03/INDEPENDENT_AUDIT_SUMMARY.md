# 最终独立数值审计与 B→0 消融

日期：2026-11-03。范围为选定参数的裸 R 完整一对 SET/RESET，以及状态连续
传递的两对 1T1R 回线。未修改拟合、内核或主评价文件；仅训练数据用于消融的
描述性评分，未用留出数据选择候选。

## 数值检查

生产实现采用 Radau；独立参考重新构建三角波路径、写出原状态速率并使用
DOP853。二者共享电路工作点函数，因此另用独立电流空间 Brent 根和直接
代数电压式检查抽样工作点。所有电压分配、KCL、被动性及功耗分量守恒通过。

| 选定模型 | 最大电流差 / decade | 最大全轨迹 u 差 | 最大末态差 | 独立负载点 | 最大求根相对差 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 准确重标定基线，严格容差 | 2.70×10⁻⁸ | 4.18×10⁻⁷ | 2.76×10⁻⁹ | 136 | 4.28×10⁻¹³ |
| RESET 分组校准，严格容差 | 1.26×10⁻⁹ | 4.18×10⁻⁷ | 1.35×10⁻¹⁰ | 137 | 3.96×10⁻¹³ |
| 最终 Access 候选，常规生产容差与严格参考 | 1.26×10⁻⁷ | 1.79×10⁻⁶ | 8.30×10⁻⁹ | 136 | 4.74×10⁻¹³ |

原验收门槛保持不变：电流差不超过 2×10⁻⁴ decade，全状态与末态差均不
超过 2×10⁻⁵。表中结果不认证任意参数或全部 50 圈，也不等于物理机制验证。

保留两类实际失败：

- 基线在较宽容差下，裸 SET 2.80 V 观察点的 u 差约 0.00201，电流因
  1 mA 限流而一致。收紧两种求解器后消失；不能以电流一致代替状态精度。
- Access 在极严 Radau 容差下，以及 B=0 无重拟合消融的普通路径求解中，
  曾出现步长低于浮点间距。没有据此改方程或强制跳态；这些配置不称为通过。

## 最终 Access 确实未修复目标趋势

最终选中第二个起点，B=0.1607108 V。实际连续 SET 轨迹的 2→4 V 对比为：

- `Rh(4 V)/Rh(2 V)=0.497084`，电阻下降约 50%；训练实测则全部上升 17–28%。
- `u` 从 2.508285 降到 2.021627，电流从 44.44 µA 增至 72.29 µA。
- 新增压降只占对应 h-BN 总压降约 5.1%。`I exp(u)` 两端均约 0.5458 mA，
  几乎贴着 SET 停止阈值。因此“新增静态项允许电阻上升”没有变成真实轨迹。
- 即使冻结 2 V 时的 u，使用上述两电流，电阻比值也只是 0.752；B=0
  时为 0.650。该冻结状态检验也是模型消融，不是新的实验验证。

## 全轨迹 B=0 消融

所有其他参数和两个初态冻结；状态沿波形重新计算，并未复制 Access 的状态
轨迹。如下是原始训练记录的对数 RMSE，不是留出评分或训练中位曲线误差。

| 分支 | 最终 Access | B=0，无重拟合 |
| --- | ---: | ---: |
| 裸 R SET | 0.7513 | 0.6484 |
| 裸 R RESET | 0.7953 | 0.8939 |
| 1T1R 第一对 SET | 0.3378 | 0.3360 |
| 1T1R 第一对 RESET | 0.5773 | 0.5785 |
| 1T1R 第二对 SET | 0.3742 | 0.3707 |
| 1T1R 第二对 RESET | 0.5773 | 0.5785 |

裸 RESET 峰从 Access 的 −0.375 V、3.219 mA 变为 B=0 的 −0.400 V、
3.827 mA；训练中位曲线峰为 −0.500 V、4.780 mA。1T1R RESET 峰几乎
不变：35.07→35.81 µA，均在 −1.26 V。这表明新增项没有解决该峰的幅值
偏差。这里的实验峰是“训练中位曲线的峰”，不可与“逐圈峰的中位数”混称。

两种情况下裸 SET 最终 u=0，50 mV 读阻和零偏微分电阻都为 93.4801 Ω。
相较之下，分组校准基线末态 u=0.0271035，50 mV 读阻为 113.842 Ω，
零偏微分电阻为 3895.41 Ω。Ron 的数值由训练观测锚定，不是独立材料预测。

B=0 裸 SET 的极快层采用审计专用的精确变量变换 `ds/du=1/G(V(s),u)`
求解；指令电压仍随 s 变化，没有冻结偏压或规定瞬时跳变。DOP853 与 Radau
得到首次 u=0 的电压相差 1.93×10⁻¹⁰ V，存储观察点的电流、状态和末态
一致。该数值处理没有写入生产内核；普通生产求解失败仍在结果中显式记录。
