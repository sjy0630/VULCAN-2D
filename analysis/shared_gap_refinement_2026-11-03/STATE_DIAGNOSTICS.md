# 训练数据对现行 GapLaw 的结构约束

日期：2026-11-03。仅使用裸 1R 前 14 对与 1T1R 第 4–35 圈。
输运、动力学和晶体管参数均冻结，未重拟合。逐点反演使用目标电流，属于
诊断，**不是自主预测或唯一微观状态测量**。

完整数据、逐圈结果、训练中位曲线反演及来源哈希见
`state_diagnostics.json`；复现脚本为同目录 `state_diagnostics.py`。

## 不能靠当前输运参数重标定消除的约束

现行输运式给出

`R_h(I,u)=V_h/I=Ron+V0*u*asinh(I*exp(u)/I0)/I`。

对任意正的 Ron、V0、I0，固定 u 时 R_h 随 I 不增，固定 I 时 R_h 随 u
增加。因此，SET 中若 u 只能减小，而后一个点的电流增大，则 R_h 不能增大。
其电流方向的导数符号来自
`x/sqrt(1+x²) - asinh(x) <= 0`。此结论不依赖当前拟合输运参数数值。

使用固定的独立晶体管曲线去掉压降后，在 **1T1R 训练 32 圈的正向扫描
2 V → 4 V** 中，32 圈电流全部增大，但 h-BN 的 V_h/I 全部增大：

| 指标 | 结果 |
| --- | ---: |
| 逐圈 R_h(4 V)/R_h(2 V) 最小值 | 1.17160 |
| 中位值 | 1.23971 |
| 最大值 | 1.28255 |
| 训练中位曲线 R_h(2 V) | 60.823 kΩ |
| 训练中位曲线 R_h(4 V) | 75.063 kΩ |

因此，在**晶体管映射适用、指令电压可作准静态端电压**这些前提下，现行
GapLaw 输运形式与 SET 单向 u 动力学的组合，无法精确复现这段稳定趋势。
仅重调 Ron/V0/I0 或 RESET 启动阈值不能消除此矛盾。这不排除其他共享材料
模型，也不能排除晶体管对应关系、测量电压或准静态假设本身存在偏差。
17–28% 的差异在 32 圈均出现，是一致性证据；目前没有仪器误差模型，不能
将其写成已完成统计显著性检验。

更宽泛的回线方向约束并未被训练中位曲线明显否定：SET 回扫同电压电流应
不低于去程，RESET 相反；四支训练中位曲线均没有超过 0.1 decade 的
反向次序违反。因此不能笼统宣称所有单向状态模型都已被数据排除。

## 可以通过共同参数重标定改变的冲突

当前 Ron=93.4801 Ω，而本构强制 V_h/I>=Ron。裸 R 训练数据中有 7 个
非限流 SET 点及 145 个 RESET 点低于该界，因而根本没有可行 u。训练
中位 SET 最后 +0.05 V 点的电阻为 90.8928 Ω；逐圈最强下界冲突约为
61.5400 Ω。把低阻电阻的中位数固定成模型最小电阻，会预先排除部分真实曲线。
这说明当前 Ron 的固定方法不充分，不能据此排除整个输运族。

冻结输运参数反演时，四支训练中位曲线都需要一部分与 G 方向相反的 u
变化。最大反向变化为：裸 R SET 0.879、RESET 1.438；1T1R SET 3.199、
RESET 1.845。排除 |V|<0.1 V 后，1T1R RESET 仍为 0.708；其他三支
最大值不变。这些数值依赖冻结的输运参数，不能单独当作参数无关的定理。

裸 SET 的 2027 个限流点只提供 0<=u<=u_upper 的区间，并未用完整指令
电压反演成一个确定状态。单调性检查使用区间可行性，保留平坦晶体管分支的
电压区间。低电压或低于原评分电流门槛的点单独标记。

## 状态交接诊断

从末端电流反演的状态出发，仅传播已知的短路径“当前读点→0→下一读点”，
再检查下一支电流。其起点含实测信息，因此也是条件兼容性检查。

- 裸 R SET→RESET：受 Ron 下界限制，仅 7/14 对可反演 SET 末端。对这
  7 对，直接采用首个 −25 mV 点时，预测/实测电流对数差的中位值约
  +0.984 decade；改在 −50 mV 检查时中位值为 +0.008 decade，范围
  −0.013 至 +0.059 decade。已知首个 RESET 点异常不能解释成真实状态跃迁。
- 1T1R SET→RESET：32 对均可检查；选择不低于 50 mV 的端点时，预测/
  实测电流对数差中位值约 +0.183 decade，范围 −0.333 至 +0.840。
  训练中位曲线 +60→−60 mV 需要 u 从 1.094 变为 1.432，但当前 G
  在这段连接路径完全冻结，电流差约 +0.298 decade。
- 1T1R RESET→下一次 SET：31 次交接；最近非零读点的预测电流均偏小，
  对数差中位值 −0.177 decade，范围 −0.662 至 −0.078。使用至少
  50 mV 的控制读点时中位值 −0.414 decade，方向并非每圈一致。

这些交接差异依赖固定输运、固定阈值和测量背景；待机时间、偏置偏移、端口
不对称或晶体管来源均未独立识别。不能用逐圈重新设初态把它们藏起来，也不
应把它们立即命名为某种新微观机制。裸 R 没有已确认的跨记录时序，本诊断
不强制其 RESET 末态接到下一个编号的 SET。

## 数值核对

用已知 u 的合成冻结点独立检查反演：13 个可确定状态的点最大绝对误差
6.1×10⁻¹²；其余 3 个限流点的区间均包含真值。未改变任何基线内核或参数。

下一步首先应核对/约束上述 2→4 V 去嵌入电阻趋势与 Ron 的含义；继续只调
RESET 动力学无法解决已暴露的 SET 输运结构矛盾。
