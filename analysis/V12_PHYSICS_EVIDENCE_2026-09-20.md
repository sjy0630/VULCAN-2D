## 1. 当前模型与证据来源

当前研究对象是固定协议的 1T1M h-BN 器件：`V_G=1.1 V`，SET 为 `0→+5→0 V`，RESET 为 `0→−1.7→0 V`。模型在完成训练后只接收电压序列和栅压，自主给出两段电流。它是该协议下的有效紧凑模型；方程的可预测性与微观机制的唯一性是两个不同问题。

## 3. 两个状态与层厚约束必须单独说明

### 3.1 SET 的 x 和 RESET 的 s 不天然是同一状态

`x` 以正向 `pre/connected` 包络为基准，`s` 以负向 `HRS/LRS` 包络为基准。两者都在 `[0,1]`，也都可用“连接比例”描述，但归一化参考、极性和读出协议不同。范围一致不意味着 `x=s`，更不意味着二者等于同一空位浓度或局域桥数量。

现行 `run_autonomous_full_cycle` 把 `xs` 与 `pbs` 拼接输出为 `connected_fraction`。电气交接实际使用 `A_conn` 和 `η`；它**没有将 SET 的最后一个 `x` 数值直接赋给 RESET**，RESET 内部状态从 1 初始化。因此现阶段闭环成立的含义是“在校准协议中连续生成两段 I–V，并用训练得到的幅值桥接”，不是“已经证明同一微观状态变量跨极性守恒”。不应据此宣称模型已处理部分 SET、任意中断点或一长串历史依赖循环。

### 3.2 6 nm 与约 18 层提供几何约束，不提供逐层动态

原文章及仓库既有记录给出的目标 h-BN 厚度约为 6 nm；继承的参数还记录约 18 层，平均层距约 0.33 nm。这支持将平均内部电压换算为场，并把解释限制在层状 h-BN 的面外传输几何中。

当前 RESET 使用 `E=10v/6`（MV/cm）。`hbn_layers=18` 没有在 v0.12 自主路径中成为 18 个可独立连接/断开的状态，SET 包络和 PF 曲率也没有由逐层电势计算推出。局部有效厚度可能与膜厚不同，是其他 h-BN 研究支持的候选解释 [R4–R6]；本模型没有识别其数值或演化规律。改变厚度时仅重算 `E`、同时保留现有阈值、曲率和幅值，不能视为已验证的厚度外推。

### 3.3 正反查表采用已确认条件，不重复打开已解决事项

按项目交接记录，用户已确认 `Bookoutput2.xls` 第四列是 ID，独立 1T 与 1T1M 的晶体管类型、尺寸和端子/body-well 连接相同，目标拓扑为 Au–Ti 顶电极扫描、h-BN 下方 W 接 Drain、Source 接地、Gate 恒压。JSON 中部分“待确认”标签早于这些确认，应按交接信息理解。

body/well 的具体电位仍未知，但匹配的反向实测曲线包含该接法下的总电流响应，在已测范围内无需镜像正向数据。此次材料核对使用仓库保存的两份查表，未重新转换或审计原始 `2b.xlsx/Bookoutput2.xls`，因此不能声称本次重新确认了原始测量、文件转换或寄生支路的微观归属。

## 5. 验证结果应怎样表述

现行 53 对 1.1 V 循环中，R2/R3 未通过既有包络可分性筛选，保留 51 对。逐对留一时使用其他 52 个 SET 和 50 个有效 RESET 来重新拟合相应规律；顺序划分用编号 1–35 中的 35 个 SET、33 个有效 RESET，预测后 18 对。继承的 0.9/1.3 V LRS 曲率及跨栅压转变先验不是每个 1.1 V 留一折重新估计的量。

应使用“不将目标电流用于该目标的预测参数估计；目标电流用于预先定义的质量筛选和评分”。直接写“目标电流只在评分后才被读取”不准确，因为保留集合依赖其包络可分性。保留集合的性能也不能自动代表所有失败/不可分循环。

存档的中位回线 RMSE 为 SET 0.078/0.085 decade（升/回），同协议 RESET 0.192/0.124 decade；逐点汇总误差较大，分别约 0.166 和 0.293 decade。这反映典型曲线和逐循环随机波动是不同预测任务。不要用由训练电流反演的状态拟合 RMS（SET 约 0.057、RESET 约 0.037）替代留出电流预测误差。

同协议 RESET 转变律和 `cross_gate_prior` 共用输运、查表和交接，仅阈值/宽度来源不同。同协议律更适合同一总体的留一评估，跨栅压先验在已观察到的晚期分布变化上较稳健；两者的选择经过本数据回顾性比较。加上 SET 映射和包络形式也经过开发期选择，现有结果属于**内部验证**，不能称为未参与模型开发的独立外部测试。

## 6. 最有价值的三个简化模型对照

以下只使用现有 DC 数据，属于待执行的研究设计，不宣称已有结果，也不要求先新增实验。所有对照固定同一正反查表、筛选集合、评分电流门槛和训练/测试划分；不允许用目标电流设置端点或重新对齐阈值。报告每个循环的误差差值、中位回线误差和分支/电压区间残差，避免只比较一张看起来接近的总图。

### 对照一：降低输运包络复杂度

- **问题**：SET 的超欧姆指数与 RESET 的 PF 类曲率是否分别带来可重复的预测收益？
- **简化模型**：先单独把 SET 连接包络固定为欧姆 `I_conn=A_conn v`（`n=1`），其余路径不变；再作为分开的单因素对照，把 RESET HRS 换回旧 `A_H sinh(α_H v)`，保持共享曲率的参数数目可比。两项不能同时改后再把收益全部归给其中一项。
- **拟合与判据**：每折仅从训练循环重新估计受影响幅值、状态律和交接；比较 SET 回支与 RESET 回支的误差、残差曲率和参数稳定性。v0.11 已给出 HRS 对照的历史参考，但其输入包含实测 SET，不能直接与 v0.12 的电压自主结果作同条件优劣比较。
- **能回答什么**：若简化模型在留一与顺序划分中效果相当，应优先考虑更简单的包络；若现行形式稳定胜出，可支持其紧凑预测价值，仍不能单凭胜出识别微观输运机制。

### 对照二：把 SET 电压曝光驱动换为简单电压阈值

- **问题**：在已经校正的正向映射下，累积内部电压曝光是否比简单扫描坐标更有预测价值？
- **简化模型**：用 `x_eq=[1+exp(−(|V_app|−V50)/wV)]^−1` 替代曝光 sigmoid，保留两包络、电路求解、不可逆更新和回支冻结。阈值与宽度仍为两个训练参数，避免因参数数量不同而混淆。
- **拟合与判据**：固定同样的稳定包络识别规则，在训练循环拟合 `V50,wV`，对留出电流评分；重点看 SET 转变区定位、形状、逐循环误差以及顺序划分中的稳定性。
- **能回答什么**：若曝光律显著改善这些指标，支持在当前 DC 协议中保留它。由于现有扫描路径相似，曝光与电压可能高度相关；结果相当说明数据不足以唯一选择驱动坐标，不证明累积历史在物理上不存在。网格加密只能检查数值收敛，不能冒充扫描速率或时间预测验证。

### 对照三：去掉配对 SET→RESET 交接

- **问题**：经验 `η` 桥接是否比独立给定同协议 RESET 初始 LRS 更有信息？
- **简化模型**：跳过 `η A_conn` 交接，直接用训练 RESET 的 `G_L` 对数中位数预测目标初始幅值；保留 HRS 终点、输运与 RESET 转变律。目标初始读电流仍不得输入。
- **拟合与判据**：保持相同外层留一与顺序划分，比较 RESET 起始低压段、转变段和整段误差；同时检查训练配对数据中交接残差是否随 SET 连接幅值变化，任何关系选择只能发生在训练集。
- **能回答什么**：当前同一训练折对所有目标都采用同一个中心 `A_conn`，实际交接也不读取各目标的 SET 末态。因此独立 `G_L` 基线与现行模型可能近乎等价。若没有稳定增益，应把 `η` 定位为一致的协议换算，而不是已验证的逐循环记忆传递；若有增益，也只能支持配对统计关系，不能把 `η` 升格为原子迁移效率。

这三类比较宜预先固定方案再统一报告。即使采用训练内选择，它们仍是在已用于开发的数据上开展的进一步内部检验，不应包装成全新的外部盲测。
